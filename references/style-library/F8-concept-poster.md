# F8 概念海报

**家族量化规格**：文字即主体 ≥80%；留白 ≥40%；元素 ≤4 件；色 ≤4 种；禁普通插画、禁字效贴字、禁元素堆砌。

**风格卡片**：核心调性 = 词义、隐喻、精神状态的视觉化；视觉特征 = 文字图形化、丝网印刷、克制色板；经典结构 = 主题词为主视觉 + 字形隐喻 + 关系级叙事；禁忌 = 普通插画、字效贴字、元素堆砌。

**Best for**：字/词/词组/短句的视觉化，词义隐喻，高级概念海报，展览感海报。

## V8 — 概念海报 ✅ 已验证，可进默认路由

**Best for**：任意主题词的视觉化，词义→核心关系→空间叙事的转译。

```
一张 5:2 超宽横版的高级概念海报，极简、克制、有展览感的丝网印刷质感。先理解主题词的字面含义、情绪气质与隐含象征，确定它的核心关系与空间叙事方向，由词义推演，再依此组织画面。主题词横排于画面中央，颜色与背景形成强对比，笔画清晰舒展，是整张画唯一的主视觉；主题词的笔画与字形可作图形化处理，将词义隐喻融入字形，而非仅字外配图。字与图构成空间叙事，可见的是词义的具象，不可见的是词义的余韵，二者张力随核心关系推演；画面里点缀一处与主题呼应的点睛物，点到为止。主题词与一行辅助短句字号相近、差别不大，靠粗细与位置区分主次；所有文字与画面边缘都留足内边距，不贴边、不裁切。整张画除主题词和那行短句外没有任何其他文字、水印、日期或印章。配色克制、整体不超过四种，深底浅字、对比强烈，颗粒与纸纹轻微，清爽利落。整体清冷孤高、安静求索，让人一眼看懂主题词为什么是这样被表达的。

用户输入内容：主题：[请在此填写]
```

**量化**：比例 5:2；文字即主体；字形可图形化（笔画替换/字形同构/局部解构）；元素 ≤4 件；色 ≤4 种；深底浅字强对比；颗粒纸纹轻微；无多余文字/水印/印章。

**槽位**：主题词 = 唯一必填变量（字/词/词组/短句皆可）；核心关系与空间叙事方向、意象、点睛物、辅助短句、四色配色均由模型从主题词自动推演，不写死。

**状态**：已出图验证（踏雪寻仙 V8，用户确认质量相当高），可进默认路由。
