**家族量化规格**：真实质感为硬约束；禁插画化、禁平面化；光质与镜头参数明确；本家族提示词用中文或英文均可，镜头参数建议保留英文术语。

**风格卡片**：核心调性 = 真实、情绪、现场感；视觉特征 = 胶片颗粒、真实纹理、明确光质；经典结构 = 特写/近景 + 真实环境 + 镜头语言；禁忌 = 磨皮美颜、影棚摆拍、塑料质感。

## S — 纪实人像

**Best for**：未修饰的真实情绪、后台、生活现场。

```
[主体：如后台休息的京剧刀马旦侧脸特写，卸妆前的真实状态]额头渗出细密的汗珠，混合着厚重的油彩。几缕湿润的发丝粘在脸颊上。聚焦眼神中的疲惫与坚韧，真实皮肤纹理，卡粉与毛孔细节清晰可见。后台昏暗的杂乱灯光，形成自然的散景。超写实，8K分辨率，新闻纪实摄影风格，情绪饱满。

负向：磨皮、美颜、舞台定妆照、过度修饰、眼神空洞、塑料皮肤、影楼风、插画、平面化。
```

**说明**：主体槽位填「谁 + 什么状态下的特写」，示例（京剧刀马旦）是已发布版本，可替换为任何职业/人物。负向行必须保留。

**量化**：特写构图；皮肤纹理必须可见；负向 9 项全保留。

## T — 胶片抓拍（Kodak Portra）

**Best for**：亲密瞬间、九十年代私人照片感。

```
手持相机拍摄，稍微偏离中心的近景构图，[主体描述]。使用增感冲洗的柯达Portra 400胶片拍摄，配50mm f/1.4老镜头全开光圈——明显的胶片颗粒感，焦点柔和地落在眼睛上，鼻子和边缘位置稍微失焦，自然的动态模糊，边缘有轻微色差。城市夜晚混合光源，脸部稍微过曝，颧骨处有明显的高光溢出，阴影部分欠曝发黑，背景过曝形成光晕。画面带有轻微暗角，镜头灰尘轻微雾化，1-3度自然倾斜。九十年代私人约会照片的美学风格，不完美但亲密的瞬间，绝非影棚质量，自发的抓拍感觉。

负向：影棚布光、完美对焦、磨皮、商业精修、摆拍感。
```

**量化**：倾斜 1-3°；焦点 = 眼睛；必须有过曝高光 + 欠曝暗部；负向 5 项。

## V — 超写实影棚人像

**Best for**：干净高级的时尚人像。

```
超写实电影感影棚人像，2:3画幅，高分辨率，照片级真实感。[主体：一位时尚东亚年轻女子半身肖像，可替换为其他人物/肖像类型]，身姿微倾，头部轻侧，神情清冷从容。纯色衣物，简洁剪裁。无缝影棚，深色背景渐变。柔光为主，强而温润，补光极简，保留深邃暗部强化明暗对比，轮廓光勾勒身形。平视取景，85mm f/2.2，浅景深，肌肤与织物质感真实细腻，画面纯净。

负向：过度磨皮、塑料质感、花哨背景、夸张妆容。
```

**量化**：比例 2:3；镜头 85mm f/2.2；光 = 柔光主 + 轮廓光；负向 4 项。

**槽位**：主体可替换（人物身份/年龄/姿态）；其余光质、镜头、画幅锁定句不动。
