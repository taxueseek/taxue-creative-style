# F6 氛围实验

**家族量化规格**：单色或近单色；强对比；禁复杂场景；禁多余装饰。

**风格卡片**：核心调性 = 神秘、电影感、精神性；视觉特征 = 单色强对比、符号雕塑、数字诗意；经典结构 = 巨大主体 + 微小人物 + 极简标题；禁忌 = 彩色、复杂场景、多余装饰。

**变体索引**：

| 变体 | 名称 | 状态 |
|------|------|------|
| D | 黑暗行者 | 默认 |
| X | 书法符号雕塑 | 默认 |

---

## D — 黑暗行者

**Best for**：沉思、神秘、电影感、精神性概念（行者、独行、觉悟）。

```
极简黑暗大气海报。纯黑背景，高对比黑白。

主体为巨大的、半透明的、被垂直雨丝或光柱切碎的佛面或人面轮廓，从上方垂落，带有数字毛刺与细白光晕质感（毛刺为黑白噪点，光晕为细白光线，不引入任何彩色）。底部有一个极小的孤独人影站在水面倒影上，面向光柱。

顶部极简中文标题（如「行者」），细白字，居中。

整体神秘、静谧、有电影感与数字诗意。禁止彩色、禁止复杂场景、禁止多余装饰。

画面中除顶部标题外不出现任何其他文字与标点，标题原样呈现不加标点，无任何水印、日期、签名。

标题：[填入中文标题，2-4 字]
```

**量化**：色板 = 纯黑 + 白；标题 2-4 字；人影 ≤1 个且极小。

## X — 书法符号雕塑

**Best for**：抽象符号、年份、生肖的雕塑感表达。

```
以“[主题]”为主题的单一符号雕塑画面。主体为一个抽象化的轮廓，形态由连续、流动的书法式字样构成。整体像被拉伸的红色漆面笔势，而不是写实动物。材质为高光釉面或树脂，表面光滑有明显反射。单一柔和光源，产生轻微立体投影。背景纯浅色，高留白。画面极简、克制、强调符号感而非叙事。

画面中不出现任何文字、标点、水印、日期或签名。
```

**量化**：主体 =1 个；色板 = 红漆 + 纯浅底；留白 ≥50%；禁写实形态、禁叙事场景。
