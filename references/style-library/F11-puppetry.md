# F11 皮影偶戏

**家族量化规格**：主媒介 = 透光皮偶或实体木偶，二者不同时当主媒介；必须能看出「被操控」；色彩 ≤4 种；禁与剪纸混写为同一工艺。

**风格卡片**：核心调性 = 戏台、侧影或偶身、手工操控；视觉特征 = 灯屏透光 / 布料木头微缩；经典结构 = 角色表演 + 舞台或布景；禁忌 = 把皮影写成剪纸、把木偶写成光滑 CG、写实人脸。

**与旧卡分工**：F5-M1 把「民间剪纸 / 皮影」写在同一张卡，是混卡，点名皮影或木偶禁止再走 M1。F9-R5 是照片转皮影涂鸦，输入必须是用户的照片。

**变体索引**：

|------|------|------|

## F11-PY — 皮影戏台

**Best for**：传说对峙、侧面叙事、仪式、舞蹈、白蛇/哪吒等戏文。要平面剪影但不需要灯屏时走 F10 或 F5-M2。

```
中国皮影戏单帧。侧面或正侧结合的皮偶在暖色灯屏前表演。[主体]为镂空皮偶，四肢和颈部有可见关节与连接点，内部雕花服从可动结构，不是满铺装饰。光从幕布后方透过半透明皮革，形成朱红、棕黄、墨黑与幕布米白的层次。背景是色纸或极简戏台布景，层数少、轮廓清楚，没有写实深度。动作停在一个戏曲式顿挫点。禁止把皮偶画成窗花剪纸，禁止玻璃质感，禁止 CG 角色关节，禁止现代舞台射灯。画面中除[可选题字]外不出现任何其他文字与标点，无水印、日期、签名。

用户输入内容：主题：[请在此填写]
```

**量化**：比例默认 16:9 戏台横幅（单人对峙可 3:4）；主体 1–2 个皮偶；色 ≤4（朱红/棕黄/墨黑/幕布色）；关节必现；灯屏必现；禁剪纸层叠语法。

**槽位**：主体（谁在做什么，填「角色 + 动作 + 对峙或独演」）；可选题字（默认无，剧目名 ≤4 字）。

## F11-MU — 木偶定格

**Best for**：市集喜剧、民间小人物、儿童寓言、带道具的生活瞬间。要神话英雄动作走 F14-SM。

```
传统木偶定格动画单帧。[主体]是手工制作的实体木偶，材料能看出布料、纸糊、木头、毛线或金属丝，头身比例简练夸张，关节像被逐帧摆过。环境是微缩布景，墙、摊、桌、地面都有手工痕迹，不是照片街景，也不是光滑塑料玩具。光线温和，像窗边日间光，读得出偶和布景的层次，不用电影轮廓光。色彩跟材料走，土墙、布帘、陶罐这类生活色，全画面不超过四种。禁止真人皮肤、禁止电脑 3D、禁止超浅景深商品摄影。画面中除[可选题字]外不出现任何其他文字与标点，无水印、日期、签名。

用户输入内容：主题：[请在此填写]
```

**量化**：比例默认 4:3；主体 1 个木偶（可加 1 个配偶）；材料痕迹必现；布景 = 微缩手工；色 ≤4；禁 CG / 真人 / 浅景深商品照。

**槽位**：主体（角色种类 + 一个生活动作 + 一件道具）；可选题字（默认无）。
