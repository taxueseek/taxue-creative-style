# 风格独立协议（开放注册表）

> 用途：判断一个视觉语言该不该独立成家族，以及如何新增。旧编号（F1–F9 的 61 个变体）保持稳定接口，不搬号、不删号。家族数量不是上限。

## 一、根问题

表层需求：风格库再多几个家族。
根问题：用户雇本技能，是要把**任意主题**编译成可执行的视觉指令。卡住的不是「模板不够」，是**分组维度错了**——同一家族里混进了互斥的制作语言。
第一性原理：风格 = 媒介 × 构图 × 色板 × 情绪 × 工艺约束。一张风格卡必须能独自回答这五个变量；两个模板若不能共用同一套禁忌，就不是同一个家族。
因此必须按视觉语法注册风格卡，而不是按题材往 9 个抽屉里塞。

非目标：不把 `taxue-artist` 的正宗门类还原、`taxue-solar-polaroid` 的完整节气推演、`brand-hand-drawn` 的品牌纯度、`chinese-art-animation-prompt-system` 的动画工艺全书复制进来。本库只收**踏雪化、可单段执行**的风格卡。

## 二、独立判定（量化，MECE）

四问互斥：媒介 / 禁忌 / 称呼 / 题材。每问 0 或 1 分。**≥3 分必须独立成家族**；=2 分先做参考模板（不占变体号）；≤1 分留在原家族当变体。

| 轴 | 问什么 | 1 分条件 | 0 分条件 |
|---|--------|---------|---------|
| 媒介 | 画面是怎么做出来的 | 制作语言不同（剪 / 雕 / 绣 / 绘 / 折 / 透光 / 拓印 / 釉 / 拍 / 档案装帧） | 只是同一媒介换题材 |
| 禁忌 | 父家族的负向约束会不会误杀它 | 父家族禁忌与本语法冲突（如「留白海报禁写实」杀掉器物釉面） | 禁忌可共用 |
| 称呼 | 用户怎么点名 | 用户直接说风格名，不说父家族（「皮影」「青花瓷」「年画」） | 只在父家族下被当作变体提 |
| 题材 | 能否跨主题复用 | 同一语法可服务 ≥3 类无关主题 | 绑死单一题材 |

判定时只打这四轴，禁止用「好不好看」「出图多不多」当独立标准。

## 三、新增家族流程（计数开放）

1. 用上一节四问打分，写入本文件「判定记录」。
2. 新建 `style-library/F{n}-{slug}.md`：家族量化 + 风格卡片 + 变体索引 + 每变体（Best for / 模板 / 量化 / 槽位）。
3. 旧变体**不搬家号**。新语法用新代号。旧混卡（如 F5-M1）保留，路由时改走新家族。
4. 三处同步：家族文件、SKILL §1 速查表、verification-ledger。标题里的「N 家族 / M 变体」按实际计数，禁止写死 9 或 61。
5. `python3 scripts/consistency-check.py` 必须 OK。
6. 主题路由：在 `theme-router.md` 给该语法至少 2 个主题对照，证明能跨题材。

禁止：为了凑数把同一媒介换个题材就算新家族；把子技能全书粘进本库；把实验变体当默认。

## 四、开放注册口径

- 家族 = 检索索引，不是天花板。公开分享（@TaXue2025，2026-08-16）写的「距离 72 种变化还有一定距离」是资产层的量化目标，不是再锁死 9 个抽屉。
- 五层架构仍是治理视角。用户问「有哪些风格」时，按独立语法回答，不按「第几层」。
- DNA 七条是纸底、浅底家族的默认气质。满构图、灯屏、釉面、年画、摄影按本家族量化豁免留白百分比，禁止把「留白第一」写进这些模板当硬百分比。
