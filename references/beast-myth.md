# 妖兽 / 神兽母题系统

参考模板（同 geometric-monument-poster：不占变体号，不改变体计数；模式二/三可按需引用）。本文件解决「画妖、画兽、画神兽」这一大类主题，用一条连续轴切分，而不是把每只兽当成一个独立变体。

**第一性原理**：妖兽/神兽不是「画一只兽」，而是**人兽程度的连续谱**。造型、气质、禁忌都由「人兽占比」这一个轴决定：

- **偏人**：近人形、妩媚、有情绪、可交互 → 造型比例偏向人，只保留兽性特征（尾、耳、鳞、瞳）。
- **偏兽**：兽形态、气势、蛮荒、有力量 → 造型比例偏向兽，人性只体现在姿态与眼神。
- **神兽**：神圣、图腾、祥瑞、超现实 → 不追求真实生物，讲究规矩、对称、符号化、仪式感。

## 一、先定档（母题定位）

用户提到「妖」「兽」「神兽」「异兽」「瑞兽」时，先判断落位，再选对应填充模板。判断依据 = 用户对「它是人还是兽」的描述：

| 用户说法 | 落位 | 造型占比 | 气质关键字 |
|---|---|---|---|
| 狐妖、蛇精、魅、妖媚、美人鱼、半人半兽 | **偏人** | 人 8 兽 2 | 妩媚、危险、冷、疏离 |
| 异兽、猛兽、穷奇、饕餮、龙、麒麟、大妖、山海经兽 | **偏兽** | 兽 8 人 2 | 气势、蛮荒、威严、神秘 |
| 神兽、祥兽、瑞兽、镇宅、图腾、青龙白虎朱雀玄武 | **神兽** | 符号化 | 神圣、对称、祥瑞、仪式感 |
| 狼人（人形）、吸血鬼、血族、魅魔 | **偏人·西式** | 人 8 兽 2 | 贵族、危险、冷、嗜血 |

## 二、偏人妖兽（狐妖 / 蛇精 / 魅）

近人形，保留 1-2 处兽性特征（尾、耳、鳞、竖瞳、异色瞳）。核心是「危险的美」，气质的疏离感比五官重要，避免画成普通美女加个尾巴。

```
一幅[家族：水墨留白 / 上美影浓艳 / 新中式]风格的[妖兽名]图。主体是[人形描述]，近人形，只保留[1-2处兽性特征：如狐尾/猫耳/蛇尾/竖瞳]。姿态[优雅侧身/回眸/俯视]，眼神[不直视观者/带一丝危险与冷]，面部清冷精致但不夸张，[兽性特征]与[人形身体]的衔接自然，兽性部位以[画法：枯润墨线/精细鳞片/柔色晕染]表现。整体气质[妩媚而疏离]，美得带危险。画面[留白/构图]克制，[单强调色]如唇色/瞳色/尾尖一点。禁止：卡通化、过度暴露、把妖兽画成普通美女加道具、兽性特征夸张成怪物。
画面中除[指定文字]外不出现任何其他文字与标点，[指定文字]原样呈现不加标点，无任何水印、日期、签名。
```

**量化**：人 8 兽 2；兽性特征 ≤2 处；单强调色；留白按家族规格；禁卡通化、禁把兽性夸张成怪物。
**家族适配**：
- F1-P 水墨美女/魔幻 → 清冷空灵，留白 ≥60%，蛇尾/狐尾用枯润墨线（见 F1-P-Snake）
- F5-L 上美影仕女 → 浓艳妖魅，石青/钛白/墨黑 + 深墨绿背景，兽性特征精细
- F5-MP 民国月份牌 → 复古摩登，糖色复古调，旗袍仕女 + 兽耳/尾

## 三、偏兽妖兽（异兽 / 猛兽 / 龙 / 麒麟 / 饕餮）

兽形态，力量与气势是主体。人性只体现在「有神志的凝视」——眼睛是灵性所在，身体是蛮荒与凶威。

```
一幅[家族]风格的[异兽名]图。主体是[兽形态描述]，体型[巨大/威猛]，姿态[盘踞/昂首/回身]，肌肉与骨骼结构清晰有力。[兽性细节]如[鳞甲/鬃毛/利爪/獠牙/角]以[画法]表现，质感[如金属/岩石/皮革]。眼睛有神志，是整张画的灵性点，[注视/凝视]方向带威严或肃杀。整体气质[蛮荒、神秘、远古]，[色彩]克制的单主调或[色板]。背景[大面积留白/深底]烘托体积与压迫感。禁止：卡通化、宠物化、过度详细到像标本、元素堆砌。
画面中除[指定文字]外不出现任何其他文字与标点，[指定文字]原样呈现不加标点，无任何水印、日期、签名。
```

**量化**：兽 8 人 2；眼睛为灵性点必须精到；禁卡通化/宠物化/标本化；色彩单主调或 ≤4 色。
**家族适配**：
- F2-OP 欧普线描 → 已验证（貔貅，主体可换龙/麒麟/饕餮），纯黑白、线条纯装饰非毛发、竖版 2:3（见 F2-OP）
- F1 水墨 → 写意，浓淡干湿，兽的骨感与毛发飞白，留白烘托气势
- F5 锦地 → 重装饰锦地边框，祥兽做主体，华丽织锦质感，挂轴/壁画用途
- **国潮泥塑 · 蟠龙（龙纹实例，来源 vivo 笔记 2067）**：手工捏制蟠龙，粗陶土材质，表面龟裂纹自然开片，局部鎏金，龙鳞以篆刻刀法刻划，龙眼镶嵌玻璃珠，传统琉璃瓦配色，赛博数据流环绕，背景虚化老窑洞场景，顶光营造神圣感，3D 扫描质感，ZBrush 雕刻细节，博物馆展灯光——龙纹的「筋骨 + 材质 + 时代混搭」可执行模板。

## 四、神兽（祥兽 / 图腾 / 青龙白虎朱雀玄武 / 瓦当）

不追求真实生物，讲究**规矩、对称、符号化、仪式感**。神兽的「神」来自秩序与图腾性，不是实物感。可参考非遗笔记「先秦两汉凤鸟 / 四神兽瓦当」的远古玄奇气质（远古、玄奇、神秘，忌太具象、太详细、色彩太多、线条太精准）。**凤鸟特质**（来源 vivo 笔记 11_纹样图腾）：太仙、太飘逸，像从仙界走出来的神兽——线条舒展、形态轻盈、凌空欲飞，与四神兽瓦当的「远古玄奇、动物纹瓦当」同源，忌具象结构与精准线条。

```
一幅[家族]风格的[神兽名]图腾。主体是[神兽]，高度符号化、对称，讲究[图腾结构：如卷云纹/回纹/规矩对称]，姿态具仪式感。[神兽细节]如[鳞/羽/角/火焰纹]以[符号化画法]表现，不追求生物写实，重秩序与装饰。色彩[色板]如[墨黑/朱红/石青/金]，克制而有威严。整体气质[远古、玄奇、神圣、祥和]，有图腾与镇宅的仪式感。背景[纯色/宣纸底/深底]烘托。禁止：过度写实、结构太详细、色彩太多、线条太精准、宠物化。
画面中除[指定文字]外不出现任何其他文字与标点，[指定文字]原样呈现不加标点，无任何水印、日期、签名。
```

**量化**：符号化 + 对称 + 规矩；色彩克制 ≤4 色；忌过度写实/精细/多色/精准线条；质感以装饰纹样为骨。
**家族适配**：
- F1 水墨 → 写意玄奇，留白衬神圣，笔墨生拙
- F2 留白海报 → 瓦当/图腾居中，深底浅纹或宣纸底，强对比
- F5 剪纸 → 剪纸造型天然图腾化，红/黑/金，镂空负形，视觉冲击
- **工笔重彩（神兽·偏兽实例，来源 vivo 笔记 2894）**：近侧视角，坐骑神兽体型饱满、前肢下压后肢蓄力、头微低獠牙外露卷须张扬，眼神温和却蕴含爆发力，周身卷云纹毛发飘动，姿态如箭在弦；祥云缭绕，深墨金色背景，工笔重彩细腻勾勒 + 金属质感金色渲染，朱红/金/黑，威严神秘的宗教氛围，构图饱满，3:4。
- **异兽微缩手法（偏兽参考，来源 vivo 笔记 2873）**：超写实微距摄影，微缩景观，黑色哑光背景，极简俯视图——用微缩景观的「异形压迫」表现吞噬一切的异兽，比正面写实更有张力。

### 四.5 皮影妖兽 / 神兽（牛皮带脊 · 逆光透射 · 狞厉面孔）

皮影是妖兽/神兽最贴合的家族之一——关节结构 + 镂空雕刻 + 半透明逆光，天然承载「妖而狞厉」的东方神秘气质（来源 vivo 笔记 2901/2902/2904/2905，且与 F9-R5 皮影涂鸦、F5-M1 皮影/剪纸同源，避免重复）。

**皮影妖兽 · 通用语法**（骨架，来源 2901）：

```
[生物名]皮影肖像，牛皮镂空雕刻，[矿物彩：朱砂红与石绿/朱砂红与赭石]矿物彩绘，米黄色皮纸背景。逆光透射产生半透明蜜蜡质感，正面柔光勾勒白色镂空轮廓线。[面部夸张狞厉：如吊睛三白眼/暴突圆睛如铃，獠牙外露，鬃毛/卷发呈S形卷云纹或火焰纹卷曲]。装饰[火焰纹/鱼鳞纹/云雷纹]，皮革表面有老化裂纹与斑驳磨损。等效85mm微距镜头，f/2.8浅景深，[暖色温偏暖]，平视略仰视角度。清代民间非遗工艺，东方神秘主义，[陕西皮影头茬风格]，高对比低饱和，纤维纹理清晰可见。
```

**量化**：牛皮镂空 + 矿物彩绘（朱砂红/石绿/赭石）；逆光蜜蜡质感 + 白色镂空轮廓线；面部狞厉（三白眼/圆睛/獠牙/卷云纹）；装饰纹样（火焰/鱼鳞/云雷）；皮革老化裂纹；85mm 微距 f/2.8 浅景深；暖色温偏暖；高对比低饱和；默认 3:4 竖幅。比例、色温、光圈按 L1/L2/L3 分级（焦段/光圈直写，色温只写效果，不写 3200K——见 prompt-craft.md 参数分级）。

**皮影变异体（来源 2905 马妖）**：长脸裂唇、马耳尖竖如刀、鬃毛火焰纹卷曲、鱼鳞纹与云雷纹装饰。**头部形态可换**：妖怪（人面狞厉）、马妖（兽首）、其他异兽，面孔与鬃毛按生物调整，皮影工艺语法不变。

**皮影神兽 / 图腾纹样（来源 2904）**：中国传统皮影雕刻纹样，祥云螺旋纹饰，深酒红/橄榄绿/土黄金交织，云纹饱满圆润呈螺旋卷曲，白色镂空轮廓线分隔云块，皮革细密龟裂，构图密铺无留白——适合神兽/图腾的符文化表达，与镂空轮廓线合力构建庄重神秘。

**皮影戏式样基础（来源 1272/2911）**：关节式可动结构、拉毛纹理工艺、柔性纸张质感、传统色彩（红/黑/金）、装饰性构图、层次分明立体效果、动态姿态设计。

## 五、西式生物（狼人 / 吸血鬼 / 兽人 / 美人鱼 / 西方龙）

西式生物不是一条新轴，而是**沿「人兽占比」这根轴往西式哥特与魔幻方向延伸**，并叠加西式特有的**超自然/哥特气质**（苍白的贵族、暗夜、血、教堂、荒原）。中式侧重「气韵、留白、图腾」，西式侧重「造型、光影、哥特氛围」。

### 5.1 偏人·西式（吸血鬼 / 魅魔 / 人形狼人）

近人形，靠「非人感」与「危险的美」立起来——苍白的皮肤、特殊的瞳色、邪魅的笑、过长的犬齿。核心是**贵族化的阴郁**。

```
一幅[西式画法：哥特/魔法写实/Art Nouveau]风格的[生物名]。[人形描述]，近人形，只保留[1-2处非人特征：如血色竖瞳/尖犬齿/苍白的皮肤/极长的指甲]。姿态[优雅侧身/居高临下/回眸]，眼神[冷而迷离/带一丝嗜血]，[非人特征]与[人形身体]衔接自然。整体[哥特气质：维多利亚式礼服/暗夜/烛光/教堂窗户]，色彩[暗调为主：暗红/紫黑/冷灰]，[单强调色]如瞳色/唇色/血迹一点。画面[深色背景/光束]营造贵族与危险的氛围。禁止：卡通化、把吸血鬼画成普通帅哥加道具、过度血腥、现代旅游照感。
画面中除[指定文字]外不出现任何其他文字与标点，[指定文字]原样呈现不加标点，无任何水印、日期、签名。
```

**量化**：人 8 兽 2；非人特征 ≤2 处；哥特暗调 + 单强调色；禁卡通化、禁普通帅哥加道具、禁过度血腥。
**适配**：可走 F7 写实摄影（哥特光影、电影感）或平面插画（Art Nouveau 装饰线条）；若用户点名「真人感」走 F7-S/T，点名「插画感」走平面。

### 5.2 半人半兽·西式（兽人 / 美人鱼 / 塞壬 / 石像鬼）

人兽对半，是「异形感」最强的档——上半身人、下半身兽/鱼尾/翅膀，或人脸兽身。核心是**蛮荒 / 海妖 / 异形**的怪异美，不是纯人也不是纯兽。

```
一幅[西式画法]风格的[生物名]。主体是[半人半兽描述]，上身[人形部分]，下身/背部[兽形部分：如鱼尾/鹰翼/狮身/羊角]，[衔接处]如[鳞纹/羽毛/皮革]过渡自然。[兽形部分]以[画法]表现，质感[如湿润鳞片/金属羽翼/厚重毛皮]。眼睛是灵性点，[注视]带[怪异的魅/蛮荒的警惕]。整体气质[海妖的魅惑/蛮荒的怪异]，色彩[如深海青/黄昏暖/灰绿]，[单强调色]点缀。背景[水下/悬崖/废墟]烘托异形感。禁止：卡通化、把两半生硬拼接、过度写实到像标本、可爱化。
画面中除[指定文字]外不出现任何其他文字与标点，[指定文字]原样呈现不加标点，无任何水印、日期、签名。
```

**量化**：人 5 兽 5；衔接处必须自然（鳞/羽/皮革过渡）；眼睛为灵性点；禁生硬拼接、禁标本化。
**适配**：F7 写实摄影（美人鱼水下、塞壬礁石）；或平面插画（装饰性奇幻）。

### 5.3 偏兽·西式（西方龙 / 狮鹫 / 半人马 / 恶魔 / 地狱犬）

兽形态，力量与魔幻是主体，可叠加翅膀、火焰、咒文等西方奇幻元素。核心是**凶威与远古神话**，不是东方神兽的图腾对称。

```
一幅[西式画法]风格的[生物名]图。主体是[兽形态描述]，体型[巨大/雄壮]，姿态[盘踞/展翅/俯冲]，肌肉与骨骼结构有力。[兽性细节]如[鳞甲/巨翼/利爪/獠牙/角]以[画法]表现，质感[如火龙鳞甲/石像鬼石质/恶魔皮革]。[眼睛]有神志，透[凶威/远古智慧]，[额外元素]如[火焰/烟雾/咒文光点]营造魔幻。整体[暗黑奇幻/史诗感]，色彩[如暗金/赤红/冷灰]。背景[荒原/城堡/火焰]烘托体积。禁止：卡通化、宠物化、过度详细到像标本、元素堆砌。
画面中除[指定文字]外不出现任何其他文字与标点，[指定文字]原样呈现不加标点，无任何水印、日期、签名。
```

**量化**：兽 8 人 2；眼睛为灵性点；禁卡通化/宠物化/标本化；色彩单主调或 ≤4 色。
**适配**：F7 写实摄影（史诗感），或平面奇幻插画；西方龙可走「写实巨兽」或「装饰纹章」（半人马/狮鹫适合纹章化）。

### 5.4 西式生物通用处理

1. **先判西式/中式**：用户说「狼人/吸血鬼/兽人/美人鱼/西方龙/恶魔/精灵」→ 走本段西式；说「狐妖/龙/麒麟/神兽/镇宅」→ 走上面东方段。西式生物默认叠加**哥特/魔幻气质**，与东方的留白图腾不同。
2. **西式默认画风**：用户未指定时，偏人/半人半兽走「哥特写实」（F7 写实摄影光影）或「Art Nouveau 插画」，偏兽走「暗黑奇幻写实」；点名要「迪士尼/美漫/卡通」再降级为平面插画。
3. **单强调色纪律保持不变**：西式暗调里只留一处亮色（瞳色/唇/火/血迹），避免杂乱。
4. **可复用东方模板**：偏人复用 §二 结构（只改兽性特征为西方非人特征），偏兽复用 §三 结构（加翅膀/火焰等奇幻元素），神兽类西式（天使/独角兽/纹章兽）复用 §四 的结构思路但换成西方图腾（对称纹章、宗教符号）。

## 六、交付纪律

1. **先定档再画**：用户提及妖/兽/神兽，先按 §一 判档，再选对应填充模板；判不准时按用户最强调的语感取（「妖」→偏人，`兽`/异兽→偏兽，`祥瑞`/镇宅/图腾→神兽）。
2. **人兽占比写进正文**：偏人要写「只保留 1-2 处兽性特征」防止变怪物；偏兽要写「眼睛为灵性点」防止失效；神兽要写「符号化、对称」防止画成写实标本。
3. **不新增变体号**：本文件是参考模板，供模式二/三引用，不改 61 变体计数与三处同步。
4. **枚举不进正文**：三档分类、家族适配是设计侧自检逻辑，正文只留一句「造型与气质由人兽占比推演」。
5. **色板按家族**：同一妖兽在不同家族用不同色板（水墨墨色 / 上美影石青钛白 / 剪纸红黑金），不套单一神兽色板——遵守主技能硬约束 #12。

## 七、现有可复用资产（无需重写）

- **F2-OP 欧普线描貔貅**（✅已验证）：偏兽异兽的高质量落点，主体可换「貔貅/龙虾/瑞兽/符号」，守住「线条纯装饰、非毛发」防翻车句。
- **F5 锦地**（默认）：宠物/瑞兽/人物的重装饰肖像，锦地边框，适合神兽化装饰。
- **F5-M2 剪纸祥兽**（速写版）：剪纸天然图腾化，可承接神兽。
- 归档「非遗四神兽瓦当」：远古玄奇气质参考，非可执行模板，只吸「玄奇、神秘、克制」气质进神兽档。
