# 跨模型方言层

taxue 在家族模板槽位填充 + 七维 + 量化锁定之后，得到一份**踏雪母版本**。本文件管最后一公里：把母版本转成目标模型的方言。**只改语法外壳，不改内容；任何方言转换不得改变主体身份、数量、画面意图、比例、色板。**

读取时机：①模式一二三的产出要落到达标模型时 ②用户点名模型时 ③同一创意要跨多模型保持一致时 ④静帧转视频 / 关键帧链路时。

## 单行纪律（吸收冗余，浓缩为一句）

质量关卡、反模式、专名准入、负面词纪律、量化精度边界，taxue 已有（optimize-pipeline 步骤 1.5 矛盾扫描 / prompt-craft 负向纪律与量化精度边界），**本文件不重复，只对齐；本文件的独有职责 = 跨模型方言转换与跨模型一致性。**

## 一、先定母版（模型无关）

母版 = 家族模板槽位填充结果 + 七维 + 量化锁定 + 六词检查口诀。字段与 taxue 映射（非平行体系）：

| 母版字段 | 对应 taxue 概念 |
|---|---|
| 主体 / 动作 | 七维·主体 |
| 场景 / 环境 | 七维·环境（家族模板里） |
| 构图 / 视角 | 七维·构图 + prompt-craft 尺寸表「提示词必须写」 |
| 光影 / 色彩 | 七维·光影 / 七维·色彩（HEX 色板） |
| 质感 / 媒介 | 七维·质感 |
| 文字 | 文字纯净句（DNA 第 7 条） |
| 不可变项 | 七维·约束 + 量化锁定（比例/留白/元素上限/负向） |

母版是跨模型版本的**唯一事实源**。加参考图时先列素材职责（见 task-constraints.md），再进方言层。

## 二、模型路由表（任务 → 首选 → 写法重点 → 避免）

默认以 taxue 宿主（Grok / Codex，见 imagegen-routing.md）为参考。下表用于用户点名其他模型、或用同一创意跨多模型保持一致时；「模型能力」一律不写成保证，以用户实际入口为准。

| 模型 | 首选任务 | 写法重点 | 避免 |
|---|---|---|---|
| ChatGPT / GPT Image | 对话式生成、参考图编辑、单图概念 | 自然语言讲清「做什么、保留什么、改什么」；精确文字置引号 | 一次要求多轮互相矛盾的改动；只说「更好看」 |
| Nano Banana Pro | 高精度商业图、复杂合成、版式、产品、多参考图 | 强动词开头；叙事化场景；参考图逐一分配角色 | 关键词堆砌；只用负面词表达目标 |
| Nano Banana 2 | 快速迭代、信息型视觉、实时信息 | 沿用 Pro 结构；「信息来源→视觉转译」 | 把不可核验即时事实当已锁定素材 |
| Seedream 5.0 Pro | 商业视觉、信息图、海报横幅、精确局部编辑、多参考融合、视频关键帧 | 先信息层级与画面网格；保持「保留项→编辑区→修改→边缘/光影延续」；参考图各担身份/姿势/道具/材质 | 无优先级混多张参考图；把时间轴/镜头运动/音效写进静帧 |
| Grok Imagine Image 2.0 | 精确静帧生成与编辑、密集版式、清晰小字、智能扩图 | 先锁定信息层级与布局；编辑写区域/保留项/改动目标；多图融合每张分角色 | 把视频节拍/音效写进静帧；未界定编辑范围就要求「全部重做」 |
| Grok Imagine Video 1.5 | 带同期声短视频、情绪表演、明确运动节奏 | 单镜头或少量连贯节拍；速度变化、镜头运动；声音独立 `Sound:` 段 | 一段塞过多角色、跳切、互相冲突动作；忽略声音 |
| Seedance 2.0 | 多模态视频、人物/品牌一致性、运镜、延展与短片叙事 | 主体→环境→动作节拍→镜头→声音→锁定项；`@AssetName` 分配角色 | 无主次长清单；一次替换角色/镜头/光线/动作 |
| Midjourney / FLUX / SDXL 通用 | 用户指定平台或需兼容多工作流 | 输出核心母版 + 适配提示；平台参数单列为可选 | 假装知道未确认版本参数；把参数当内容描述 |
| Codex 内置 gpt-image-2 | taxue 默认宿主出图 | 不变。沿用 imagegen-routing.md 第 3 条，用出图封装 | 不擅自为路径或分辨率切 CLI |

## 三、分支工作流

### A. 纯图像生成

顺序：`生成/设计/重构 + 主体 + 动作 + 场景 + 构图/镜头 + 光线/色彩 + 材质/风格 + 文字/锁定项`。对通用扩散模型再额外给一行精简关键词版，但关键词版不得省略主体、场景、构图。

### B. 图像编辑与参考图融合

开头用「保留—修改」句式：先列保持不变的身份、产品几何、Logo、姿态、镜头或画幅，再界定唯一修改目标。多参考图时明确每张职责、优先级、最终画面禁止出现重复主体。跨模型时参考任务类型与多参考角色（task-constraints.md）。

### C. 静帧转视频

从已定稿首帧抽静态锁定项：主体身份、服装、道具、场景结构、比例、光线方向、色彩。视频提示**只描述会变的内容**：动作、镜头、时间、声音、结尾画面。视频生成的「运动」层交 `taxue-photo-studio/sub-skills/moving-image`（只编运动、不改介质），本文件只提供视频模型的方言语法。默认单镜头；除非用户明确要剪辑，才增加可数转场与镜头数。

### D. Seedream 5.0 Pro → Seedance 2.0 关键帧链路

先用 Seedream 做视频前期的「视觉定稿层」：锁定人物/产品身份、服装或包装、构图、色板、光线、可读文字、关键道具。再把该静帧作为 Seedance 的 `@Image` 参考，只描述随时间变化的动作、运镜、声音、结尾。多场景视频为每个场景产同一角色与品牌约束下关键帧，每帧只改一个叙事变量。若视频结果的脸部/产品/版式漂移，回 Seedream 修正关键帧，不在视频 prompt 里堆静态细节。

## 四、方言转换纪律（与 taxue 硬约束对齐）

1. 色板 ≤4（geometric-monument 定稿模板例外 ≤5）、单一比例、留白预算、元素上限——随母版走，不因模型方言放宽
2. 文字纯净句用自然语言描述（DNA 第 7 条），不加「负面」标签
3. MECE 枚举是自检逻辑，禁止整段进 prompt 正文
4. 禁止把「踏雪审美 / 踏雪 DNA / 踏雪留白 / 踏雪化」等内部术语写进交付 prompt
5. 静帧 prompt 不混入时间轴与音效；视频 prompt 不漏主体、动作节拍、相机或声音
6. 参考素材必须明确分工；不加入未证实的参数或能力承诺
7. 有语义差异才写迁移差异，无差异写「无语义差异，仅改写为模型方言」

## 五、双层质量检查

1. **语义一致性**：所有版本的主体数量、主体身份、产品特征、核心动作、信息层级、画幅目标一致
2. **模型适配性**：静帧是否混入时间轴/音效；视频是否漏主体/节拍/相机/声音；参考素材是否分工；是否加入未证实参数或承诺

同一内容要图像与视频版本时，先给静帧母版，再给视频动态层；视频不得重新发明静帧的构图与色彩，除非用户明确要求改变。

## 六、输出协议（用户点名模型 / 要求跨模型一致时）

除非用户只要一条 prompt，按此顺序输出：

1. **模型建议**：首选 + 备选 + 选择依据；用户已指定则只说明采用的模型方言
2. **踏雪母版本**：一段精简自然语言，列出不可变视觉事实，不输出冗长技术参数
3. **[模型名] 可直接使用的 Prompt**：每个模型单独代码块，块内不写标题、解释、不被该模型支持的参数
4. **迁移差异**：一行简表，说明各版本相较母版新增/弱化/无法保留的内容
5. **下一轮单变量迭代**：一条短 prompt，只改一个可观察变量（光线/运镜速度/声音/背景密度）

## 七、任务快捷映射（与 scenario-pack / cover-constraints 对齐）

用户点名模型时优先给「该模型擅长任务」的最短路径：产品/版式/多参考融合 → Seedream 5.0 Pro 或 Nano Banana Pro；信息图/海报横幅 → Seedream 或 Grok Imagine Image 2.0；短视频、情绪表演 → Grok Imagine Video 1.5 或 Seedance 2.0；对话式编辑 → ChatGPT / Nano Banana 2。静态帧一律先走本库家族模板，方言层只转语法。
