# F4 治愈插画

**家族量化规格**：单色主调 + 同色系浅底；手绘线条；禁 3D、禁写实、禁多色；构图饱满不拥挤。

**风格卡片**：核心调性 = 温暖、安静日常、手作温度；视觉特征 = 单色主调、轻松手绘线、同色系浅底；经典结构 = 主体居中 + 少量装饰 + 温馨留白；禁忌 = 写实、多色、3D 渲染。

**变体索引**：

## G — 单色线描插画（原 G/K 合并）

**Best for**：窗台植物、茶具、花篮、小动物等安静日常。

```
温暖可爱的单色线描插画。主色限定为柔和桃色、暖橙或浅棕（三选一），背景为同色系极浅底。

手绘线条轻松但干净，场景多为窗台植物、茶具、花篮、小兔子、树下等安静日常。可加入少量装饰性小元素（小花、叶子、爱心）。

构图饱满但不拥挤，整体温馨、治愈、有手作温度。禁止写实、禁止多色、禁止3D渲染。

场景内容：[填入具体场景，从上方候选中挑一类或自定，但保持「安静日常」基调]
```

**量化**：主色 =1 种（三选一）；装饰元素 ≤3 类；禁多色。

## J — 动态趣味动物

**Best for**：夸张动态、轻微荒诞的动物。

```
有趣的动物插画。干净白色或极简背景。

动物呈现动态夸张姿态（奔跑、跳跃、肌肉感、惊讶表情），带有明确的动作线和运动感。细节丰富（龟壳纹理、毛发、爪子），但整体仍是插画而非照片。

表情或肢体带有轻微拟人化幽默，但不完全卡通化。

整体轻松、有活力、带一点荒诞趣味。禁止写实摄影感、禁止复杂背景、禁止多角色拥挤。

动物：[填入具体动物，一只即可]
```

**量化**：动物 =1 只；动作线 ≥1 条；禁照片感。

## R — 极简纸感线描猫

**Best for**：极致简约的猫线稿。

```
极简线描猫，单色黑色细线，在有细微纹理的米色/宣纸质感背景上。猫以最简轮廓表现（伸懒腰、蜷缩、坐姿等），几乎没有内部细节，只有干净流畅的线条。大量留白，安静、治愈、有手绘纸本感。

姿态：[从伸懒腰/蜷缩/坐姿中选一]
```

**量化**：线条 = 纯黑细线；内部细节 ≈0；留白 ≥60%。

## K — 儿童绘本手账（元提示词，主题唯一变量）

**Best for**：抽象概念（写作、投资、生活哲思等）的诗意可视化，儿童绘本/手账风，温暖治愈。

```
一张竖版手绘插画（横版视主题气质而定），儿童绘本与手账风格，温暖治愈。围绕主题词展开创作，将抽象概念转化为富有诗意与想象力的画面。画面主体以拟人化或象征化方式演绎主题，正在进行与主题相关的动作或互动，动作自然生动、有叙事感与情绪表达——主体只需遵守两条：动作正在发生，与主题构成互文，让观者读懂后心里轻轻「啊」一声。黑色细线轻松勾勒轮廓，线条保留手绘的粗细变化与断续感，彩色铅笔、水彩或蜡笔淡淡着色，铅笔的叠色颗粒与水彩的晕染边缘都值得保留，米白色粗糙水彩纸背景，纸张纤维与手工绘制痕迹清晰可见。着色克制，色板锁定四色以内：米白纸底之上，一个主色、一个次色、至多一处小面积点缀色，随主题气质推演；不强调写实光影，扁平着色即可，最多在主体底部带一层极浅的同色系铅笔投影，让它有落地感。构图简洁克制，主体位于画面中下区域，占画面高度约三成，留白占比过半，除主体外至多两三件小器物，每个细节都服务于主题表达。画面右侧竖排一行手写中文短句，毛笔或铅笔书写，自然松弛、略带童趣与手工感，字形不必工整，短句由主题推演一句；画面中除这一行字外不再出现任何其他文字、标点、水印或签名。整体气质温暖、安静、幽默、治愈，带有东方留白美学与绘本诗意。避免复杂背景、商业插画质感与过度精致：不要均匀矢量线条、完美对称构图、统一粗细笔刷、光滑渐变与塑料质感，也不要贴纸风描边和表情包化的五官。

用户输入内容：主题：[请在此填写]
```

**量化**：色板 = 米白底 + 主色 + 次色 + 点缀 ≤1（四色内，随主题推演）；留白 ≥50%；主体占画面 ~30%；器物 ≤3 件；短句 1 行竖排；避免清单全保留。

**槽位**：主题 = 唯一必填变量（写作/投资/生活哲思等）；竖版/横版、主体意象、动作、短句、主次色随主题推演。

## F4-RB — 橡皮章版画线稿（早期实践提炼）

**Best for**：小红书/日常场景的极简线稿，复古版画的刻痕与印刷质感。

**来源**：个人出图提炼（「极简线稿插画 小红书 风格质感：复古版画_橡皮章雕刻质感，类似油毡浮雕印刷效果」，4 张出图）。与 G（桃色手绘线描）、R（细线描猫）的区别：本变体的线条是**刻出来的**——橡皮章/油毡雕刻的刀痕感与印刷颗粒，不是手绘软线。

```
极简线稿插画，复古版画风格。线条如橡皮章或油毡雕刻后印刷的效果：刻痕边缘干净利落，笔画内有刻刀留下的顿挫与断点，留白处散布油墨未及的白点颗粒。主体[内容]，以线稿表现，不涂色或至多一处单色点缀（[色]）。纸面为米白手工纸，有印刷颗粒与压印的浅凹痕。构图简洁，主体[位置]，留白充足。整体复古、手工、温润粗粝，像一张刚从油毡板上印下来的版画。避免手绘软线的圆滑感、避免照片写实、避免过度精致。画面中除[指定文字]外不出现任何其他文字与标点，指定文字原样呈现不加标点，无任何水印、日期或签名。

用户输入内容：主体：[请在此填写]
```

**量化**：线条 = 刻痕感（刀痕顿挫 + 断点）；印刷颗粒 = 纸面必现；色 ≤2（线稿色 + 至多 1 点缀）；留白 ≥40%；主体 1 件；纸面 = 米白手工纸。

**槽位**：主体与单色点缀可换；小红书/日常/静物场景由主体推演。

**状态**：原始版已出图 4 张，提炼模板待本体系验证。
