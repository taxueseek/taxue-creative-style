# 模式三：元提示词创作管线

用户给任意需求（一句话到一段话），从零构建精确视觉指令。**核心：重新定义问题，不是直接翻译需求。**

**元提示词的正确形态（参数化，非固化）**：
- 元提示词 = 可复用模板：风格骨架固定一次，主题、主体意象、题字等为槽位，换主题只换槽位内容，风格段落一字不动。
- 输出必须含三件套：①带槽位的模板正文（保持自然语言）②槽位填法示例（≥3 个主题对照，说明主题→意象→题字如何联动）③替换规则（哪些段落一字不动、哪些联动更换、色彩等约束如何按主题微调）。
- 常见错误：把「当前主题的填充结果」当元提示词交付。用户说「这个我只要输一次即可」「以后换主题复用」= 要模板，只给固化主题版即不合格。
- 微调必须给理由：色彩等「建议锁定」的约束按主题调整时，说明微调原因，并提示保留原色板的替代选项。
- **变量最小化原则**：必填变量越少越好，主题作为唯一必填项是最高形态，主标题、副标题、主题色等由模型从主题自动推演，可留可选覆盖口，但默认不给用户填表负担。
- **用户输入区样式约定**：元提示词结尾保留「以下内容作为变量，每次可替换：」+ 变量列表（用户偏好样式），或更简的「主题：{主题}」单行 + 「用户输入内容：主题：[请在此填写]」；删掉用户的输入区会让模板失去入口感。

## 步骤 1：重定义需求（第一性原理）

用户说「画一张有夏天感觉的图」→ 不可直接出图。先把感受翻译成可执行要素：夏天感觉 = 什么场景（午后窗边）+ 什么光（斜射硬光）+ 什么色（低饱和暖黄绿）+ 什么质感（胶片颗粒）+ 什么情绪（慵懒）。

重定义追问清单（缺哪项问哪项，一次一个问题，优先从上下文推断，能推断就不问）：
1. 主体是什么？谁、在哪里、什么状态？
2. 情绪基调：静/动、暖/冷、庄/谐？
3. 媒介质感：水墨、纸、胶片、CG？
4. 观众感受：看完这张图希望对方感到什么？

## 步骤 2：七维填充（MECE 拆解）

任何影像 = 主体 × 构图 × 光影 × 色彩 × 质感 × 情绪 × 约束。逐维填实，每维至少一个可执行描述，不写抽象词（「高级感」不算描述）。（注：这是创作七维；与模式二诊断七维的「风格锚点/负向」不同，两套清单用途不同，勿混用。）

## 步骤 3：风格 DNA 决策

- 用户未指定风格 → 从 9 家族中按主题匹配（主 SKILL.md 主题默认映射），选定后完整套用该变体模板，把重定义出的要素填入槽位；**主题为「字/词/词组/短句的视觉化」或「高级概念海报」时，优先路由 F8-V8**（已验证模板）；**主题为「用户已有照片的艺术化」时，优先路由 F9-R1~R5**；**主题为「运动/速度感」时，优先路由 F7-H**；**主题为「抽象概念的诗意可视化 / 儿童绘本手账风」时，优先路由 F4-K**
- 用户指定了非本库风格 → 走 optimize-pipeline.md 对待（先诊断用户的风格描述再组合）
- 用户要求创新/混搭 → **混搭卡片机制**：明确「哪张家族卡片做内核（调性/概念深度）、哪张做外壳（视觉语言）、各自占比」，不得模糊混搭。范式：`内核 = 卡片的调性 + 外壳 = 卡片的视觉特征`。示例：F1 水墨调性（孤寂哲思）+ F2 海报外壳（极简几何+留白）= 水墨概念海报；F6 氛围调性（神秘电影感）+ F7 摄影外壳（胶片颗粒）= 电影感概念摄影
- **关系提取优先**：元提示词先定义「主题 → 核心关系」的转译，再画关系，不预写意象。踏雪寻仙的核心关系 = 寻→远方→不可及；鲸落 = 沉没→深海→归于寂静；白夜 = 永恒→循环→昼夜交界。关系决定叙事轴（视觉方向随主题情感推演），意象从关系派生，不从主题名硬编
- **概念海报双技法**：①字形级隐喻（笔画替换/字形同构/局部解构/正负形，词义做进字形）；②关系级叙事（字与图的空间关系承载词义）。两技法可单用可叠加，默认叠加
- **个人视觉系统定位**：本 skill 不是单风格生成器，是系统化视觉资产——家族卡片 + 修复块 + 色板 + 归档共同构成可复用的视觉系统，交付时提示词与成图一体（polished prompt + 图），不只是文本
- **枚举不进正文（MECE 枚举是自检逻辑，不是 prompt 内容）**：推演用的枚举清单（如五种空间叙事轴、六种情绪倾向）用于自检与设计侧推演，**禁止整段写进正文**。正文只留一句推演指令（如「核心关系与空间叙事方向由词义推演」），模型自会推演；枚举+括号塞进正文只会稀释注意力、制造噪音、导致崩坏。

## 步骤 4：量化锁定

出图前锁定：比例（prompt-craft.md 尺寸表）、色板（明确色名+占比）、留白预算（若有）、元素数量上限、负向清单（≥3 项）。凡画面含指定文字，正文以自然语言写明文字纯净句（主 SKILL.md DNA 第 7 条）。色板用 HEX 色值锁定消除歧义（prompt-craft.md 参考色板）。六词检查口诀：风格、主体、动作、环境、构图、参数，六维说清再出图。

## 步骤 5：出图（imagegen-routing.md）→ 自检（prompt-craft.md）→ 记录（memory-protocol.md）。

**保持独到影像风格的三道闸**：
1. 拒绝直译：符号性需求（画龙舟、画月饼）必须转译为情感本质（F2-B 的「主题的东西不直接画」逻辑）
2. 留白强制：浅底/纸底家族（F1/F2/F4/F5 浅底变体/F8/F9）按各自家族规格的留白下限写进提示词；无留白规格的深底或满构图变体（F3-O、F5-L、F5-M3、F6-D）改写为等价的负空间与呼吸感描述，禁止向这类模板注入留白百分比
3. 色彩预算：任何图 ≤4 色，写明确色名不写「多彩」「丰富」；唯一例外 = geometric-monument-poster.md 定稿模板（基座同色系层级需 ≤5 色），其余一律 ≤4
