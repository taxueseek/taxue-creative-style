# 踏雪风格体系分类（Taxonomy · 对外介绍版）

> 用途：对外介绍、README、分享、评审时的体系总览与分类口径。内部路由与执行规则以 SKILL.md 为准。
> 设计原则：**旧编号资产不动**（F1–F9 的 61 个代号仍是稳定接口）；**家族数量开放**（现 14 家族 77 变体）。科学性由「独立视觉语法 + 五变量 + 主题路由」承担，不是靠锁死 9 个抽屉。

## 一、一句话定位

踏雪风格引擎 = 一套风格化影像创作系统：把任意主题编译成可执行视觉指令。资产是已固化的风格卡，按视觉语法独立注册；组合靠五变量语法；治理靠台账与检查器。

公开分享口径（@TaXue2025，2026-08-16）：风格来自多年出图与提示词归纳，不是凭空分类；当时写「九个家族、47 种变化，距离 72 种还有一段」。本地现已到 **14 家族 / 77 变体**（72 达成后继续按场面语法扩展人物卡）。77 不是新的天花板。

## 二、五层是治理视角，不是产品边界

| 层 | 名称 | 内容 | 对外一句话 |
|---|------|------|-----------|
| ① | 资产层 | 开放注册的风格卡（现 14×77） | 「已经固化、能直接套的风格底牌」 |
| ② | 组合层 | 母题 / 技法包 / 批量架构 / 人物场面，不占变体号 | 「风格之外的母题、技法、系列纪律」 |
| ③ | 方法层 | 三条管线 + 封装自检 | 「出图、优化、从零写提示词」 |
| ④ | 治理层 | 台账 + 偏好 + 检查器 | 「每张卡有档案，漂移会被脚本抓住」 |
| ⑤ | 生态层 | 子技能 | 「大主题有专门工作台」 |

用户问「有哪些风格」时，按独立语法回答（剪纸、皮影、釉面、档案、美术片……），不回答「第几层」。

## 三、资产层：表现族是归类，家族是索引

划分依据仍是「画面用什么语言生成」。F10–F14 补的是原来被塞进 F2/F5/子技能的独立语法。

| 表现族 | 家族 | 变体数 | 归类理由 |
|-------|------|-------|---------|
| **笔绘绘画族** | F1 / F4 / F5 | 16+5+15 = **36** | 手绘笔触与工艺绘画 |
| **平面设计族** | F2 / F6 / F8 | 11+2+1 = **14** | 文字即设计、留白、丝网 |
| **摄影影像族** | F7 | **8** | 镜头语言 |
| **微缩立体族** | F3 | **3** | 纸雕、层叠、等距 |
| **照片转换通道** | F9 | **5** | 任务型：照片输入 |
| **剪纸纸艺** | F10 | **2** | 剪、镂、套染、窗花透光 |
| **皮影偶戏** | F11 | **2** | 灯屏关节 / 实体木偶 |
| **釉面器物** | F12 | **2** | 釉与器物组字 |
| **纸本档案** | F13 | **2** | 物证装帧 / 即时成像 |
| **美术片媒介** | F14 | **3** | 年画 / 折纸 / 赛璐璐原创 |

F5 里的剪纸旧卡（M2/M3/M4/DC）与 F10 并存：旧号不搬，新任务点名染色/窗花走 F10。F5-M1 是剪纸+皮影混卡，点名皮影走 F11-PY。

## 四、五变量风格语法

**风格 = 媒介 × 构图 × 色板 × 情绪 × 工艺约束**。每张风格卡是这个空间上的一个已采样点。两个模板不能共用禁忌 → 不是同一家族（判定见 style-independence.md）。

## 五、轴标签

| 轴 | 回答的问题 | 取值（家族级，含新族） |
|---|-----------|----------------------|
| 媒介 | 用什么做 | 笔墨、绘本、工艺绘画、平面、摄影、微缩、照片输入、剪纸、灯屏/木偶、釉、档案装帧、美术片 |
| 题材 | 画什么 | 人物/猫、日常、仕女生肖、文字概念、城市、器物、节气物证、戏文、任意照片 |
| 情绪 | 什么感觉 | 孤寂、克制、治愈、古典、城市诗意、电影感、现场、物证余温、戏台仪式 |
| 任务 | 从哪到哪 | 从零创作、照片转换、档案记录、批量系列 |

## 六、对外介绍口径

**30 秒版**：踏雪是风格化影像引擎。风格按制作语言独立注册，不锁在九个抽屉里。现有 77 张已固化模板，覆盖笔绘、海报、摄影、微缩、剪纸、皮影、釉面、档案和美术片；人物场面可跨家族复用；用五变量语法组句；三条流水线出图、改提示词、从零写。每张模板有台账。

**措辞纪律**：对外称「已固化模板」。不把内部 ✅/⚠️/🔶 写进对外话术。不说「只有九个家族」。

## 七、与内部路由

内部仍走 SKILL.md：模式 → 子技能 → theme-router → 家族文件按段读。表现族是介绍骨架，不是路由层级。新增家族：先过 style-independence.md 四问，再三处同步，最后跑 consistency-check.py。
