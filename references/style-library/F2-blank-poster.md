# F2 留白海报

**家族量化规格**：留白 ≥50%；浅色纸底；文字极简（主标题 ≤6 字）；禁写实描绘、禁符号堆砌。

## B — 极简概念杂志海报

**Best for**：节日（端午、中秋等）、节气、抽象主题。

```
一张[主题]的高级杂志风格插画，细节极简，概念性视觉叙事，杂志级品质，干净的矢量渲染，大量留白，纯白或极浅背景。

必须彻底跳出传统节日/主题海报框架，不要直接画符号、卡通、红金喜庆、祥云边框、祝福模板。

核心表达：[提炼主题的安静情感本质，填法见模板外槽位说明]。不需要任何完整的场景，只去捕捉那些平时不被注意的瞬间。主题的东西不直接画。

色彩以雾白、苔绿、水蓝、浅灰为主，少量深墨绿或单一强调色压住画面。质感上保留轻微印刷感和纸张质地，避免过度光滑。

文字极简，中文主标题仅一个词或极短短语。

整体安静、克制、有呼吸感。

画面中除主标题外不出现任何其他文字与标点，主标题原样呈现不加标点，无任何水印、日期、签名。
```

**量化**：主色板 雾白/苔绿/水蓝/浅灰；强调色 ≤1 种；标题 ≤6 字；两个槽位（主题、核心表达）必填。

**槽位填法**：核心表达 = 提炼主题的安静情感本质（示例：端午节 →「从喧闹中慢下来，重新找回呼吸和节奏」）；示例只用于引导填槽，不进入交付正文。

## E — 文化概念海报

**Best for**：传统文化主题的现代化诠释（天坛、青花瓷、故宫、书法等）。

```
[主题]的现代概念海报。大量留白或极简背景。

用几何层叠、半透明色块、或流动书法笔触重新诠释主题，而非写实描绘。保留纸张质感与印刷感。

色彩高度克制，只使用与主题文化关联的两三种颜色，并让其中一种成为主色。

中文标题与短句干净排版，与画面形成呼应。整体高级、安静、有文化厚度但不复古堆砌。

画面中除中文标题与短句外不出现任何其他文字与标点，中文标题与短句原样呈现不加标点，无任何水印、日期、签名。
```

**说明**：色彩选择在模板外决定后填入——如天坛用朱红与米白层叠，青花瓷用蓝白晕染，写死在模板里会导致每次出图泄漏示例。填法：把「两三种颜色」替换为具体色名。

**量化**：色彩 2-3 种；标题 ≤8 字；禁写实。

## F — 纯书法字海报

**Best for**：单字或短语的视觉力量。

```
纯文字海报。大面积留白。

以极具力量感的毛笔书法作为绝对主体（一个字或两个字），笔触有飞白、顿挫与墨色变化。可在字内或字旁融入极小的剪影人物或物件，形成互文。

底部极短一行小字说明或诗句。右下角可放极小红色印章。

整体干净、有力、现代书法海报感。禁止多余装饰与复杂背景。

画面中除主体书法字与底部一行小字外不出现任何其他文字与标点，主体书法字与底部一行小字原样呈现不加标点，无任何水印、日期、签名。
```

**量化**：主体 1-2 字；留白 ≥60%；印章 ≤1 枚且极小。

## H — 招聘 / 人生隐喻海报

**Best for**：职业、面试、简历、人生阶段概念。

```
概念招聘/人生隐喻海报。大面积留白。

用书法大字或极简图形表达核心概念，并在字内或旁边融入小巧的剪影人物，形成幽默或深刻的互文。

底部一行极短诗意说明。整体干净、有设计感、带一点黑色幽默或人生洞察。

画面中除核心概念大字与底部一行说明外不出现任何其他文字与标点，核心概念大字与底部一行说明原样呈现不加标点，无任何水印、日期、签名。
```

**量化**：核心概念 2-4 字；剪影人物 ≤1 个；说明 ≤15 字。

**槽位填法**：核心概念与底部说明必填（示例「面试」「简历」与「人把自己折进一张纸里」只用于设计推演，不写进交付正文）。

## I — 隐喻物件海报

**Best for**：抽象人生概念（简历、财富自由、提示词、机会、时间等）。高度概念化的产品级海报。

```
高端概念海报。大面积干净米白或浅米色纸质背景，带轻微纸张纹理。

主体为一个高度写实、工作室灯光质感的物件，作为核心隐喻。

巨大的中文标题优雅地叠加或半透明覆盖在物件上，字体现代而有力。

底部1–3行极短的诗意说明文字，字号小、颜色低对比。

整体像高端杂志广告或概念设计作品：克制、有深度、视觉冲击力强但不喧闹。禁止复杂场景、禁止多余装饰、禁止卡通化。

画面中除主标题与底部说明外不出现任何其他文字与标点，主标题与底部说明原样呈现不加标点，无任何水印、日期、签名。

隐喻物件：[填入一件具体物件，并在模板外先对齐「物件→概念」的映射，填法：物件+其代表的抽象概念。示例（只用于对齐映射，不进入正文）：一堆红砖=人生经历；一叠旧纸=浓缩的自我；断开的铁链与金色钥匙=自由；VGA线缆=连接与提示词]
```

**量化**：主体物件 =1 件；标题 ≤6 字；说明 ≤3 行；色彩 ≤3 种。

## F2-K — 国潮书法连字海报 ⚠️ 实验

**Best for**：春节贺图、品牌主视觉、生肖/节日海报。

```
一幅极简主义国潮书法海报，画面中央是一个巨大的"福"字与奔马形态的完美连字融合（ligature）。采用上美影80年代水墨动画的焦墨枯笔质感，墨色由浓黑渐变至赭石棕，在米白撒金宣纸上呈现。背景大面积留白，仅在右下角点缀一枚朱砂印章"丙午"或"马上有福"小字。构图取法汉代瓦当的圆形或唐代碑刻的方正，现代排版中融入轻微噪点纹理与微距纸张纤维感。无装饰纹样，无渐变填充，纯以线条的粗细变化与墨色干湿表现力量与祥瑞，整体氛围既有金石篆刻的庄重，又有当代平面设计的干净利落。
```

**量化**：留白 ≥60%；印章 ≤1 枚且极小；噪点轻微（伪精度禁令：不写 3%）；禁渐变填充、禁装饰纹样。
**槽位**：连字内容（福×生肖可换）、印章文字（如「丙午」「马上有福」）。
**状态**：实验变体，点名才用，不进默认路由；出图验证后回填。

## AB — 混合现实手绘信息图 ⚠️ 实验

**Best for**：知识图解、个人年报、概念说明。

```
极简主义混合现实信息图。背景为纯净无纹理的白色纸面，所有信息以二维手绘与三维实物对比呈现：主题元素用手绘墨线或水彩薄涂绘制（线条轻松有手绘感），关键数据点用极小三维实物替代（一枚印章、一颗纸团、一片枯叶、一截铅笔头），二维与三维并置形成强烈质感对比。信息层级以留白与细线分割，标题区预留纯白空间。整体克制、干净、有手工温度，无透视场景，无多余装饰。
```

**量化**：纯白纸底；三维实物 ≤3 件且极小；手绘元素 ≤4 类；留白 ≥50%；禁渐变背景、禁透视场景。
**槽位**：主题内容、三维实物清单。
**状态**：实验变体，点名才用，不进默认路由；出图验证后回填。

## F2-OP — 欧普线描（Op Art Line，早期实践提炼）✅ 已验证

**Best for**：瑞兽/符号/动物的线构成肖像，纯黑白光学艺术的秩序与张力。

**来源**：个人出图提炼（欧普线描貔貅 4 张出图）+ 本地归档欧普貔貅 V1→V2 迭代记录（用户手改 diff：机制性描述 > 效果性描述、删冗余、补「无阴影、无噪点」）。

```
欧普艺术风格，严格的二维平面构成，竖版画幅，纯正面平视视角。背景为极致纯黑色，主体为巨大白色细密水平波浪线条构成的[主体]形象，[局部特写]。线条在画面空白区保持绝对平行规整，仅在[主体]的[头部/脊背/转折处]产生轴向偏移与密度堆叠，以此构建轮廓。波浪仅限单线自身波形，线条之间保持平行排布。线条是纯装饰性图形元素，非毛发、无立体起伏。画面呈现纯黑白配色、极致明暗对比，无杂色、无渐变、无阴影、无噪点。纯正矢量图形质感，线条边缘切角锐利、衔接顺滑，画面秩序井然、科技感强烈。
```

**量化**：色板 = 纯黑白；线条 = 空白区绝对平行 + 关键结构处轴向偏移/密度堆叠；禁毛发丝质感、禁立体浮雕、禁渐变阴影噪点；轮廓由线条密度差构建；默认竖版 2:3。

**槽位**：主体（貔貅/龙虾/瑞兽/符号）与其关键结构（头部/脊背/转折）可换；保持「线条纯装饰、非毛发」铁律。

**状态**：✅ 用户已迭代 V1→V2 并出图（archive 记录），可进默认路由。

**防翻车提示**：最常见的失败是线条画成毛发丝或立体浮雕——锁定句必须保留「线条是纯装饰性图形元素，非毛发、无立体起伏」。
