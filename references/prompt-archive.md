# 提示词版本归档

> 由 taxue-creative-style §4「版本归档」维护。每次交付追加一条，作为可学习、可归档、可复盘的资产库。
> 归档让提示词从「一次性输出」变成「可迭代资产」：交付前查档案，同主题/同风格历史版本直接参考。
> 本文件是**本地学习文件**，安装后由 skill 在本机自动追加记录，不参与仓库更新。

## 记录格式

每次提示词交付（优化或创作）后，按下列格式追加一条：

```
## [主题] 版本 [Vn]（[日期]）
- 来源：[用户原始提示词 / 优化 / 创作]
- 原比例：[如 4:3] → 建议比例：[如 2:3] + 理由
- 七维诊断：[主体 5 / 风格 5 / 构图 4 / 光影 N/A / 色彩 5 / 质感 5 / 负向 4]
- 交付版本：[完整提示词]
- 变更说明：[逐条]
- 用户反馈 / 手改 diff：[待补 / 记录]
- 复盘结论：[这版哪些有效、下次同类提示词保留什么]
```

## 复盘方法（归档后必做）

1. 每次交付后，下轮交付前，查本文件同主题/同风格历史版本
2. 对比相邻版本 diff，提炼「哪类描述被用户保留、哪类被删改」
3. 方向性结论（如机制性 > 效果性）写入 SKILL.md §4 正/负反馈清单，并标注「来自手改 diff」或「来自出图反馈」
4. 被验证有效的锁定句并入 SKILL.md §8.11 对应风格修复块，形成资产复用闭环
