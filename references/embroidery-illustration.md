# 刺绣 · 混合媒介参考技法

参考模板（同 beast-myth / geometric-monument：不占变体号，不改变体计数；模式二/三可按需引用）。本文件收纳三类独到技法：**彩锦绣肖像**、**苏绣肖像**（二者合为「刺绣系列」）、**实景 × 2D 涂鸦混合媒介**。核心原则：介质优先声明、丝线/纸面用语言而非素材贴图、保留对象身份。

## 一、彩锦绣肖像（纯粹彩色织锦）

**第一性原理**：彩锦绣不是「画的像绣」，而是「以彩色织锦语言重构对象」——用色块、针脚、纹样表现体积与光影，而不是逐根写实毛发。重装饰、重色块、重节奏感。

```
创作一幅[南通彩锦绣]风格的[主体：宠物/人物]肖像绣稿：1:1 方构图，主体是一只[主体特征，如：表情骄傲又有点憨的橘猫]的胸像或近景头像，居中占画面约 60-70%。

在结构上仍然写实：五官与骨骼比例准确，[毛发/发丝]走向贴合头骨和身体体积，保留真实立体感与光影；用单一主光源塑造明暗过渡，让眼眶、鼻梁、下巴有清晰体积。

在表现语言上采用[彩锦绣]美学：色彩高饱和、多层次，类似「彩色织锦 + 现代装饰画」结合，整体偏明亮华丽；[毛发]不再逐根写实，而是被概括为有方向性的彩色绣纹色块，用成片短针、曲线针和细碎色块拼接，形成有节奏的「锦纹感」；轮廓线清晰，局部可略微夸张和装饰化，但不能变成卡通。

为[主体]设计一圈「锦地 + 纹样背景」：背景为[深色或中性色]大色面绣地（如墨蓝、绛红、深墨绿），其上用细线绣出浅金或对比色的传统纹样（云纹、回纹、团花、几何锦纹等），形成有秩序的重复图案，让画面有强烈装饰性边框感与织锦气息。纹样密度从画面边缘向中心逐渐减弱，避免抢夺[主体]。

整体针法与质感：呈现[彩锦绣]大幅作品的质感——大块平整色面 + 多层叠色 + 局部细密排针；线材为高光丝线，色彩丰富，近看有明显针脚方向与丝线反光，远看像一幅华丽的彩锦织绣；眼睛与鼻子参考苏绣仿真绣的精度，用更细密的排针和更多色阶过渡形成焦点。

气质：像一幅可挂在客厅或展厅的[主体类型]肖像壁画，融合真实神态 + 东方织锦式华丽，既有写实肖像感，又有强烈装饰艺术感。超高分辨率，便于放大输出、转换为真实彩锦绣打样。
画面中除[指定文字]外不出现任何其他文字与标点，[指定文字]原样呈现不加标点，无任何水印、日期、签名。
```

**量化**：1:1 方构图；主体居中占 60-70%；写实骨架 + 彩锦绣色块语言；锦地 + 纹样背景（云纹/回纹/团花/几何锦纹）；纹样密度边缘密中心疏；高光丝线高饱和；眼睛鼻子更细密；禁卡通化、禁逐根写实。
**与 F5 家族分工**：F5-AE 是「仿真绣」写实工艺重点；本彩锦绣是「色块化、抽象化」的织锦语言，重装饰节奏，二者互补。F5-AF 彩锦绣偏绣稿落笔，本技法偏肖像成品。

## 二、苏绣肖像（绣在布上的当代人像）

**第一性原理**：看起来「像绣在绸缎上的画」，而不是照片或插画——光影靠丝线明暗变化塑体，而非摄影打光；整幅以刺绣语言构成，禁止「插画 + 一点绣花贴图」。

```
创作一幅方形构图的当代[人物：女性/男性]半身肖像插画，整体效果仿佛一幅绣在细腻绸缎上的苏绣艺术作品，适合作为书籍封面或音乐专辑封面。

画面中央是一位[人物]的胸像，三分之二侧面或略微偏正面角度，神情平静、内敛，带有思考感和文艺气质，而不是甜美卖萌的表情。

风格（苏绣本质）：整幅都呈现刺绣质感——[头发、眉眼、皮肤、衣领、背景装饰]都由一根根细密丝线构成，而非笔触或像素；能清晰看到丝线走向、针脚长短与叠压关系。光影不是摄影棚打光，而是靠丝线明暗变化塑体：线在转折处细微高光，暗部用更密更深色丝线叠绣，亮部用更稀疏更浅色丝线表现，形成柔和细腻的立体感。[头发/眉毛]由更细更深色丝线一缕缕绣出，发丝方向清晰但不过度写实，带一点工艺化装饰感。

色彩与情绪：整体低饱和、温润克制——[皮肤]由米色、浅粉、极淡赭色丝线多层叠绣，过渡柔和，无夸张高光强对比；背景衣物用藕粉、月白、浅灰、淡金、雾蓝等雅致配色，让人物温柔浮现。局部在衣领边缘或背景一角，用少量更饱和丝线点缀一两处颜色（一朵红梅、一片翠竹叶）作为视觉焦点，面积小、形状简洁，不喧宾夺主。

人物与构图：五官清晰不过度夸张，眼神柔和、轻微抿嘴，表情带若有所思。发型服饰可略东方气质（简单盘发、齐肩直发、中式领口或极简现代服饰），以绣线表现布料褶皱。方构图，上方预留空间、下方略留白，适合后期排版标题文字；人物不贴边，整体像一幅挂在墙上的绣品，而非自拍。

绣面细节：底布为淡米色或极淡暖灰色绸缎，带细腻布纹与轻微光泽；可在肩部、背景一角加极简花鸟山水绣纹（一支梅花、一片竹叶、一只小鸟、几笔抽象山峦）。不画绣框和边缘装饰，只通过布料纹理、针脚细节和丝线光泽让观者意识到这是「绣在布上的画」。

强约束：完全避免照片写实感和油画笔触，禁止摄影景深、镜头光斑、纸纹水彩、油画肌理；不要滤镜质感、不要美颜自拍、不要「插画+一点绣花贴图」；高分辨率、细节丰富，可放大看每一缕丝线针脚，适合印刷级封面。
画面中除[指定文字]外不出现任何其他文字与标点，[指定文字]原样呈现不加标点，无任何水印、日期、签名。
```

**量化**：方构图；三分之二侧面或略偏正面；丝线明暗塑体；低饱和温润配色 + 局部一点饱和点缀；底布绸缎纹理；禁止照片感/油画/美颜/贴图；可放大看丝线；适合印刷封面。
**优化点**（相对原稿）：把「不是油画/照片/插画」的否定表述改成「综合刺绣语言构成」的正面声明（遵守 prompt-craft 负向纪律：正向优先）；把「背景植物和装饰」收敛为「极简花鸟山水」；删除多版本并存，收敛为单一可执行版。

## 三、实景 × 2D 涂鸦混合媒介

**第一性原理**：把真实照片与 2D 插画元素融合，**核心不改变人物身份**——人脸、皮肤、身体保持完全写实，2D 涂鸦作为叠加层表达主题氛围。适用于把普通照片做出话题感、风格化封面。

保留人物的脸、皮肤、身体完全写实，不改变身份。根据照片的氛围、穿着与光线确定一个视觉主题，再选一种 2D 技法叠加：

1. **能量光环（适合干净背景或动态姿态）**：在人物身后与周围生成一团混乱但平衡的涂鸦「云」，元素从肩后探出或重叠在衣服/包上，但绝不遮脸。内容随主题变化——酷/前卫用箭头、闪电、涂鸦标签、故障色块、抽象街头怪物；可爱/甜美用卡通角色、爱心、星星、糖果、星光、圆润有机形；空灵用流动线条、花瓣、天体、魔法漩涡。扁平 2D 矢量、粗轮廓、贴纸感、鲜艳配色。
2. **超现实守护兽（适合城市/风景背景）**：在背景层加一只巨大的梦物化实体，悬于天空或负空间，与场景互动。设计契合氛围的实体：巨型睡猫、云鲸、几何精灵、流动花魔像、复古科技机器人。风格选霓虹壁画（平涂色）或白色凝胶笔（发光线稿），置于真实物体之后，尊重纵深。
3. **2D 转化（适合特色服装）**：把真实世界变成混合次元——人物头部和手保持真实，把衣服/配饰（夹克、裤子、鞋、包、手机）改绘为扁平插画。简化褶皱为干净粗卡通线，给衣饰加动感线、光泽点、漫画式阴影笔触。高对比赛璐璐风格或矢量波普艺术。

**量化**：身份写实不改变（人脸/皮肤/身体）；三种技法三选一；涂鸦不遮脸；主题与照片氛围匹配；扁平 2D 粗轮廓贴纸感；二维化只改衣饰不改头脸。
**优化点**（相对原稿）：原稿是英文 Role/Task 单图专用，本库改写为普适中文口诀 + 三技法三选一，使其对任意照片可用；明确「绝不遮脸」「只改衣饰不改头脸」两条硬约束防翻车。
**边界**：本技法偏好写实照片输入（F9 照片转艺术更泛指风格化），此处特指「身份保留 + 2D 涂鸦叠加」。若用户要整幅纯插画而非混合，走对应 F 家族，不用本段。

## 交付纪律

1. **介质优先**：三技法开头都先声明「是什么媒介的作品」（彩锦绣织锦 / 苏绣绸缎 / 实景×涂鸦叠加），防模型漂移到油画/照片/插画。
2. **材质用语言不用贴图**：丝线、针脚、布纹、涂鸦叠层都要写成可执行的视觉描述，禁止「绣花贴图」式的表面效果。
3. **身份保留铁律**：涂鸦混合媒介必须保留人物身份（脸/皮肤/身体），只改衣饰或加叠加层；刺绣系列保留对象神态特征。
4. **负向克制 + 正向优先**：能不写「不要 X」就不写；确需禁的（卡通化、照片感、油画感）用一句正面声明收口。
5. **不新增变体号**：本文件是参考模板，供模式二/三引用，不改 61 变体计数与三处同步。
6. **与 F 家族分工**：刺绣系列与 F5-AE/F5-AF 互补（本技法侧重肖像成品 / 色块语言，F5 侧重绣稿/工艺落笔）；涂鸦混合媒介与 F9 照片转艺术区分（本技法须保留实际照片身份）。
