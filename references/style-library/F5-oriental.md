## F5-AE — 仿真绣苏绣（写实工艺） 🔶

**Best for**：人物/宠物/生物肖像的刺绣工艺化，藏品级质感，博物馆展品气质。

**与 M 系剪纸分工**：M 系是「剪/雕」路线，AE 是「绣」路线——用针脚与丝线模拟照片光影，写实仿真；底布、针法、丝光是固定语法，主体槽可换人物/宠物/生物。

```
创作一幅 {画幅} 的仿真绣{主体类型}肖像：{主体描述}，居中占画面约 70%，五官清秀、比例接近真实人像，整体观感接近高质量人像照片，但放大后所有明暗、细节和边缘都由刺绣针脚和丝线排布构成，是一件写实仿真绣作品。技法核心为仿真绣+乱针绣：先用较粗丝线稀针铺底打大明暗，再逐层减少线股数，用更细的劈丝线密针做细与加色造型，五官、高光、暗部叠加多层乱针，明暗过渡自然柔和；针脚长短不一、方向交错，但局部始终顺着结构（鼻梁、面颊、下巴的体积方向）运行。丝线用高光泽桑蚕丝，符合苏绣「平、齐、细、密、和、光、顺、匀」；肤色与五官用三四种以上同类色线套绣叠色，有微妙色温变化与血色感；眼睛、眉毛、嘴唇用更细劈丝线与更高密度针脚，边缘柔和。多层乱针叠加使鼻梁、颧骨、额头等高点半浮起，能察觉绣线层层堆叠而非平面贴图；丝线有强烈丝绸光泽，随针脚方向形成细长高光带，不同色线叠加处发生光学混合，远看肤色如柔雾晕染，近看能分辨多种色线交织。底布为高等级白色真丝绸，接近纯白偏暖，背景几乎完全留白，只允许极淡云纹或真丝暗纹，不添加图案，背景始终扮演「安静的布面」。光线为博物馆展陈光：柔和顶光保证绣面光顺匀称，一侧温和侧光强化绣线凸起与方向，中性略偏暖。作品定位为仿真绣作品的高清记录而非油画或数码插画：禁止油画笔触、水彩纸纹、数码画笔颗粒、摄影式景深虚化、镜头光斑、HDR 炫光；构图极简，不加入耳环、夸张头饰、大面积服饰花纹。针脚与丝线纹理的细节密度极高，放大后每一针都清晰可辨。
```

**量化**：比例 {画幅} 默认 1:1；主体占画面约 70%；底布 = 白色真丝绸；光 = 博物馆顶光+侧光；同类色叠绣 ≥3 种；硬约束 = 禁油画笔触/水彩颗粒/景深/光斑/HDR；针脚细节高密度必现。

**槽位**：{主体类型}（人物/宠物/生物可替换）、{主体描述}（填「谁 + 神态 + 特征」）、{画幅}（1:1 默认，竖幅改 3:4）。
