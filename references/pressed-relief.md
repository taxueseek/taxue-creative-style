# 压印凹凸技法包（钢印 / 按压）

参考模板（同 visual-deception / embroidery-illustration：不占变体号，不改变体计数；模式二/三点名「凹凸 / 钢印 / 按压 / 压印」时引用）。高度场不是制作媒介，点名才用。

**第一性原理**：凹凸成立，当且仅当槽、形体与承印面是同一块材料，明暗只来自高度差。默认阴底阳纹：板面被压出浅槽（凹），主题形体落在槽底、相对槽底微微隆起（凸）。一盏掠射硬光贴着板面扫过：槽壁迎光剩一条窄亮边，槽底比平面暗，形体迎光外坡一条窄亮边。写高度与光，不写「立体感 / 浮雕滤镜 / 冲击力满满」。与 F2-JS、F2-3D、F2-OP 分工：JS 管平面印泥，3D 管字站起来的厚度与层间空隙，OP 禁立体起伏，本包管承印面上的压印高度场。

## 钢印压进

**Best for**：徽章、契约、纪念章底板、金属铭牌、封面主视觉要「被砸进去」的那一下。主题被翻译成「一件形体连着浅槽压进一块板」。

**机制**：钢模已经离开。板面留下一个浅槽，槽底托着主题形体，形体相对槽底微微隆起。槽沿被挤开一圈浅棱，浅棱外一两道散开的环形压痕。光只做一件事——把凹和凸一起读出来。

```
一张 1:1 方形的微距静物。主题决定压在承印面上的那件形体，也决定这块板是什么材料。画面是一块完整的承印面，正中被压出一个浅槽，主题的核心形体落在槽底，相对槽底微微隆起，槽、形体和板面连成同一块材料。槽沿有一圈被挤开的浅棱，浅棱之外有一两道渐渐散开的环形压痕，像力还留在材料里。只有一盏斜上方的掠射硬光贴着板面扫过：槽壁迎光的一面剩一条窄亮边，槽底比未压的平面暗，形体迎光的外坡一条窄亮边，背光根部贴着接触阴影。形体、浅棱和板面共用同一套固有色，明暗只来自高度差。承印物从主题最硬的材料里推演，全图不超过三种色相，可在槽底留一丝同色系更深的氧化。印面居中约占六成，四周露出未被压到的平面。纯正面平视微距，焦平面贴在印迹上。画面中不出现任何文字与标点，无水印、日期、签名。槽压在板里，形体不离开槽底。

用户输入内容：主题：[请在此填写]
```

**量化**：1:1 方图；印面居中约 60%；光源 = 1 盏掠射硬光；色相 ≤3；形体与板同色系；环形压痕 ≤2 道。
**锁定句**：槽压进承印面，形体落在槽底不悬空。一盏掠射硬光，槽壁迎光一条窄亮边。
**出图前确认**：形体是板的一部分，不是坐在板上的物件；浅槽可见；亮边在迎光槽壁与形体迎光外坡；接触阴影贴着根部。

### 槽位填法（示例不进正文）

| 主题 | 压进形体 | 承印物 | 色板角色 |
|------|----------|--------|----------|
| 貔貅 | 俯身貔貅，头与脊的轮廓进槽 | 冷黄铜板 | 铜 #C4A35A，高光 #EDE0C0，槽底氧化 #5C4A28 |
| 契约 | 一枚掌印，掌心最深 | 厚卡纸 | 纸米 #E8DCC8，压实处 #C4B49A，一丝墨褐 #6B5344 |
| 杠杆 | 一根细杆压进中点，两端微微翘 | 拉丝钢 | 钢灰 #8A9096，高光 #D8DCE0，槽底 #4A4E52 |

### 替换规则

- **一字不动**：微距静物、浅槽、形体落在槽底、与板面连成一块、一盏掠射硬光、窄亮边、接触阴影贴根部、同色系、无字、≤3 色相、1:1
- **联动推演**：槽底形体、承印物、固有色 HEX、槽底氧化深浅
- **覆盖口**：用户可写死形体或材料，不填则由主题推演。用户点名「全阴 / 阴文」时，形体一并压进槽底，不再隆起。用户点名「全阳 / 浮雕」时，去掉浅槽，形体从平面顶起，浅棱改成形体根部一圈沉陷，其余不动
- **比例**：正文锁 1:1。竖幅铭牌把首句「1:1 方形」换成「3:4 竖版」，印面仍居中约六成，其余不动

## 交付纪律

1. 不占变体号。计数以 verification-ledger 为准，本包不进 77 变体。
2. 主题唯一必填。其余由主题推演，可选覆盖，不填则推演。禁用「缺省」。
3. 出图前把承印物固有色、高光、槽底三枚 HEX 写实，禁止套水墨五色。
4. 一次出图。仅 blocker（高度场没了 / 形体离板 / 禁忌）允许一次定向修；主观分不够不重生。同一 blocker 修一次仍失败即停（prompt-craft.md）。
