# 模式二：提示词优化管线

用户拿来任意提示词（不限本库风格）要求优化时执行。**先诊断再改，禁止无依据重写。**

## 步骤 1：七维诊断（量化打分）

对原提示词逐维打分（0-5 分），5 分 = 该维信息完整且无歧义：

| 维度 | 打分依据 | 分数锚点示例 |
|------|---------|------------|
| 主体 | 主体是什么、特征是否具体、槽位是否可替换 | 5 = 主体+特征+姿态全具体；3 = 只有主体名；1 = 主体都含糊 |
| 风格锚点 | 有无媒介/流派/风格词，判定有无证据链，专名（画师/IP/导演）是否准入 | 5 = 媒介+流派明确且每个风格判定都能指出画面/主题证据；专名 ≤1 且有独立锚点证据；3 = 只一个风格词，或专名无证据支撑；1 = 风格词互相矛盾或专名 ≥2 堆砌 |
| 构图 | 视角、比例、布局、主体位置、景别是否自洽 | 5 = 比例+位置+留白都说清且景别唯一；3 = 只说视角；1 = 无任何构图信息，或景别/比例自相矛盾 |
| 光影 | 光源方向、光质、明暗结构 | 5 = 光源+光质+明暗全有；3 = 只一个光质词；1 = 无光影；**平面/矢量类标 N/A，不适用，不得触发补全** |
| 色彩 | 色板是否明确、有无占比约束 | 5 = 色名+占比锁定；3 = 只给色名；1 = 只说「彩色」 |
| 质感 | 纸张/胶片/CG/材质细节 | 5 = 材质+工艺细节具体；3 = 一个质感词；1 = 无质感描述 |
| 负向 | 禁止项是否精准克制，只针对该风格真实跑偏点 | 5 = 2-5 项，每项都对应该风格真实跑偏风险，正文已有特征未列入，能正向化的已正向化；3 = 有禁止项但零散、过宽或与正文特征重叠；1 = 无负向，或堆砌通用否定词表 |

**打分纪律**：
- 每维必标 N/A 或 0-5 分，禁止留空
- **N/A = 该维度对该风格物理不适用**（平面/矢量类无光影），标 N/A 的维度不进入修复规则，不得补光影
- 0-5 分必须有锚点支撑，禁止凭感觉打中间分（2/4 分须在变更说明里写理由）
- 打分结果写入交付的变更说明开头，让分数可复核

## 步骤 1.5：矛盾扫描（Cross-Check Gate）

**为什么必须有这道闸**：七维诊断按维度打分，而矛盾是跨元素的**关系属性**，按维度打分天然发现不了。历史漏检案例（马长角、水墨×丙烯并列、粗黑描边×细线勾勒）全部是「单维看着都对、跨元素互斥」的类型。用户提供的提示词常是半成品或从其他提示词改写而来，改写过程会残留旧主体词、旧媒介词、旧负向，必须显式扫描。**本步在七维诊断后、修复规则前强制执行，逐类勾掉才算过。**

**矛盾类型学（MECE 十二类，自检用，禁止写进 prompt 正文）**：

| 类型 | 判定 | 严重度基准示例 |
|------|------|--------------|
| 媒介互斥 | 两个物理逻辑相反的媒介词同时出现在媒介位置 | 水墨×丙烯（渗化 vs 覆盖）、油画×水彩、照片×插画 |
| 主体矛盾 | 物种/物体与特征互斥；主题词与修饰词互斥 | 马长角、牛带翅、金属雕像着布衣 |
| 工艺互斥 | 技法描述互相否定 | 粗黑描边×单线勾勒、哑光×高光、平面×体积光 |
| 色彩超载 | 正向段色名 >4 且无主次约束 | 红绿黄蓝橙青紫七色并列 |
| 正负互斥 | 正向指定与负向禁止冲突 | 正向要 logo/签名，负向无差别禁一切文字 |
| 时空冲突 | 时代/环境元素互相否定 | 古代水墨题款×现代霓虹灯 |
| 景别互斥 | 取景范围自相矛盾，同一主体同时占两个互斥景别 | 特写×全身、半身×全身、近景×远景并列；「中近景全身」「半身全身」这类复合词必翻 |
| 比例多处冲突 | 正文不同位置出现两个及以上不同画幅比例 | 构图段写 3:4、比例行写 16:9；同一 prompt 内比例必须唯一 |
| 专名堆砌/冲突 | 画师/IP/导演名 ≥2 并列，或专名与可见特征冲突 | 宫崎骏×新海诚并列；指定「新海诚」但主体是水墨写意（专名与媒介锚点冲突） |
| 方向/位置矛盾 | 朝向与构图/留白互相否定 | 头朝右但负空间全在右侧 |
| 比例/用途冲突 | 比例与使用场景不匹配 | 横 5:2 配竖版海报用途 |
| 来源痕迹残留 | 改写来源的旧元素未清理 | 负向防「写实牛照片」但主体是马；方向词、媒介词与当前主体不一致 |

**分级与处置**：
- **严重（不修必翻车，直接改好）**：媒介互斥、主体矛盾、工艺互斥、色彩超载、正负互斥、来源痕迹残留（旧主体词）。直接改写为自洽表述，变更说明中单列「矛盾修复」条目，逐条说明改了什么、为什么。
- **轻微（保留原句，指出风险）**：方向细节含混、措辞可二解（如「淡淡笔触」）、不影响主体识别的来源残留。原句不动，在变更说明「风险提示」区给出一行可选修复句，让用户自己决定。

**两条豁免（修复矛盾优先于常规规则）**：
1. 「4-5 分维度不动」在维度内出现严重矛盾时不适用，该维度允许动刀
2. 「原句保留率」达标线不适用于矛盾修复句，机械核对时矛盾修复句标「矛盾修复」类，不计入改词率

**来源痕迹检查（半成品/改写来源必查）**：
- 负向段是否残留旧主体防翻车词（如「防牛」对应旧主体牛？）
- 方向词、位置词是否与当前主体姿态一致
- 媒介词全文是否唯一：开头锚点句、中间媒介句、负向段三处核对
- 主体特征词与主题名词逐词对照（马×角、马×鹿角、人×四条腿）

## 步骤 2：修复规则（按分处理）

- 0-1 分维度：必须补全，从上下文推断或向用户追问（一次只问一个问题）；**已标 N/A 的维度跳过，这是规则例外，不是缺分**
- **档位与一步到位的裁决**：改动档位（打磨/补全/重构）决定改动授权范围，一步到位原则在授权范围内执行——打磨微调档只修必改处（含严重矛盾），不因缺维而越档补全；结构化补全档才允许全维补齐。两条规则不冲突，越档即违反原句优先
- **一步到位原则（本 skill 的验收标准）**：所有能从上下文或主题推断的维度，一次补全到位，禁止留到下一轮再问。只有真正多义、推断会错的方向才向用户追问（一次只问一个问题）。交付即终版：用户拿到的提示词应是可直接出图的高质量成品，不是「改完还需再调」的中间件
- 2-3 分维度：补具体化，把抽象词换成可执行描述（如「好看」→ 具体光质与色板）
- 4-5 分维度：不动，避免过度修改；**维度内出现严重矛盾时（见步骤 1.5）例外，允许动刀**
- 冲突处置：步骤 1.5 关卡命中的严重矛盾直接修复并单列「矛盾修复」条目，轻微矛盾保留并写入风险提示
- 补全优先引用「缺维修复块资产表」（本文件末尾），不现场拼装（查表 → 套块 → 按主题微调）

**专名准入（风格锚点维的修复规则，先于补全执行）**：提示词中的画师/IP/导演/作品名属于高风险词——模型对专名有自己的平均化想象，两个专名并列时各自拉扯必然风格漂移。本规则按三层证据链执行（吸收自 image-reverse 的证据链纪律，用本库语言重写）：

**第一层：先证据后风格名**。每个风格判定先列出可观察证据（笔触形态/色彩结构/阴影层数/边缘处理），再给风格名称；证据不足时只写可观察特征，不下风格结论。风格判定是条件组合不是感觉——例：判「平涂/赛璐璐」需闭合轮廓+平面固有色+1-2 层硬边阴影同时成立；局部腮红/高光不改变判定。

**第二层：专名准入**。反推/引用画师/IP/导演名时，需至少 3 项独立锚点证据（发型轮廓/脸部或眼部结构/标志性服装配色/专属道具/可识别场景），且最多保留 1 个专名、只表达「画风相似」；锚点不足或与可见特征冲突 → 删专名，改写为可观察风格特征，禁止编造归属。处置：
- ≥2 个专名并列 → 保留证据最强的一个，其余替换为可观察风格特征（笔触/色彩结构/构图语言）
- 单个专名但与媒介锚点冲突（如专名是动画导演、媒介是水墨写意）→ 删专名，保留媒介与可观察特征
- 专名只表达「画风相似」，不写「某某的作品」；用户明确要求某专名且知其含义时尊重用户，但在变更说明标注漂移风险
- 判定证据不足时，用三个以内可观察特征替代专名

**第三层：情绪仅从面部推导**。人物情绪只能从可观察面部证据推导（眉形/眼睑压力/视线方向/嘴角与唇部状态）；服装、道具、场景、色调不得单独推出情绪标签（红唇夜场不等于妩媚，暗调不等于忧郁）；推导不出时写「情绪未明确」而不是猜。本层在优化含人物情绪描述的提示词时使用，防止无依据渲染情绪。

## 步骤 3：注入踏雪 DNA（可选，默认轻度）

按原提示词气质决定注入强度：只加不违背原意图的踏雪原则（留白、克制、纸感、概念性）。凡涉及指定文字的提示词，以自然语言补一句「画面中除[指定文字]外不出现任何其他文字与标点，[指定文字]原样呈现不加标点，无任何水印、日期、签名」，不加「负面」标签。用户明确说「别加踏雪风格」则跳过此步。原词明确要胶印/专色/Riso/单色双色印刷封面时，改走 `taxue-poster-studio` 印刷模式，不在本管线补印版字段。

## 步骤 4：输出

**输出纪律（优化 ≠ 重写，三条硬规则）**：
1. **语言形态守恒（含标点与可执行性）**：优化版必须保持用户原提示词的语言形态与行文风格。自然语言提示词就输出自然语言，分节格式才输出分节格式，禁止把自然语言重构为模板分节格式（【基底】【笔墨】式）。标点同样守恒：不得新增原文没有的破折号（——）、冒号、分号等结构性标点；任何新增标点视同改动，必须写进变更说明。可执行性同样守恒：禁止把「踏雪审美 / 踏雪 DNA / 踏雪留白 / 踏雪纸感 / 踏雪化」等内部术语原样写进 prompt；色板必须按所选风格展开为具体 HEX，不套单一水墨色板。
2. **原句优先**：能改词不改句，能补句不改段；用户原句保留率按档位达标（打磨微调 ≥90%、结构化补全 ≥80%，见下方机械核对），每处修改在变更说明中对应该维度的诊断分。
3. **参数化只在用户要求时做**：只有用户表达「元提示词」「模板」「换主题复用」等意图时才输出带槽位版本；固化单一主题的提示词不是元提示词。输出元提示词必须附槽位填法示例与替换规则（见 create-pipeline.md）。

**改动程度选择（优化前先定档，默认最小档）**：用户说「优化」有三种实际需求，按原文质量与用户语气判断：
1. 打磨微调：原文结构完整、质量高 → 只改必改处，原文保留 ≥90%，每处改动都要能说出「不改会翻车」的理由
2. 结构化补全：原文有明显缺维（色彩/光影/负向/比例缺失）→ 保持样式，按七维诊断补缺，一次补全到位
3. 重构：仅限用户明确要求（「改成元提示词」「更精炼」「重新设计」）→ 输出前先确认新形态
拿不准时选更小的档位，宁可少改不可多改。

**输出前五查（改完、交付前逐项核对）**：
0. 矛盾扫描：步骤 1.5 关卡已执行，十二类逐类勾掉，输出含矛盾扫描结果
1. 形态守恒 + 标点守恒 + 可执行性：原文是自然语言就输出自然语言，无【】标签、无编号清单化；优化版不新增原文没有的破折号（——）等结构性标点；不出现「踏雪审美 / 踏雪 DNA / 踏雪化」等内部黑话，色板按风格写具体 HEX
2. 改动量匹配：改动量符合所选档位，无未经要求的增删
3. 变量最小化：元提示词必填变量 ≤2 个，主题唯一必填为最高形态，其余由模型推演
4. 比喻具象化：抽象关系（连接/承托/对比）是否已用可画出的比喻锁定（如「方尖碑投影」），无比喻则补一个，优先于补参数
5. 比例建议：是否按 prompt-craft.md 的比例判断规则给出「建议比例 + 理由」——**缺比例建议 = 交付不完整**

**交付前机械核对（逐句过一遍，防「优化变重写」）**：
- 把优化版与原提示词逐句对照，每句标注四类之一：**原句**（一字未动）/ **改词**（句内换词）/ **补句**（新增整句）/ **新句**（重排或改写）
- 标点逐句对照：优化版新增的破折号、冒号、分号逐一删除或改回原句式，确需保留的在变更说明里逐条记录理由
- 可执行性逐词对照：prompt 中出现「踏雪审美 / 踏雪 DNA / 踏雪留白 / 踏雪纸感 / 踏雪化」等内部黑话，或色板只写“踏雪色板”未展开具体 HEX → 返回重写
- 原句保留率 = 原句字数 ÷ 原文总字数，目标按档位：打磨微调 ≥90%，结构化补全 ≥80%，重构不限
- 保留率不达标 → 回到原句优先原则重改，不得交付
- 变更说明必须逐条对应上述标注，禁止「优化了整体表达」这类无依据说明

```
优化版提示词：
[完整可执行提示词]

建议比例：（不可省略，必须给出）
[保留原比例 / 原 4:3 → 建议 2:3 等 + 一句理由]（见 prompt-craft.md 比例判断规则）

矛盾扫描结果：
- 严重修复：[n] 处（类型：媒介互斥/主体矛盾/…，详见变更说明「矛盾修复」条目）
- 轻微保留：[n] 处（类型：…，见变更说明风险提示）
- 通过：[未命中类型逐一列出]

变更说明：
1. [改了哪里]：[为什么，对应哪个诊断分]
2. ...
- 矛盾修复：
1. [改了什么]：[类型，为什么直接改而非保留]
- 风险提示：
1. [保留的轻微矛盾]：[可选的修复句]
```

**交付完整性检查（每项缺一即交付不完整，禁止交付）**：
1. ✅ 优化版提示词（完整可执行）
2. ✅ 建议比例（含理由）
3. ✅ 变更说明（逐条对应诊断分）
4. ✅ 矛盾扫描结果（十二类勾选 + 严重已修复 + 轻微已指出）
5. ✅ 归档 + 偏好双写（按 memory-protocol.md）
6. ✅ 出图验证待办（按 imagegen-routing.md，除非用户只要文本）

## 步骤 5：出图验证（imagegen-routing.md），除非用户只要文本。同时按 memory-protocol.md 写版本归档。

## 缺维修复块资产表（步骤 2 的补全来源）

**用法**：七维诊断发现 0-1 分维度后，查本表找该风格的修复块，整块补进锁定句；只补缺的维度，不重复已有维度。块内【主体】按主题替换。

| 风格类 | 常缺维度 | 修复块（直接补入） |
|--------|---------|------------------|
| 书法 / 水墨 | 色彩、质感 | 宣纸米白底 #F5F0E8，纯墨色 #2C2C2C，墨色浓淡自然分层，飞白枯润笔触 |
| 书法 / 水墨 | 负向 | 保持纯水墨质感，拒绝彩色、油画厚涂、照片写实、立体渲染、多余细节与装饰 |
| 欧普 / 几何 / 平面 | 光影（标 N/A）、线条纪律 | 线条是纯装饰性图形元素，仅在塑造【主体】轮廓处扭曲变形，其余区域保持规整平行排列 |
| 欧普 / 几何 / 平面 | 色彩、负向 | 极致纯黑白配色，无杂色、无渐变、无光影立体效果 |
| 矢量 / 平面商业 | 质感 | 纯正矢量图形质感，线条衔接精致顺滑、细节干净利落 |
