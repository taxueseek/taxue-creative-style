# F3 城市建筑

**家族量化规格**：横构图；纸感或纸雕材质；禁人物近景、禁车流霓虹；城市要素 2-4 个。

**风格卡片**：核心调性 = 城市气质、天气互动、秩序；视觉特征 = 水墨几何体块、纸雕层次、柔和斜光；经典结构 = 微缩模型居中 + 天气墨色 + 上方城市名；禁忌 = 人物近景、车流霓虹、复杂细节。

**变体索引**：

| 变体 | 名称 | 状态 |
|------|------|------|
| C | 现代水墨城市天气卡 | 默认 |
| O | 多层纸雕世界 | 默认 |
| F3-LC | 层叠微缩城市（签名吸纳） | 默认 |

## C — 现代水墨城市天气卡

**Best for**：城市名、城市纪念海报。

```
现代极简多彩水墨城市插画，4:3 横构图，宣纸质感，45° 俯视等距微缩模型。

城市：[城市名]
地标：[交付前由 agent 查实写入 2–4 个具体地标或典型天际线，写出名称与总数]，抽象为水墨几何体和楼群体块，组合成一块居中的城市微缩模型。用淡墨、枯笔、飞白勾勒体块与轮廓，不画窗户、广告牌、车流等具体细节。

天气：[交付前由 agent 查实写入的具体天气]，用水墨方式表达：用墨色干湿、浓淡与晕染形状表现效果，让天气与城市轻柔互动。背景保持纯纸白，大量留白。

用墨色深浅模拟柔和斜射光照，形成体积感。画面上方留出留白，用极简墨字写中文城市名称。

禁止人物、车辆、霓虹、UI 和夸张 CG 特效。整体安静、克制、信息清晰，像一张现代水墨城市天气卡片。

画面中除城市名称外不出现任何其他文字与标点，城市名称原样呈现不加标点，无任何水印、日期、签名。
```

**量化**：地标 2-4 个；留白 ≥40%；标题 = 城市名 2-4 字。

**槽位填法**：城市名、地标、天气三个槽必填。地标由 agent 查实后写具体名称与总数（示例：重庆 →「洪崖洞、解放碑、长江大桥，一共三块」），天气写查实结果（如「雨雾」「晴空」）；示例只用于引导填槽，不进入交付正文。禁止把「自动识别地标 / 自动选择天气」原样交给生图模型（prompt-craft.md 锁定句纪律）。

## O — 多层纸雕世界

**Best for**：宏大场景、城市与山水融合、世界观构建。

```
一幅由多层纸片构成的世界场景，所有建筑、山峦、云朵与人物都像被精细裁剪后逐层叠放。
城市高楼与中国传统山林、殿堂共处同一空间秩序中，没有冲突，像同一文明的不同表达。
画面以朱红、米白、墨绿和少量鎏金为主色，每一层纸都有清晰的厚度与柔和阴影，空间深度来自层层堆叠而非夸张透视。
光线温和而均匀，立体纸雕作品，整体庄重、盛大，但节制克制。
人物很小，只作为尺度参照，世界本身是主角。
```

**量化**：色板 朱红/米白/墨绿 + 鎏金点缀；纸层 ≥3 层；人物占画面 ≤3%。

## F3-LC — 层叠微缩城市

**Best for**：单个城市的视觉名片、旅行纪念、城市系列创作。3D 立体层叠纸雕 × 中国城市地标 × 书法题字——把一座城市压缩进一个有呼吸感的立体盒子里。

**与 C/O 分工**：C 是水墨平面微缩+天气互动；O 是纸雕大场景世界观；LC 是多层景深空间+地标符号化+书法落款的城市卡。

**来源**：签名风格库 S2 吸纳（豆包出图验证 2026-08-16，样图 gallery/f3-lc-layered-city.jpg）。

**模式**：LC-1 经典层叠城市卡（默认，横 4:3）/ LC-2 水墨层叠（竖 3:4 立轴感）/ LC-3 夜景层叠（16:9 宽银幕）。

**LC-1 经典层叠城市卡（默认）**：

```
一幅[城市名]的多层色纸城市卡，4:3 横构图。四层哑光色纸前后叠放，层间有空隙和柔和投影，侧面可见纸的厚度。最前一层是[前景元素]剪影，只占画面下部一条。中层只放[地标清单]，一共[数量]块，每个地标只保留最标志性的外轮廓，抽象成纸片几何体，不画窗户、广告牌、车流。后层是[山脊或天际线]淡剪影，[次色]薄染。层间弥漫极淡[氛围色]。色彩只有[主色]、[次色]、[氛围色]、墨四色，低饱和。右下角落款只写[城市名]二字，极小行楷，可附一枚米粒大朱砂印。画面中除[城市名]外不出现任何其他文字与标点。禁止写实全景、超过四个地标、人物车辆、霓虹。
```

**LC-2 水墨层叠城市**：

```
一幅水墨质感的 3D 层叠微缩城市景观。
【整体结构】
3-4 层前后层叠的纸雕层，每层材质为水墨渲染的宣纸，层间有柔和投影形成景深。
【水墨质感】
所有层都以水墨晕染为基底，墨色有浓淡干湿变化，地标轮廓以毛笔线条勾勒，边缘有自然的墨色晕开，不是锐利的矢量切割。层与层之间的雾气以淡墨渲染，如水墨画中的留白。
【地标】
[城市名]的 2-3 个地标以水墨微缩形式呈现，只保留最标志性的轮廓，墨色为主，可有一处极淡的[强调色：如朱砂/赭石/石青]点染。
【书法】
画面一角竖排题写[城市名]，毛笔行楷，墨色浓黑，旁可附极小朱砂印章。
【色彩】
墨色为绝对主导（≥80%），仅允许一处强调色点染，其余全为墨色浓淡与宣纸底色。
【气质】
比经典层叠更东方、更写意、更空寂。城市如同从水墨里浮出来的梦境，层叠的景深让水墨画有了立体的呼吸。
【禁止】
高饱和色彩、写实细节、锐利边缘、车流人群、多余文字。
```

**LC-3 夜景层叠城市**：

```
一幅夜景氛围的 3D 层叠微缩城市景观。
【整体结构】
4-5 层前后层叠，深色背景，每层地标以[发光材质：如霓虹边缘/内部透光/金属反光]呈现，层间有雾气和光影。
【光影】
主光源来自地标内部或边缘，[主光色：如暖金/冷蓝]的光从层叠缝隙中透出，在深色背景中形成温暖的光点。层与层之间的投影在夜色中更明显，景深强烈。
【地标】
[城市名]的 2-3 个地标以微缩模型形式呈现，夜间灯光点亮，窗户透出暖光，轮廓边缘有光晕。
【色彩】
深色背景（墨黑/深蓝）+ 1-2 种发光色 + 少量暖光窗户色，总色彩 ≤4 种。
【书法】
画面一角以细笔题写[城市名]，如同夜景中的签名。
【气质】
城市在夜色中如同一座发光的沙盘，层叠的景深让夜景有了可以探入的纵深感。克制的发光色在深色背景中格外温暖。
【禁止】
多彩霓虹、车流人群、过曝、写实照片感、多余文字。
```

**量化**：层数 3-5；地标 2-4 个；前景元素 1 个；题字 ≤1 处 + 印章 ≤1 枚；色彩 ≤4 种（水墨版墨色 ≥80%）；留白 ≥15%（水墨版 ≥20%）；默认 4:3 横幅（水墨版 3:4 竖幅，夜景版 16:9）。

**平台兼容性**：即梦 5.0 实测不适用（2026-08-18 用户实测，出图效果不符合本风格）；使用即梦时请改用其他变体或家族（如 F3-C 水墨微缩、F3-O 纸雕大场景），其他平台不受影响。出提示词时务必向用户提示此点。

**槽位**：城市名（必填）；地标清单（必填，出图前由 agent 查实 2-4 个最具辨识度地标，禁止让模型自动识别）；层数（默认 4）；材质（默认哑光纸雕，可半透明亚克力/金属蚀刻）；主色/次色/氛围色（按城市气质推演：江南→青灰+米白+晨雾白；山城→赭石+墨绿+暮色橙；古都→朱红+金棕+烟灰）；题字位置（默认右下角）。

**城市地标速查（出图前查实，禁止让模型自动识别）**：北京：故宫角楼、天坛、长城、鸟巢；上海：东方明珠、外滩建筑群、豫园、陆家嘴天际线；重庆：洪崖洞、解放碑、长江大桥、穿楼轻轨；成都：宽窄巷子、武侯祠、大熊猫、太古里；杭州：西湖三潭印月、雷峰塔、断桥、灵隐寺；苏州：园林假山、虎丘塔、平江路、苏州博物馆；西安：大雁塔、钟楼、城墙、兵马俑；南京：中山陵、夫子庙、明城墙、总统府；武汉：黄鹤楼、长江大桥、武汉大学、江汉关；广州：广州塔、陈家祠、骑楼、五羊雕塑；深圳：平安金融中心、市民中心、世界之窗、大梅沙；厦门：鼓浪屿、日光岩、南普陀寺、环岛路。

**出图锁定句**：四层色纸叠起来，层间有空隙；地标是纸片几何轮廓，不画窗户；只有[具体地标名]，一共[数量]块；字只能是[城市名]。
