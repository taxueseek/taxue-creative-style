# 出图工程：封装 · 词库 · 尺寸 · 自检

出图前读本文件：封装规则（第一部分）、关键词库、HEX 色板、比例决策、质量自检。

**读取指引（速度优先，按需读）**：
- **出图 / 模式一**：只读「一、出图封装」+「三、尺寸适配」+「四、质量自检」
- **模式二 / 三创作**：额外读「二、提效关键词库」（补缺维/HEX 色板/方法论）
- 禁止通读本文件后凭记忆套用，按需取段。

## 一、出图封装（不改模板原文）

风格模板是审美资产。填槽后**原文进 prompt**，禁止改写、禁止压缩成短句、禁止把模板之外的量化百分比或规格数字追加进封装（模板原文里已有的量化表述照用，不自作主张另写数字）。

借鉴成熟封装原则：用户给了详述就原文照用；前置主体；一次只改一处；规格留在自检、不进 prompt；约束改成可画的形态。

**组装优先级裁决（多层方法论量叠加时）**：封装三段（前置一句+模板原文+锁定句）是唯一交付结构；文生图四要素、FLUX 五段、封面五维是设计期的构思工具，产出物最终落回封装三段，禁止把四要素/五段的结构标签写进交付正文。

封装结构：

```
[前置一句] 主体 + 姿态 + 媒介，必须是画面里最重要的那件事。
[模板原文] 填完槽的变体模板，一字不改。
[锁定 2–3 句] 只写该变体最容易翻车、且能画出来的事。正向描述。禁止再堆「不要/禁止」清单。
```

锁定句从变体量化规格**翻译**，不抄数字：
- 「墨 95% + 留白 ≥50%」→「画面几乎全是墨与素纸，器物只占一角」
- 「五官豆点」→「头的轮廓还在，脸上只留针尖大小的两个墨点，没有眉、鼻、嘴」。「豆大」会画成黑球，禁用
- 「标题不加标点」→「画面上的字只能是财富自由四个字，没有引号和任何标点」
- 「地标 2–4 个」→ 出图前由 agent 查实并写进锁定句（如「洪崖洞、解放碑、长江大桥，一共三块」），禁止把「自动识别」甩给模型；F3-C 模板原文中的「自动识别地标 / 自动选择天气」同样必须在填槽时替换为查实结果后才能交付
- 封面约束档开启时：锁定句加「画面一个字都没有；主体避开上四分之一与下五分之一」

指定文字：前置句和锁定句都写死精确字符。题字以外的器物表面保持空白（卷轴、招牌、书页不另生字）。

中文必须精确可读（标题 / 数据 / 多行文案）且不属于书法变体（F1-A / F2-F / F2-H / F2-K）时：不要指望模型写对，走封面约束档（cover-constraints.md），文字后期叠加。

## 二、提效关键词库（单词语技巧）

**第一性原理**：生图质量差的根因是信息缺失，不是词不够多。一个词应补一个信息维度（光源、镜头、构图、质感、情绪），低信号词（8k、best quality、masterpiece）在现代模型下基本无效。规则：先七维诊断找出最弱维度，只在该维度加一个词，出图对比后再加下一个。

词库不进默认 prompt。只在七维诊断找出最弱维、且模板原文没覆盖时，往锁定句加**一个**正向词。通用光/镜头/构图词见各宿主通用生图规范，此处只留踏雪常用锚点：晨雾漫射、飞白、宣纸、negative space、paper texture、candid。

### 使用规则

1. 一次只加一个维度的词，出图对比后再加下一个
2. 画面发平先补光源（柔光 / 侧逆光 / 晨雾漫射），不是加 8k
3. 镜头/光源参数用英文术语，东方美学用中文，同一维度不混用
4. 情绪词（孤独/温暖/静谧）可重复一次强化
5. 约束写进锁定句，用可画的正向形态，禁止再堆 `no text / no watermark` 否定清单

### 中文标点权重法

中文提示词用标点分配权重：【重点内容】模型优先执行；（）可选内容；「」禁止内容。示例：「生成海报，【主体是墨色山水】（可加朱砂印章）「不要金色元宝」」。与主 SKILL.md DNA 第 7 条文字纯净句配合使用。

### HEX 色值锁定

色名有歧义（「墨黑」「青花蓝」各家模型理解不同），关键色用 HEX 色值锁定。**没有单一“踏雪参考色板”**：踏雪是兼容并蓄的系统，不同家族/场景有各自色板，必须按所选家族量化色板选色。水墨/东方系常用锚点（不是全库唯一）：墨黑 #2C2C2C、宣纸白 #F5F0E8、朱砂红 #C3272B、青花蓝 #4A5F7F、松石绿 #7C9D96。其他家族例如：治愈系常用桃色/暖橙/浅棕，城市系常用朱红/米白/墨绿/鎏金，写实摄影用自然胶片色，概念海报 ≤4 色由主题推演。用法：先定家族，再写该家族的具体 HEX，如水墨主色为墨黑 #2C2C2C。

### 负向纪律（全家族统一口径，取代旧版「推荐负向清单」用法）

负向不是词表堆砌，是针对该变体最可能真实跑偏的 2-5 个风险点：
- **正向优先**：能写成可画正向描述的不用否定（「背景保持素净」优于「不要复杂背景」）；锁定句已在封装层执行这条，负向清单只收无法正向化的硬禁区
- **原图/原文已有特征禁列**：变体本身要求的质感（纸感、颗粒、飞白）列入负向属自相矛盾，与矛盾扫描「正负互斥」同罪
- **无风险写明无**：某变体无真实跑偏风险时写「无额外负向约束」，禁止照抄通用否定词表、无谓堆砌
- F1 水墨系常见真实跑偏点（按图取 2-5，不是全量照抄）：彩色渗入、油画厚涂笔触、立体渲染、动漫五官、多余印章文字；F2 海报系：写实照片化、元素超件、字体乱码；F7 写实系：插画化、塑料感皮肤、HDR 过度
- 与 optimize-pipeline 负向维、create-pipeline 负向克制原则同一口径，三处同步维护

### 文生图四要素公式（源自「符号化自然语言公式」文生图转译）

创作骨架：`【媒介与画风】呈现【主体+环境】，处于【视角与构图】，营造【光影与氛围】`
- 媒介与画风 = 这是一张什么图（材质）：35mm 胶片/国家地理/拍立得/印象派/赛博朋克/皮克斯 3D/水墨
- 主体+环境 = 画什么（视觉中心）：要具体，「穿西装在蓝光机房里敲键盘」而非「工作」
- 视角与构图 = 谁在看（镜头位置）：广角给上帝看、微距给恋人看、低角度显高大、俯拍显渺小
- 光影与氛围 = 是什么感觉：丁达尔效应（神圣）、霓虹（迷幻）、柔和漫射（温馨）、高对比黑白（压抑）
与七维诊断（诊断用）互补：四要素是创作骨架（生成用），七维是检查清单（验证用）。

### FLUX 创意三法（源自 FLUX 提示词设计师）

灵感枯竭时用三个固定机制：
1. **跨领域联想**：从 3 个不相关领域抽取元素（建筑+生物+音乐 → 弦结构的生物城市）
2. **时空变换**：在不同时代/空间重塑主题（未来主义维多利亚时代）
3. **矛盾统一**：融合矛盾元素（温暖的冰雕、柔软的金属）

### FLUX 模块化五段（提示词组装顺序）

核心描述（主题+风格+关键特征）→ 环境设定（时间+地点+氛围）→ 技术规格（分辨率+渲染+特效）→ 艺术参考（艺术家+作品+流派）→ 情感诉求（情绪+象征+观者体验）。缺哪段补哪段，不重排已有内容。

### 封面五维决策（源自 baoyu-cover-image 工作流）

出封面时先锁五维再写提示词：
- **Type**：封面类型（文章头图/公众号/小红书/概念海报）
- **Palette**：调色板（主题色/背景色/强调色，受情绪档调节）
- **Rendering**：渲染质感（线条/纹理/深度/元素风格）
- **Mood**：情绪三档——subtle（低对比低饱和）/ balanced（中对比中饱和）/ bold（高对比高饱和）
- **Font + 文字层级**：none（无字）/ title-only / title-subtitle / text-rich（标题+副题+标签）
与 cover-constraints.md 配合：五维先定方向，安全三硬规则（后期叠加/安全边距/明度差）管底线。

### 色彩行为（源自早期色彩方法论实践）

色彩描述用「行为 + 饱和度」双约束：
- **色彩行为**：主色调主导，辅以极柔和的第二色点缀（而非罗列色名）
- **饱和度**：中高饱和度，柔化处理，绝不刺眼或浑浊
- **环境表现规则**：环境以克制的墨色、干净的留白和可控的晕染象征性表现主题——绝不追求字面意义的写实
用法：把「多彩」「丰富」替换为「主色调主导 + 极柔第二色点缀 + 中高饱和柔化」一句，信息密度高于三个颜色词。

### 概念压缩（源自前沿极简主义提示词设计师方法论）

- **风格**：用一个或三个以内的名人/名作概括繁杂的风格描述（如「吴冠中的线条」替代三段笔法描述）
- **具象化**：用某个或三个以内的事物替代一堆描述（如「像压扁的方尖碑投影」）
- **金句**：一句话总结画面的行为模式，写进锁定句
与「关系具象化比喻」互补：比喻锁定抽象关系，概念压缩压缩风格与细节。

### 关系具象化比喻（自然语言提示词的灵魂技法）

自然语言提示词优于参数说明书的关键：抽象关系（连接、承托、对比、悬置）用可画出的比喻锁定，一个精准比喻胜过三条参数约束。范式：「符号与基座的整体形态如同一尊被压扁的方尖碑投影，符号是碑顶，色块是碑身层叠的阴影」（纪念碑定稿，见 geometric-monument-poster.md）；「如同抽象纪念碑基座，而非具象建筑」（初版）；「像在掂量另一端的重量」（绘本投资版）。规则：比喻必须可画（视觉意象）且与主题语义一致，禁止比喻堆砌，一段一个足矣。

### 量化精度边界（伪精度禁令）

量化必须是生图模型可执行的粗略层级：区域占比、总色数、元素数量、层数范围。像素级精度（中轴容差 ≤1.5% 画面宽度、相邻层明度差 12-25%）生图模型没有执行通道，写了等于没写，还挤占预算稀释注意力，一律禁止。可执行量化锚点参考：约一半/50%、≤4 色（geometric-monument 定稿模板例外 ≤5）、3-6 层、元素 ≤4 件。

### 参数可执行性分级（L1 / L2 / L3，区分「能直接写」与「只写效果」）

写摄影/技术参数前先分级，避免把模型看不懂或一写就翻车的词塞进 prompt。吸收 photo-studio 的参数可执行性分级，用本库语言重写：

| 级 | 参数类别 | 写法 |
|---|---|---|
| **L1 直接写** | 焦段、光圈、快门效果档、光质与方向、景深档 | 直接写数字或档位（等效 85mm 微距、f/2.8 浅景深、侧逆硬光、f/1.2–f/2.2 浅景深、f/11+ 全景深） |
| **L2 写效果词** | ISO、白平衡、手机计算摄影、色温 | 只写效果（高噪点颗粒、偏暖、HDR 过度、高光溢出），不写具体数值（ISO 3200、色温 3200K） |
| **L3 禁止写** | 机身型号、镜头品牌、传感器尺寸、像素数、精确曝光组合 | 一律禁止。品牌色彩科学名（如富士绿、柯达暖黄）转成可观察的对比度/明暗/过渡描述 |

**纪律**：L1 参数写进锁定句；L2 只写触发效果，不写数值——模型对「ISO 3200」没有执行通道，对「高光溢出、暗部发灰」有；L3 是伪精度（模型无法感知机身与传感器），写了只挤占预算并显得不专业。分不清级别时往下降一级（宁可写效果，不写数值）。

## 三、尺寸适配（比例 × 构图 × 提示词）

**原理**：比例的差别是空间分配逻辑的差别。同一主题换比例不是改一个数字，是改构图。提示词必须明确「主体放哪、留白留哪、文字区在哪」。

| 比例 | 用途 | 构图逻辑 | 提示词必须写的 |
|------|------|---------|---------------|
| 9:16 | 手机壁纸、短视频封面 | 竖向纵深，主体上部 1/3，下方留白 | 主体位于画面上 1/3 处，下方大面积留白 |
| 2:3 | 竖幅摄影、立轴画、印刷海报 | 纵向三段：上方题字、中部主体、下方留白 | 主体位于画面中部偏上，上方留出题字空间，下方留白 |
| 3:4 | 海报、公众号配图（默认） | 主体中下区，上方留题字空间 | 主体位于画面中下区域，上方留白 |
| 1:1 | 专辑、头像、小红书 | 居中，四边等距安全区 | 主体居中，四边等距留白 |
| 4:3 | 城市卡、横版海报 | 横向延展，主体偏一侧 | 主体偏一侧 1/3，另一侧留白 |
| 3:2 | 标准横幅摄影、文章头图 | 横向延展，主体居中或偏一侧，天地留白均衡 | 主体位于画面中央或一侧 1/3，左右留白均衡 |
| 16:9 | 头图、视频封面 | 横向空间，主体偏一侧 1/3，文字在另一侧 | 主体位于画面一侧 1/3，另一侧留白供文字 |
| 2:1 | 信息图、banner、长卷 | 左右分割或中段集中 | 主体与辅助元素左右分区，或中央 1/3、两侧渐隐 |
| 20:9 | 电影横幅、超宽（Grok 无 21:9） | 极宽，主体集中中段 1/3，两侧渐隐 | 主体位于画面中央 1/3，两侧渐隐留白 |
| 5:2 | 概念海报（F8-V8 默认，宿主无 5:2 降级 20:9 / 2:1） | 超宽词义叙事，文字主视觉集中中段 | 主题词居中，文字与点睛物集中在中央 1/3，两侧渐隐留白 |

**应用**：任何变体换尺寸时，把目标比例行的「提示词必须写」一句并入提示词构图段，其余不动。变体默认比例：F1-Y 默认 9:16，F3-C 默认 4:3，F2/F5 默认 3:4（F2-OP 例外，默认 2:3），F4 默认 1:1，F8-V8 默认 5:2（宿主无 5:2 时用 20:9 / 2:1），F9-R1/R2/R3 默认 3:4，F7-H 默认 3:2。比例降级时（如 5:2 → 20:9）构图段同步改写，禁止只换数字不动构图（规则见 create-pipeline.md 步骤 4 比例唯一性）。

### 比例诊断与建议（交付硬约束，不可省略）

**原理**：比例不是用户的固定参数，是构图决策。用户给的原始比例可能只是惯性（竖版就用 3:4），不是最优解。每次交付提示词时，**必须**附带一条**比例建议**：判断原比例是否匹配画面结构，不匹配则给替代比例 + 理由，并把对应「提示词必须写」并入构图段。

**硬约束**：**缺比例建议 = 交付不完整，禁止交付**。这条与交付完整性检查（optimize-pipeline.md）联动，是每次交付的固定组成部分，不是可选项。

**判断规则（MECE）**：
- **主体竖向延展**（立轴、人物、长笔势、纵向流动线条）→ 竖幅：默认 3:4，纵向张力强用 2:3，壁纸用 9:16
- **主体横向延展**（横幅、左右流动、宽构图节奏）→ 横幅：默认 4:3，电影感用 16:9，超宽用 2:1 / 20:9
- **超宽概念载体**（词义海报、文字主视觉、长卷词义叙事，即 F8-V8 类）→ 5:2（默认）；宿主无 5:2 时降级 20:9 / 2:1，构图段同步改写
- **主体居中紧凑**（徽标、符号、单字、集中式构图）→ 方图 1:1
- **原比例已匹配画面结构** → 保留原比例，写明「原比例匹配，无需调整」，不强行换
- **拿不准** → 优先竖幅 3:4（默认），宁可保守不可跳过

**交付格式**（加在提示词之后、变更说明之前）：
```
建议比例：[保留原比例 / 原 4:3 → 建议 2:3 等]
理由：[一句，对应画面结构]
```

**示例**（欧普貔貅）：原 4:3 横向，但主体为局部特写、纵向线条流动——横向构图会裁掉主体纵向张力，建议 2:3 竖幅。

## 四、质量自检

出图后、交付前。量化规格只在这里用，不写进 prompt。

1. 读回成图：Grok 用 `read_file`；Codex 内置用 `view_image`；Codex CLI 用 `view_image` 打开 `--out` 文件。
2. 先盲写「画面上实际有什么」（主体、文字、颜色、多余元素），再对照该变体量化规格。含糊 = 该项失败。
3. 粗检（能看出来就算，不测百分比）：
   - 留白是否明显过半（非写实家族）
   - 颜色是否明显超出该变体色板
   - 元素是否明显超件
   - 禁止项是否出现（印章、卡通五官、车流）
   - 指定文字是否原样、有无多余字 / 标点 / 水印
4. 失败 → 只修一项，写明「其余保持不动」。Grok 用 `image_edit`；Codex 内置先 `view_image` 再走 imagegen 编辑；Codex CLI 用 `edit --image`。中文乱码不要同词重试，改走封面约束档或告诉用户后期叠字。
5. 同一项连续 2 次失败 → 停，检查槽位和锁定句，不要第三次盲重试。不要为了修图从 Codex 内置切到 CLI，或从 Grok 切到 Codex。

**评分输出格式（每版必填）**：

```
自检评分：留白 4/5，色板 5/5，元素数量 5/5，文字纯净 5/5，禁忌触犯 0
失败项：仅 [一项]，其余保持不动
```

- 评分维度 = 该变体量化规格（留白/色板/元素/文字/笔触/肌理等），按 1–5 给分；禁忌触犯 = 触犯条数（0 为合格）
- 任一项 <3 或禁忌触犯 >0 → 返工该单项；≥3 且禁忌 0 → 通过，交付

**模板维护**：已出图通过的变体才是验证过的资产，只许补负向、参数化硬编码、拆冲突。实验变体（F1-Z / F1-AA / F2-K / F2-AB / F5-AC）与测试中变体（F1-AE / F1-AH / F2-AC / F5-AE / F5-AF / F7-AE）不适用这条硬规则，点名使用后按本节省检并回填状态。禁止以「优化」名义稀释已验证约束。

## 五、通用精华库（跨提示词提取，2026-08-16）

> 从 vivo 原子笔记 2995 条提示词中提取的跨模板结构精华（MECE：介质/材质/工艺/光/语言/约束/文字 七类）。
> 这些是「句子级语法」，可注入任意家族变体，不改变变体身份。源条目出自本地素材归档（不随技能分发）。

### 1. 介质优先声明（第一句锁定作品性质）

先声明「这是什么工艺/媒介的作品」，再描述内容；介质词前置防模型漂移到油画/插画/照片。

```
整体观感接近高质量[载体类型]，但所有细节都由[工艺元素]构成，是一件[工艺名]作品
介质优先：这是[玻璃/纸/布/皮]上的[工艺名]，不是油画、不是数码插画
画面像一帧暂停的[剪纸/皮影/定格]动画：所有元素由[工艺语法]构成，而不是油画或照片
```

### 2. 材质排除法（负向锚点三段式）

「不是 X，不是 Y，是 Z」收尾 + 「禁止 A、B、C」清单，二者同时出现才锁死。

```
不是[油画效果]，不是[平面插画]，不是[卡通]；是真实存在的[工艺名]作品[场景]照片
不要油画笔触、水彩颗粒、数码画笔纹理，不要相机景深、镜头光斑和 UI 元素
避免塑料感与数码光滑表面，避免纯平面[工艺]效果，避免[其他画种]笔触风格化覆盖工艺细节
```

### 3. 工艺递进语法（工序链，让模型理解制作过程）

工艺提示词按「制作工序」顺序写，比罗列效果词稳定。已验证工序链：

```
刺绣：稀针铺底 → 密针做细 → 多向乱针叠色（锚点：「平、齐、细、密、和、光、顺、匀」）
纸雕灯彩：竹篾铁丝扎骨架 → 长纤维手工纸逐层裱糊 → 刻纸纹样镂空负形 → 针刺微孔孔阵透光
剪纸：底层红纸镂空雕刻 → 上层绒面/米白纸保留轮廓
皮影：牛皮镂空雕刻 → 矿物彩绘 → 逆光透射出蜜蜡质感
```

### 4. 光逻辑四式（工艺 × 光法固定搭配）

| 光式 | 适用 | 句子 |
|------|------|------|
| 博物馆展陈光 | 刺绣/器物/纸雕 | 柔和顶光保证光顺匀称 + 一侧温和侧光强化凸起与方向，中性略偏暖 |
| 珠宝影棚光 | 剪纸/雕塑/摆件 | 单侧高对比硬光 + 侧后方逆光勾边 + 高反射台面镜面反射 |
| 棚拍柔光 | 萌系/产品 | 大软箱高键低对比 + 柔和接触阴影 + 干净商业产品图 |
| 自然光漫射 | 水墨/节气/氛围 | 无方向、低强度，光只标记时间，不制造戏剧 |

### 5. 升格句式（对象 → 价值品）

把日常对象升格为藏品/艺术品的四句式，用于气质收尾：

```
光影将[主体]升华为价值连城的[品类]艺术品
像一件被精心设计并[工艺]出来的[节气/祝愿]作品
整体像可以挂在[客厅/展厅/博物馆]里的[作品类型]
更像一瞬[节令/情绪]，被时间轻轻按住
```

### 6. 槽位化最高形态

单必填变量 {主体} 为最高形态；姿态/配色/背景并入槽位说明，正文零模板污染；填法一律外置到「槽位」行（含「填/替换/可换/推演/选一」）。

### 7. 画面文字自动生成规则（当画面需文字时）

限定字数与风格，禁止口号：2-6 字祝福型文案，语言朴素传统，优先使用熟悉祝愿结构（平安喜乐/岁岁平安），按主题语义自动变化，不可固定复用；文字题签式置于角落，不加标点，不加装饰。

### 8. 防翻车锁定句库（已验证句，按需注入）

```
线条是纯装饰性图形元素，非毛发、无立体起伏（线描/欧普类）
纹样密度从画面边缘向中心逐渐递减，避免抢夺主体（锦地/纹样边框类）
撕裂前后除[指定差异]外，姿势表情光线背景全部保持一致（错视/拼贴类）
纸张有真实纤维与剪切痕迹，边缘略带毛边；叠纸间细微阴影（纸艺类）
雾感来自空气透视与层次递减，而非镜头虚焦（氛围类）
```

### 9. 摄影参数块模板（器物/产品微距通用）

```
等效{85}mm{微距}镜头，f/{2.8}浅景深，{暖}色温偏暖，{平视略仰}角度，高对比低饱和
```

### 10. 比例-构图联动（先定构图再定比例）

竖向张力（飞天/题签/飘带）→ 竖幅 2:3/3:4；横向延展（天际线/舞台/长卷）→ 横版 4:3/16:9；集中式（胸像/器物/纹样）→ 方形 1:1；超宽概念（词义叙事）→ 5:2/2:1。比例真源表见本文件第三节。
