## B — 极简概念杂志海报

**Best for**：节日（端午、中秋等）、节气、抽象主题。

```
一张[主题]的高级杂志风格插画，细节极简，概念性视觉叙事，杂志级品质，干净的矢量渲染，大量留白，纯白或极浅背景。

必须彻底跳出传统节日/主题海报框架，不要直接画符号、卡通、红金喜庆、祥云边框、祝福模板。

核心表达：[提炼主题的安静情感本质，填法见模板外槽位说明]。不需要任何完整的场景，只去捕捉那些平时不被注意的瞬间。主题的东西不直接画。

色彩以雾白、苔绿、水蓝、浅灰为主，少量深墨绿或单一强调色压住画面。质感上保留轻微印刷感和纸张质地，避免过度光滑。

文字极简，中文主标题仅一个词或极短短语。

整体安静、克制、有呼吸感。

画面中除主标题外不出现任何其他文字与标点，主标题原样呈现不加标点，无任何水印、日期、签名。
```

**量化**：主色板候选 雾白/苔绿/水蓝/浅灰（雾白作底，按主题选 ≤2），强调/压色（深墨绿或单一强调色）≤1，全图合计 ≤4 色；标题 ≤6 字；两个槽位（主题、核心表达）必填。

**槽位填法**：核心表达 = 提炼主题的安静情感本质（示例：端午节 →「从喧闹中慢下来，重新找回呼吸和节奏」）；示例只用于引导填槽，不进入交付正文。

## E — 文化概念海报

**Best for**：传统文化主题的现代化诠释（天坛、青花瓷、故宫、书法等）。

```
[主题]的现代概念海报。大量留白或极简背景。

用几何层叠、半透明色块、或流动书法笔触重新诠释主题，而非写实描绘。保留纸张质感与印刷感。

色彩高度克制，只使用与主题文化关联的两三种颜色，并让其中一种成为主色。

中文标题与短句干净排版，与画面形成呼应。整体高级、安静、有文化厚度但不复古堆砌。

画面中除中文标题与短句外不出现任何其他文字与标点，中文标题与短句原样呈现不加标点，无任何水印、日期、签名。
```

**说明**：色彩选择在模板外决定后填入——如天坛用朱红与米白层叠，青花瓷用蓝白晕染，写死在模板里会导致每次出图泄漏示例。填法：把「两三种颜色」替换为具体色名。

**量化**：色彩 2-3 种；标题 ≤8 字；禁写实。

**槽位**：主题（填具体文化对象，如「天坛」「青花瓷」）。

```

**槽位**：{输入文字}（唯一必填变量，品牌名/关键词/节日名，可替换）、{画幅}（默认 2:3，可改 1:1）。

## F2-3D — 3D 书法层叠海报

**与 F2-F（纯书法字）分工**：F 是平面墨笔书法字；3D 是字从平面站起来的立体雕塑，自带厚度/投影/景深。

**来源**：签名风格库 S5 吸纳（豆包出图验证 2026-08-16，样图 gallery/f2-3d-calligraphy.jpg）。

**模式**：3D-1 立体书法字（默认）/ 3D-2 层叠概念海报 / 3D-3 光影书法（戏剧光效版）。

**3D-1 立体书法字（默认）**：

```

## F2-JS — 金石印象（篆刻主视觉）

**Best for**：品牌 Logo 级视觉、单字概念海报、个人品牌标识、封面主视觉。把篆刻从「画面角落的点缀」提升为「绝对主视觉」——金石刀痕的粗犬质感 + 朱红与墨黑的强烈对比 + 现代极简的构图呼吸。

**来源**：签名风格库 S6 吸纳（豆包出图验证 2026-08-16，样图 gallery/f2-js-seal-impression.jpg）。

**模式**：JS-1 巨印主视觉（默认）/ JS-2 印谱系列 / JS-3 金石残片（拓片质感）。

**JS-1 巨印主视觉（默认）**：

```
一幅以篆刻巨印为绝对主体的现代平面。[纸质：纯白]纸底。画面中央一枚[形状：方形][印色：朱砂红 #C3272B]印章，约占一半，刻「[文字]」，[篆体：小篆]，[刀法：冲刀+残破]，印泥厚薄不匀，边缘毛边斑驳，不是矢量图形。右侧可有米粒大「[边款：可无]」边款。印章周围大留白。全画面只有印色、白、墨三色。画面中除[文字]和边款外不出现任何其他文字与标点。禁止细腻工笔、红金喜庆、印章做角落点缀。
```

**JS-2 印谱系列**：

```
一幅如传统印谱般排列的多枚篆刻印章作品。
【印谱布局】
画面中排列[数量：2-6 枚]篆刻印章，如传统印谱的版式——[布局：如 2x2 方格/竖排一列/错落排布]。每枚印章内容不同，但篆体风格和刀法统一，形成系列感。印章之间有均匀的留白间距，如书页上的印谱拓片。
【印章内容】
每枚印章刻有[文字：如单字系列「金木水火土」/词组系列「踏雪寻仙」/概念系列「杠杆复利红利」]，印章形状可统一（全方形）或有变化（方+圆+随形），但整体视觉节奏和谐。
【印泥与质感】
所有印章统一使用[印色]印泥，每枚印章的印泥厚薄和斑驳效果略有差异，如手工钤印的自然变化。印章边缘有自然毛边。
【题签】
画面一侧或顶部有极细的[题签：如印谱名称/系列标题]，以隶书或行楷呈现，字号极小，如古籍的书签题签。
【留白】
画面至少 35% 为留白，印章之间和四周都有充足的呼吸空间。印谱的秩序感来自留白的均匀，而非元素的堆砌。
【色彩】
全画面色彩不超过三种：印色、纸底色、题签色。
【气质】
如翻开一本古老的印谱，每一枚印章都是一个独立的宇宙，排列在一起又形成对话。秩序、克制、有收藏感。
【禁止】
超过 6 枚印章、印章大小差异过大、多彩印泥、复杂背景、文字堆砌。
【文字纯净】
画面中除印章文字和题签文字外不出现任何其他文字与标点，原样呈现不加标点，无任何水印、日期、签名。
```

**JS-3 金石残片（拓片质感）**：

```
一幅金石拓片质感的篆刻残片作品。
【残片主体】
画面中央或偏侧放置一块[形状：不规则碑刻残片/破碎的印章石/瓦当残片]，表面有[文字：如残存的篆字/隶书/图案纹样]，文字因年代久远而部分残缺、模糊，只有部分笔画清晰可辨。残片边缘有自然的断裂和剥落，不是完整的几何形状。
【拓片质感】
整体呈现[拓片效果：黑底白字/深底浅纹]，如宣纸拓印碑刻的效果——文字和纹样处为浅色（拓包捶打后的留白），背景为深色（墨色），有不均匀的墨色厚薄和纸张褶皱感。残片表面有石质的粗糙纹理和风化痕迹。
【空间】
残片置于[背景：纯黑/深灰/深色宣纸]背景中，周围是大面积的深色留白。残片可有极淡的投影，如放置在深色台面上。
【题跋】
残片旁可有极小的[题跋：如考释文字/收藏印记/短句]，以极细的行楷呈现，如金石学家在拓片旁的批注。
【色彩】
全画面色彩不超过三种：深色底、浅色拓纹、题跋色（若有）。整体为低明度的暗调，如深夜灯下观碑。
【气质】
一块残片，承载着时间的重量。残缺的文字比完整的文字更有力量——因为它让观者去想象、去补全。金石的粗獰与拓片的静谧在黑暗中对话。
【禁止】
完整无缺的碑刻、多彩、明亮背景、细腻工笔、卡通化、文字堆砌。
【文字纯净】
画面中除残片残存文字和题跋文字外不出现任何其他文字与标点，原样呈现不加标点，无任何水印、日期、签名。
```

**量化**：印章/残片占 40-60%（残片 30-50%）；印谱模式印章 2-6 枚；边款/题签 ≤印章 1/10；留白 ≥30%（印谱 ≥35%，残片暗留白 ≥40%）；色彩 ≤3 种；默认 1:1 方图（印章经典形制）或 3:4 竖幅。

**槽位**：印章文字（必填，1-4 汉字）；印章形状（默认方形，可圆形/随形/半通印）；篆体（默认小篆，可缪篆/鸟虫篆/甲骨文）；刀法（默认冲刀+残破，可切刀/细朱文）；印色（默认朱砂红 #C3272B，可朱磦红 #E34234/墨黑 #2C2C2C）；纸质（默认纯白 #FFFFFF，可米白 #F5F0E8/深墨拓片底 #1A1A1A 反白）；边款（默认无）。

**出图锁定句**：中央一枚巨印约占一半，不是角落点缀；印泥斑驳有毛边，不是矢量；字只能是[具体文字]和边款。
