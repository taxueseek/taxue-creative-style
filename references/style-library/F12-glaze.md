# F12 釉面器物

**家族量化规格**：主媒介 = 釉、窑、器物表面或器物组字；看材质不看场景；色彩由釉色体系决定，≤4 种；禁产品棚拍白底、禁把釉写成平面色块海报。

**风格卡片**：核心调性 = 工艺物证、克制华丽、器物自己说话；视觉特征 = 开片、釉光、青料或彩料、器物轮廓；经典结构 = 一器或数器成字 + 纸或暗托；禁忌 = 电商静物、整桌宴席、红金堆砌。

**与旧卡分工**：F2-E 可以把「青花瓷」当文化主题做几何海报，那是海报语法。本家族画的是釉面本身。F7-QW 是文人器物禅意摄影；本家族是工艺绘画/平面，不是镜头。

**变体索引**：

|------|------|------|
| F12-QH | 青花釉面 | 默认 |

## F12-QH — 青花釉面

**Best for**：瓷、釉、开片、青料纹样、单器特写。要茶席氛围走 F7-QW；要文化符号海报走 F2-E。

```
一幅以青花瓷釉面为绝对主体的画面。观者贴近一件[器物]，看见釉面多于看见整器。白釉微暖，青料[纹样]沉在釉下，有浓淡和笔触停顿，不是印刷贴花。釉面有开片或橘皮，高光是釉的一层薄光，不是塑料反光。背景是安静的[底色]纸或墙，大面积留出，让釉色成为唯一强调。全画面只有釉白、青料、开片灰、底色。禁止摆一桌瓷器，禁止金色边框，禁止把青花画成蓝白插画平涂。若有题字，只在画面一角竖排不超过四字，原样呈现不加标点。

用户输入内容：主题：[请在此填写]
```

**量化**：比例默认 3:4；器物 1 件（可只取局部）；色 ≤4（釉白 / 青料 / 开片灰 / 底）；纹样 1 类；禁群器、禁金边、禁平涂插画。

**槽位**：器物（碗/瓶/盘/梅瓶局部，按主题推演）；纹样（缠枝莲/水波/云肩/空白开片，按主题推演）；底色（默认米灰 #E8E2D6，可深墨托青）。

## F12-BX — 器物字势

**Best for**：八仙、匠作、传统工艺海报、以物组字。字要立体书法走 F2-3D；字要剪纸层走 F2-AC。

```
一张新中式工艺平面。米白或浅青灰底，带纸或绢的哑光。画面中[器物清单]这些传统器物悬浮或轻放，共同组成「[文字]」的字势——远看是字，近看是器物。每件器物保留自身工艺肌理（竹、铜、瓷、木、丝），但不画成写实静物摄影。构图克制，器物数量刚好拼出字形，周围留白。色彩取自器物本色，全画面不超过四种。禁止红金喜庆边框，禁止卡通八仙人物，禁止把字写成书法墨迹或 3D 立体字。画面中除[文字]外不出现任何其他文字与标点，[文字]原样呈现不加标点，无水印、日期、签名。

用户输入内容：主题：[请在此填写]
```

**量化**：比例默认 3:4；文字 1–2 字；器物件数 = 字形所需，上限 8；色 ≤4；远看字近看物；禁人物故事画、禁 3D 字、禁书法字。

**槽位**：文字（必填，主题核，如「八仙」「匠心」）；器物清单（由主题推演：八仙→扇/剑/葫芦/笛/花篮/莲/符板/拍板，不写死进模板外的示例句）。
