# 人物场面语法包（组合层，不占变体号）

> 与 `character-lock-sheet.md` 分工：锁定卡回答「这是谁」；本包回答「人在空间里做什么」。身份任务先做锁定卡，再选场面；新图人物任务先选场面，再套家族媒介。
> 与 scenario-pack 分工：scenario-pack 按用途/画幅推荐变体；本包按身体与空间的关系选场面，再注入已选变体。

## 一、根问题

表层：再画几张仕女、再开几个风格。
根问题：现有人物卡把**场面写死在媒介里**——F1-P 只回眸、F5-DY 只窗下黛玉、F7-V 只影棚半身。换风格就要重写整段，换场面就要换卡。
第一性原理：一张人物图 = **身份 × 场面 × 媒介**。三件独立可换。场面是身体与空间的关系，不是服饰清单，也不是新家族。
因此本包只注册可跨家族复用的场面语法；新默认卡（F1-YS / F1-BY / F5-YL / F5-QS / F7-ED）是这些场面在对应媒介上的已采样点。

非目标：不替代 taxue-ip-illustration 的形象一致性；不写正宗仕女画谱（走 taxue-artist）；不把「美女」当主题类型。

## 二、六场面（MECE：身体与空间的关系）

一个主题只进一类。跨类时取用户原话里的动词（「回眸」走回眸，「弹琴」走案前）。

| 场面 | 身体与空间 | 源模板（推演自） | 默认变体 | 可套家族 | 尺度锚点 | 光（单职责） | 道具上限 | 禁 |
|------|-----------|-----------------|---------|---------|---------|-------------|---------|----|
| 回眸 | 侧身或四分之三，视线离开观者 | F1-P、F5-L | F1-P | F1-P / F5-L / F5-YL / F7-V | 人物 30–40% | 侧光勾轮廓，脸部受光少于肩背 | ≤1 | 对视镜头、露齿笑、完整正面五官 |
| 窗下 | 坐，窗是光的来源 | F5-DY、F5-MP | F5-DY（古典）/ F5-MP（民国） | F5 / F1-P / F7-T | 半身，人物 40–55% | 窗纸或玻璃的侧逆光，暗部不死黑 | ≤3，且服务状态 | 把窗画成景点；DY 与 MP 的道具叙事不可混用 |
| 背影 | 不见脸，衣纹与肩背传神 | F1-A 姿态语法 + F1-TX「背影比正面有力」 | F1-BY | F1-BY / F6-D（极小）/ F10-ST / F11-PY | 水墨 35–45%；剪纸可居中 | 逆光或漫射，只塑轮廓 | ≤2 件尺度物 | 回眸露脸、五官、复杂背景 |
| 倚栏 | 全身立，栏杆给出尺度 | F5-DY 身形与侧逆光，场面从窗下改到栏边 | F5-YL | F5-YL / F1-YS / F11-PY | 全身，人物 45–55% | 栏外进来的侧逆光，打在半边脸与栏棱 | 栏 + 手中或栏外 1 件 | 半身特写、栏杆堆雕、仙宫 |
| 案前 | 坐于器物，动作极小 | F1-A 器物≤3 + F5-AC 案灯剑 + F7-QW 旧物痕迹 | F1-YS / F5-QS | F1-YS / F5-QS / F4-G | 人物+案 ≤50% | 窗纸漫射或灯焰如豆，二选一 | 案上 ≤2 | 弹琴的戏剧手势、满案清供、多人雅集 |
| 环境立 | 当代身体站在真实环境里 | F7-V 清冷姿态 + 外滩时装人像（蓝调/双温） | F7-ED | F7-ED / F5-AD / F13-PL | 人物 40–55% | 环境光一种职责（蓝调冷底+一处暖余晖） | 环境线索 ≤2 | 影棚无缝底、地标明信片、旅游全景 |

点名「回眸 / 侧身」走回眸。点名「窗边 / 倚窗」走窗下。点名「背影」走 F1-BY，禁止再给一张露脸回眸充背影。点名「抚琴 / 对弈 / 夜读」走案前。点名「时装 / 外滩 / 编辑人像」走 F7-ED。

## 三、注入规则（场面 × 媒介，只换场面槽）

选定家族模板后，**媒介句一字不动**（墨法、绢本、镜头、剪口），只替换下表三列。禁止把两个场面写进同一张 prompt。禁止把剪纸与皮影写进同一张。

| 场面 | 姿态句（写入主体段） | 空间句 | 状态证据（道具必须能解释状态） |
|------|---------------------|--------|-------------------------------|
| 回眸 | 侧身，下颌微转，目光落在画面外 | 人物偏一侧，空白在视线前方 | 衣带或发丝被风带向视线反方向 |
| 窗下 | 坐，肩微溜，一手虚扶窗棂 | 窗占结构，光从窗来 | 残烛/冷茶/停摆的钟，与状态同源 |
| 背影 | 背对或四分之三背，头微垂或微侧 | 人面向留白走去或停在留白前 | 足迹、杖、下摆重量，不见脸 |
| 倚栏 | 全身立，一手扶栏，重心落在一足 | 栏杆横过中下，栏外是空白或淡远山 | 栏外一枝花或一弯月，不看花 |
| 案前 | 侧坐，双手停在未完成的动作上 | 案在中下，人与案成一组 | 琴弦未按、棋未落、香将尽、卷停在半页 |
| 环境立 | 身姿微倾，头部轻侧，视线不直视镜头 | 环境退成色温与质感，不写地标全景 | 一件有重量的外套或风吹起的衣角 |

**量化（所有场面共用，再叠加家族规格）**：

1. 人物数量 = 1（对影是系列第二张，不在本包单张默认）。
2. 色 ≤4，写色名+角色+占比。
3. 光只有一种职责（塑形 / 透光 / 环境时刻，三选一）。
4. 情绪只从姿态、视线、道具推，禁止空写「优雅」「忧郁」。
5. 明确成年。涉及可能未成年的描述改为安全的成年时尚或肖像。

## 四、跨风格对照（同一场面，只换媒介）

用户要「同一人物多风格」时，锁场面与身份，换媒介。例：雅士案前 → F1-YS 水墨 / F5-QS 绢本 / F10-ST 人物剪影。禁止三张都是水墨换色。

| 主题 | 场面 | 主变体 | 备选媒介 | 题字 |
|------|------|--------|---------|------|
| 雅士 | 案前 | F1-YS | F5-QS；F10-ST 若要剪影 | 默认可无字 |
| 仕女闲立 | 倚栏 | F5-YL | F1-P 若只要回眸半身；F11-PY 若要侧影 | 默认可无字 |
| 清冷女子 | 回眸 | F1-P | F5-L 体积光；F7-V 影棚 | 无字 |
| 窗边一人 | 窗下 | F5-DY 或 F5-MP | F7-T 胶片；F1-P 水墨半身 | 无字 |
| 离去 | 背影 | F1-BY | F6-D 若要极小人对巨物；F10-ST 剪影 | 可竖题 2–4 字 |
| 时装形象 | 环境立 | F7-ED | F5-AD 插画；F13-PL 拍立得现场 | 无字 |

替换角色时：场面句保留，身份（发式、服饰、年龄感）与状态证据同步换。黛玉的残烛冷药不能跟着换成时装模特。

## 五、技巧层（从已有卡与公开提示词结构收束）

写人物 prompt 时按这个顺序组句，不另发明段标题：

1. **媒介先行**：第一句锁定制作语言（水墨写意 / 绢本淡彩 / 染色剪纸 / 胶片人像）。来源：本库家族卡片；公开提示词结构把 medium 放在主语位置。
2. **主体·动作·环境**连续写完，不拆成标签。动作用正在发生的未完成态（「停在弦上尚未按下」），比「正在弹琴」更可画。
3. **尺度锚点**：人物占画面的百分比写死（上表）。来源：F1-Y「米粒大小」、F7-QW「≤25%」、公开提示词的 scale anchors。
4. **光只做一件事**：窗下=透光；背影=轮廓；环境立=时刻色温。来源：F5-DY 侧逆光、F7-V 柔光+轮廓光、公开提示词 single-duty lighting。
5. **工艺动词跟媒介走**：勾、皴、晕、罩（F1/F5）；剪、镂、套染（F10）；透、铆（F11）；拍、浅景深（F7）。避免「画一张」这类空动词。
6. **工艺痕迹当真实感**：枯笔断裂、绢丝、剪口毛边、胶片颗粒、衣上使用痕迹。来源：F1-AH / F5-DY / F10 / F7-T；公开提示词把 craft error 当 realism。
7. **传神优先于五官**：姿态动势 > 精细五官。来源：用户手改「传神形象」；F1-A 情绪走身体。
8. **约束收在段末**：只列该场面最会跑偏的 2–4 点，正向已写过的不再负向重复。

禁止把本表枚举写进 prompt 正文。正文只留执行句。
