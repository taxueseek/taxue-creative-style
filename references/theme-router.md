# 主题路由（主题 → 多风格优质提示词）

> 用途：用户给主题、未点名风格时，按主题类型选出 1 主 + 1–2 备选，再读对应家族文件的**一个**变体段。禁止把本表整段写进 prompt。
> 与 scenario-pack.md 的分工：scenario-pack 按**用途/画幅**推荐；本表按**主题语义**推荐。先判主题，再叠用途。

## 选择规则

1. 用户点名风格 / 点名变体 → 不走本表，直接读该变体。
2. 命中子技能（IP / 民国 / 中译中 / 万象 / 反推 / 正宗艺术门类 / 完整节气推演）→ 先量子技能，不在本库硬套。
3. 否则按下表选主风格。备选只在用户说「换一版 / 多风格 / 对比」时展开。
4. 每个主题只锁一个主媒介。备选必须换媒介，禁止两个剪纸变体互相当备选。
5. 实验 / 测试中变体不进本表。

打分（内部，不写进 prompt）：适配 0–2 + 证据 0–2 + 约束冲突 0–1（无冲突得 1）。主风格总分应 ≥4。

## 主题类型（MECE）

九类互斥：先归类，再选卡。一个主题只进一类；跨类时取用户原话里的动词（「刻一枚印」走符号文字，「拍一只碗」走器物，「回眸」走人物形象）。

| 类型 | 判定 | 主风格 | 备选 | 不要选 |
|------|------|--------|------|--------|
| 符号文字 | 主题是字、词、短句、品牌名、要当主视觉的字 | F8-V8（词义海报）或 F2-JS（印）或 F2-3D（立体字） | F14-YZ 若是吉祥四字；F10-WH 若是窗花字 | 写实摄影、水墨人物 |
| 节气物候 | 节气名、天气过境、刚结束的时刻 | F13-AR 物证档案 | F2-B 概念杂志；F13-PL 若要人物/街拍 | 直接画节气符号、红金祝福模板 |
| 生肖民俗 | 生肖、年节、门神、吉祥 | F10-ST 染色剪纸 或 F5-M2 极简红剪影 | F14-YZ 年画；F11-PY 若要戏台表演 | F5-M1（剪纸皮影混卡） |
| 神话戏文 | 传说、对峙、英雄动作、戏台 | F14-SM 赛璐璐原创 或 F11-PY 皮影 | F11-MU 木偶若市集喜剧；F1-A 若要孤寂哲思 | 把剪纸、皮影、年画并列写进同一张 prompt |
| 城市地标 | 一座城、天气卡、建筑气质 | F3-LC 层叠城市 | F3-C 水墨天气卡；F3-O 纸雕大场景 | 旅游摄影明信片 |
| 器物工艺 | 瓷、釉、茶器、文物、器物组字 | F12-QH 青花釉面 或 F7-QW 器物禅意 | F12-BX 若要以物组字；F2-I 若只要一件隐喻物 | 把釉面写成留白海报几何块 |
| 日常治愈 | 小物、猫、窗台、手账 | F4-G / F4-K / F1-Q | F13-PL 若要拍立得现场 | 概念海报超宽横幅 |
| 人物形象 | 雅士、仕女、背影、倚栏、时装人像、要画一个人 | 先读 character-scene.md 定场面，再套默认变体（回眸 F1-P / 窗下 F5-DY 或 F5-MP / 背影 F1-BY / 倚栏 F5-YL / 案前 F1-YS 或 F5-QS / 环境立 F7-ED） | 换媒介时：水墨↔绢本↔剪影↔摄影，禁止三张同媒介换色 | F8 超宽概念海报、F3 城市（禁人物近景） |
| 旧照改造 | 用户已有照片 | F9 对应变体（复活/抽象/涂鸦/赛璐璐/皮影） | — | 从零创作家族（F1–F8、F10–F14） |

点名「皮影」一律 F11-PY，禁止再走 F5-M1。点名「剪纸」走 F10 或 F5-M2/M3/M4/DC，按要平面还是多层再分。点名「年画 / 折纸 / 木偶 / 赛璐璐原创」走 F14 / F11-MU，不走 F9（F9 只接照片输入）。点名「雅士 / 书生」走 F1-YS（绢本改 F5-QS）；点名「背影」走 F1-BY，禁止用回眸露脸充背影；点名「倚栏」走 F5-YL；点名「时装人像 / 外滩」走 F7-ED。

## 多风格对比交付

用户要「同一主题多风格」时，选**不同媒介**的 3 张：例如「马」→ F5-M2 红剪影 / F11-PY 皮影 / F14-YZ 年画；「雅士」→ F1-YS 水墨 / F5-QS 绢本 / F10-ST 人物剪影。每张只改媒介层，主题核与场面不动。禁止 3 张都是剪纸换色。
