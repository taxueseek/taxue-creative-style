# 人物锁定卡（人物取扱说明书 · 身份锚点资料板）

参考模板（同 beast-myth / geometric-monument / embroidery-illustration：不占变体号，不改变体计数；模式二/三可按需引用）。服务「人物一致性」任务：为稳定再现同一人物，制作一张可反复使用的身份锚点资料板。

**第一性原理**：人物卡是一件**身份锚点资产**，衡量标准只有一个——复现度：任何人拿这张图再生成角色，都能锁定「这就是同一个人」。手段是**恒变量二分**：身份不变量显性锁定，允许变量画出边界。美化即漂移。

## 一、身份不变量（MECE 六层 + 表现层）

| 层 | 锁定内容 | 自检锚点 |
|---|---------|---------|
| 结构层（骨相+五官） | 脸型、下颌线、下巴、颅顶、发际线、眼距、眼裂长、眼型、双眼皮、眉位、鼻梁宽与高、鼻尖、鼻翼、人中、唇厚、嘴角位 | 脸部五角度骨相随真实角度变化，不把正脸硬贴到其他角度 |
| 体量层 | 头身比、肩宽、胸腰胯、腿长、臂长 | 全身五视角完全一致，不因角度改身材 |
| 毛发层 | 发型、发量、发缝、刘海厚度、鬓角、发流、发尾弧度、发色 | 发拆解五格 + 补充角度格 |
| 皮肤层 | 肤色、毛孔与纹理、唇纹、自然瑕疵、妆面 | 局部放大与主图一致，不磨皮 |
| 服装层 | 款式、颜色、材质、版型、穿着状态 | 不改款、不加配饰、不减衣料 |
| 年龄层 | 皮肤松紧、眼神成熟度、整体年龄感 | 不年轻化、不幼态化 |
| 表现层（介质） | 实拍 / 插画 / 三维原图属性、光线与质感 | 全板同一介质同一光感 |

**允许变量（只有三样）**：表情（眉眼、嘴角、眼睑开合）、角度、姿态。其余全部锁死。

## 二、元提示词（参考图唯一必填）

```
以这张参考图为唯一且绝对的人物身份基准，制作一张用于反复生成同一人物的「人物锁定资料板」，只做身份固定与复现：锁定同一张脸、同一种年龄感、同一套头身比例、同一发型发色、同一肤色肤质与同一套服装，人物本身不做再设计。横向 16:9，白色或极浅灰 #F7F7F5 纯色背景，细灰色横线与规整方框的资料排版，整体像一张高质量的人物设定控制表。中央区域：全身五视角（正面、侧面、后方、斜前方、斜后方），五格同一个头身比、同一副肩宽、同样的四肢比例、发型体积与服装版型，换个角度还是同一个身材；脸部五角度（正面、侧脸、斜四十五度、上方、下方），颅面结构、发际线、眼距、鼻梁、唇厚、下颌线按真实骨相变化，不能把正脸生硬贴到其他角度。右侧区域：九格表情（通常、微笑、认真、惊讶、害羞、苦恼、思考、悲伤、平静），表情只动眉眼、嘴角和眼睑开合，脸型、五官比例与年龄感保持不变，九格里一眼都是同一个人；旁边附一小格头发与脸的补充角度，交代发际线、鬓角、耳朵与下颌的组合关系。下部区域：局部放大八格（眼、眉、鼻、嘴、耳、轮廓、皮肤、手），保留参考图真实的皮肤纹理、毛孔、唇纹与指节，不做磨皮美颜；头发拆解五格（刘海、侧发、后发、发梢、发流），保留真实的发缝、鬓角与发尾弧度，各面板发长与卷度保持一致；再往下依次是特征备忘（每格不超过四个字的中文标签，只点最关键的识别点）、色卡（发、瞳、肤、唇、服、影六色，颜色直接取自参考图，保持原有深浅与冷暖）、再生成固定点（轮廓、眼睛、鼻子、嘴唇、发型、发色、肤感、服装、体型、年龄感，各写一个词）。所有面板沿用参考图同一套服装的款式、颜色、材质与穿着状态；参考图是实拍，全板就保持实拍摄影质感；是插画就保持插画；是三维就保持三维；全板同一光线、同一介质。参考图里看不到的部位，只做最保守、最符合已知结构的补全。图内文字只有各面板的简短中文标签：没有姓名、年龄数字、性格爱好和简介，没有水印、装饰标题和乱码。避免网红脸化、幼态化和过度美化，不加多余装饰。任何一格，一眼认出都是同一个人。

用户输入内容：参考图：[请在此上传参考图]
```

## 三、面板布局（MECE，16:9 横版）

| 区域 | 格数 | 内容 | 层级 |
|------|------|------|------|
| 中央 | 5 | 全身：正面 / 侧面 / 后方 / 斜前方 / 斜后方 | 身份层（必保） |
| 中央 | 5 | 脸部：正面 / 侧脸 / 斜 45 度 / 上方 / 下方 | 身份层（必保） |
| 右侧 | 9 | 表情：通常 / 微笑 / 认真 / 惊讶 / 害羞 / 苦恼 / 思考 / 悲伤 / 平静 | 身份层（必保） |
| 右侧 | 1 | 头发与脸的补充角度（发际线 / 鬓角 / 耳 / 下颌组合） | 细节层 |
| 下部 | 8 | 局部：眼 / 眉 / 鼻 / 嘴 / 耳 / 轮廓 / 皮肤 / 手 | 细节层 |
| 下部 | 5 | 头发拆解：刘海 / 侧发 / 后发 / 发梢 / 发流 | 细节层 |
| 下部 | 1 | 特征备忘（每格 ≤4 字中文标签，不写姓名年龄性格） | 信息层 |
| 下部 | 1 | 色卡：发 / 瞳 / 肤 / 唇 / 服 / 影 六色，直接取自参考图 | 信息层 |
| 下部 | 1 | 再生成固定点：轮廓 / 眼 / 鼻 / 唇 / 发型 / 发色 / 肤感 / 服装 / 体型 / 年龄感，各一词 | 信息层 |

**量化与降级**：全板约 36 格，一次生成的真实上限因模型而异。分三层执行——身份层 19 格必保；细节层 14 格在格数撑不住时合并（如八格局部并为四格组），不牺牲身份层；信息层 3 区最后保证。降级时只合并格数，不删除锁定维度。

## 四、复用方法（拿到卡之后怎么用）

1. 后续生成同一人物时，用**全身正面格**（或最清晰的脸部正面格）作为参考图输入——参考图=视觉事实来源，多参考分工按 task-constraints.md §三执行
2. 把「再生成固定点」一栏的十个词抄进提示词开头，作为文字身份锚
3. 只按允许变量改表情、角度、姿态；场景与系列扩展按 task-constraints.md §一致性锁定清单执行
4. 每次生成对照第五节自检；漂移回本卡重新锚定，不在漂移图上继续改

## 五、自检清单（出卡后逐项勾）

- [ ] 全身五视角头身比、肩宽、服装版型一致
- [ ] 九表情一眼同一人，脸型与年龄感未动
- [ ] 局部肤质与主图一致（毛孔、唇纹还在）
- [ ] 色卡取自参考图，无提亮偏色
- [ ] 标签 ≤4 字，无姓名年龄性格信息
- [ ] 全板同一介质（实拍/插画/三维不混）

失败只修一项；同一项连续 2 次失败即停（prompt-craft.md 自检纪律）。

## 六、与来源版本的差异（吸纳说明）

合并两版外部提示词（日文版面板版式 + 中文版骨相级锁定），按本库纪律重写：

- **保留**：面板清单与版式（V1）、骨相级锁定细目、六类色卡、再生成固定点、优先级思想（V2）
- **删除**：V2 的 60+ 条禁止堆砌——身份锁定改用不变量正向表达（「眼距一致」优于「禁止眼距变化」），负向收敛为 2 条真实跑偏点（磨皮美颜、负向堆叠已在正文正向化）
- **新增**（两版都没有）：恒变量二分模型、36 格三层数量与降级规则、**复用方法**（原版只管做卡、不管怎么用卡）、自检清单、标签语言为可换槽位
- **本地化**：标签默认中文（V2 混用日文标签），用户点名日语 / 英语时全局统一一种
- **语言打磨（2026-08-29，用户反馈）**：清除「不是……而是……」等 AI 味句式与「负向：」标签堆叠，规格语言直接陈述——身份用不变量说，例外用一句「避免」收口；句式向两版原稿的实务语气对齐

## 交付纪律

1. 先判任务类型：本卡服务 task-constraints.md §一的「人物/产品一致性」任务；制作前确认参考图来源与使用授权
2. 不占变体号，不新增变体号（计数以 verification-ledger 为准）
3. 标签语言全局统一一种（默认中文），禁止混排
4. 色卡直接取自参考图，不套任何家族色板（硬约束 #12）
5. 实拍真人参考图涉及肖像：确认用户有权使用该形象后交付
