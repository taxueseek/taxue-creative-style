# F14 美术片媒介

**家族量化规格**：主媒介三选一：木版年画 / 折纸构造 / 手绘赛璐璐；一张图只选一个主媒介；辅媒介最多一个且只承担一项职责；色彩 ≤4 种。

**风格卡片**：核心调性 = 中国美术片的制作语言，不是「国风滤镜」；视觉特征 = 套色或折面或平涂闭合线；经典结构 = 角色或符号 + 媒介自身的空间；禁忌 = 把年画、折纸、赛璐璐并列写进同一张 prompt。

**与旧卡分工**：F9-R4 是照片转动画，必须有用户照片。F5-L 是上美影仕女体积光，偏超现实 3D。本家族从零画，不要照片，不要 Octane。同族的 F14-SM 与 F14-SC 都是赛璐璐，分工在色彩纪律：SM 要背景降一档饱和度（清爽、角色突出），SC 要主调色连背景气氛一起统摄（重彩、气氛由色承担）；两者不得混写。

## F14-YZ — 木版年画

**Best for**：门神、年节、瑞兽、喜庆正面人物。要克制剪纸走 F10；要戏台走 F11-PY。

```
民间木版年画单帧。[主体]造型饱满，正面或接近正面，轮廓大方，像贴在门上能被认出来。套色关系用朱红、石绿、藤黄、靛蓝与墨线中的有限几种，不是全画面红滤镜。纹样只集中在衣缘、器物或边框，不铺满。空间不靠透视，靠大小和左右对称。纸面有木版套印的轻微错位和边缘，不是光滑矢量。禁止金色 3D 字，禁止电商红包排版，禁止卡通贴纸。画面中除[可选题字]外不出现任何其他文字与标点，无水印、日期、签名。

用户输入内容：主题：[请在此填写]
```

**量化**：比例默认 3:4；主体 1–2 人/兽；套色 ≤4 种关系 + 墨线；纹样分区；禁红滤镜、禁 3D 金字。

**槽位**：主体（门神/生肖/瑞兽 + 姿态）；可选题字（默认无，吉祥二字可有）。

## F14-ZZ — 折纸构造

**Best for**：飞鸟、器物变形、几何神话道具、轻巧结构。要剪纸平面走 F10；要纸雕大场景走 F3-O。

```
手工折纸场景。[主体]由可追溯的山折、谷折和纸面连接构成，像少数几张色纸折出来，不是低多边形模型，也不是复杂雕塑。折面明暗来自纸的朝向和柔和光，没有塑料反光。全画面两到四种色纸。背景简化，可有极浅的桌面或单色底。禁止用剪纸纹样盖住折线，禁止写实纸张微距商品照。画面中除[可选题字]外不出现任何其他文字与标点，无水印、日期、签名。

用户输入内容：主题：[请在此填写]
```

**量化**：比例默认 1:1 或 4:3；主体 1 个可折结构；色纸 2–4 种；折线必现；禁低多边形、禁剪纸满纹、禁商品微距。

**槽位**：主体（可折的对象 + 一个姿态，如鹤张翼、船泊桌面）。

## F14-SM — 赛璐璐原创

**Best for**：神话英雄、动作定格、儿童角色、戏曲顿挫。用户已有照片要转手绘走 F9-R4；仕女体积光走 F5-L。

```
传统手绘赛璐璐动画单帧。[主体]用粗黑闭合线，衣物和道具是稳定的不透明平涂，每个物体最多一层硬边阴影。动作停在戏曲式顿挫，剪影清楚。角色轮廓比背景更锐利；背景用低一档饱和度的舞台层次，不用镜头虚化。颜色四种以内固有色，白色干净，红蓝绿保持稳定，禁止全局泛黄和灰雾。禁止现代手游立绘，禁止 3D 渲染，禁止日式大眼厚涂，禁止胶片颗粒覆盖线稿。画面中除[可选题字]外不出现任何其他文字与标点，无水印、日期、签名。

用户输入内容：主题：[请在此填写]
```

**量化**：比例默认 16:9 或 3:4；闭合线 + 平涂 + 一层硬边阴影；色 ≤4；禁 3D / 厚涂 / 泛黄。

**槽位**：主体（角色 + 动作定格 + 一件可识别服饰或兵器）。

## F14-SC — 赛璐璐·重彩（上美影工艺还原）🔶

**Best for**：中国美术片重彩人物、神话英雄、要色彩承担气氛的单帧。要背景降饱和的清爽赛璐璐走 F14-SM；要年画满幅走 F14-YZ。

```
中国手绘动画赛璐璐单帧。角色与背景分层：角色画在透明片上，叠在静止背景之上，角色轮廓比背景更锐利。主体是[主体]，动作停在戏曲式顿挫，剪影清楚。赛璐璐片上做不了渐变，高光、中间调与阴影之间是硬朗的线条分界，不是柔和过渡；每块颜色只有一层硬边阴影，阴影是另选的一块实色，不是把底色压暗。毛笔勾线，线条有顿挫与飞白；色块不透明平涂，边缘干净，带轻微印刷质感。面部按戏曲脸谱装饰处理，五官概括、有神采，眼睛有完整结构——眼白、瞳孔与高光点。全画不超过四种颜色，从五行正色青、赤、黄、白、黑中按角色身份推演一个主调，即[主调色]，它统摄角色衣饰与画面气氛：一片饱和的浓云气从主体处漫开，整片连成一体，边界是水墨晕开的虚边，与角色身上的硬边色块形成虚实对照。另取一到两种正色点缀，只落在小面积器物或衣缘上。颜色浓而沉着，是矿物颜料的厚重，不是荧光般的艳；色块不掺灰、不掺白。背景其余部分是宣纸白的大留白，让画面透气。避免数字插画的平滑渐变、欧美动画的厚涂体积感、写实渲染与日式大眼。画面中不出现任何文字与标点，无水印、日期、签名。

用户输入内容：主题：[请在此填写]
```

**量化**：比例默认 3:4；主媒介 = 赛璐璐，角色层与背景层分开；硬边过渡 + 阴影是实色而非压暗；色 ≤4 且主调只一个（统摄衣饰与气氛）；脸谱化面部；留白托底；禁日式大眼、禁 3D、禁平滑渐变。

**槽位**：主体（角色 + 动作定格 + 一件可识别服饰或兵器）；主调色（按角色身份从五行正色推演，如帝王黄、水属蓝，不写死色名）。
