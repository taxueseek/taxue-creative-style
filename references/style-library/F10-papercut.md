# F10 剪纸纸艺

**家族量化规格**：主媒介 = 纸的剪、镂、套色或透光；轮廓由切口构成；色彩 ≤4 种；禁写实体积光、禁与皮影灯屏混写、禁矢量贴纸感。

**风格卡片**：核心调性 = 平面工艺、民间刀味、克制套色；视觉特征 = 剪影、镂空、纸边纤维、层或透光；经典结构 = 单主体或窗格 + 有限色纸；禁忌 = 3D 纸雕摄影、皮影关节灯屏、日式和纸绘本、渐变体积。

**与旧卡分工**：F5-M2/M3/M4/DC 仍可用（极简红剪影 / 珠宝影棚 / 植绒卡哇伊 / 多层景深）。新任务点名「染色剪纸」「窗花」走本家族。F5-M1 是剪纸+皮影混卡，本家族禁止再混。

**变体索引**：

| 变体 | 名称 | 状态 |
|------|------|------|
| F10-ST | 染色剪纸 | 默认 |
| F10-WH | 窗花透光 | 默认 |

---

## F10-ST — 染色剪纸

**Best for**：生肖、瑞兽、马、花鸟、民俗单物、人物剪影。单色剪纸要染色晕的层次时用；只要纯红剪影走 F5-M2；人物场面语法见 character-scene.md，媒介句不动只换主体姿态。

```
一幅中国染色剪纸。米白宣纸底。画面中央一个[主体]的完整剪影，轮廓由剪刀切口构成，边缘有轻微毛边和纸纤维，不是矢量平滑边。剪影内部有少量镂空纹样，只够认出结构，不布满。颜色来自在纸面上的套染：[主色]为底色块，[晕色]在边缘或关节处淡开一层，像染料在纸里走，不是数码渐变。全画面不超过三种颜色加纸底。无灯屏、无皮影关节、无立体纸雕厚度。构图居中，四周留出纸边。画面中除[可选题字]外不出现任何其他文字与标点，无水印、日期、签名。

用户输入内容：主题：[请在此填写]
```

**量化**：比例默认 3:4；主体 1 个；色 ≤3 种 + 纸底；镂空只服务结构；禁灯屏/关节/3D 纸雕；留白 ≥30%（纸边，不是海报式大空白）。

**槽位**：主体（必填，动物/生肖/花鸟/人物剪影；人物时填「一人 + 姿态」，如背影持杖、侧身回眸，不镂五官）；主色（默认正红 #C3272B，可靛蓝 #3F5A8C / 墨黑 #2C2C2C）；晕色（默认赭石或淡墨，由主体推演）；可选题字（默认无，生肖可二字干支）。

## F10-WH — 窗花透光

**Best for**：节气窗景、家屋、城市窗、夜与室内的边界。剪纸贴在窗上，光从背面来。

```
一幅贴在窗上的中国窗花。观者在室内看向窗外。[窗框材料]窗格占画面结构，窗花[主体]贴在其中一格或居中一枚，镂空对准室外光线。光从窗外进来，在窗花切口处形成透亮，室内侧只有极淡的纸影。窗外景物高度简化，只保留[室外线索]的色温，不写实街景。窗花本身是单层或多至两层色纸，切口清楚。全画面颜色不超过四种：窗框、窗花主色、透光色、室内暗部。禁止皮影戏台、禁止珠宝影棚黑背景、禁止把窗花画成墙饰年画。无文字则整幅无字；若有题字，只写在窗框外的墙面上，不超过四字。

用户输入内容：主题：[请在此填写]
```

**量化**：比例默认 3:4；窗花主体 1 枚；纸层 ≤2；色 ≤4；光 = 背面透光；禁灯屏戏台、禁影棚黑底、禁满墙年画。

**槽位**：主体（窗花纹样对象，按主题推演：雪→梅、夏→荷叶脉、城市→车灯剪影只作室外线索）；窗框材料（默认木格，可铝窗/旧铁栏）；室外线索（色温或一件简化物，不写实）。
