## 零、提示词可执行性铁律（重要）

“踏雪审美 / 踏雪 DNA / 踏雪留白 / 踏雪纸感 / 踏雪化”只是本 skill 内部简称，生图模型不认识。写进用户 prompt 之前必须展开为可执行视觉描述：

| 内部词 | 必须展开为 |
|--------|-----------|
| 踏雪审美 | 兼容并蓄、特性鲜明；不是单一水墨风。具体视觉特征按所选风格/场景展开，共同点通常包括：克制用色（全图 ≤4 色）、留白或呼吸感、纸感或印刷颗粒（非写实类适用）、文字即设计、边界利落 |
| 踏雪留白 | 大面积留白、主体不填满画面、画面有呼吸感 |
| 踏雪纸感 | 宣纸纹理、纸纤维颗粒、印刷颗粒、不追求塑料光滑；写实摄影家族不套用 |
| 踏雪参考色板 | 没有单一色板；按家族/场景选。水墨系：宣纸白 #F5F0E8、墨黑 #2C2C2C、朱砂红 #C3272B、青花蓝 #4A5F7F、松石绿 #7C9D96；治愈系：桃色/暖橙/浅棕；城市系：朱红/米白/墨绿/鎏金；写实摄影：自然胶片色；概念海报：≤4 色由主题推演 |

禁止把“踏雪审美”“踏雪 DNA”“踏雪化”等内部术语原样写进交付给生图模型的 prompt。

## 一、吸纳的精华（不照搬）

1. **批量系列先锁骨架**：一次 N 张图，先固定版式/信息架构/文字系统，再只变化主题与色相，避免每张图各做各的。
2. **品牌手册式三段信息架构**：上部主视觉场 → 中部结构色块 → 底部解释性文字，形成「感性→理性→说明」的阅读路径。
3. **彩虹色相纪律**：同系列每张图主色相截然不同、避免雷同，N=10 时覆盖彩虹各色相；这是模型无关的系列可识别性手段。

保留踏雪系统：兼容并蓄、特性鲜明，不是单一水墨风。共同特征是克制、留白/呼吸感、信息少而准确、文字即设计、色彩受限（≤4 色）、边界利落；具体材质与色板按主题/场景从 9 大家族中选择（水墨、治愈、城市、留白海报、写实摄影、概念海报等）。不强行照搬「清透明亮高饱和」，而是把三段架构与色相纪律套进所选踏雪材质与色板。

## 二、元提示词模板（主题唯一变量）

```
围绕任意主题对象生成一张清透明亮、具有高端品牌规范页气质，并带有克制纸感与信息秩序的视觉稿：画面上部以主题派生的材质运动作为主视觉场，材质由主题气质决定，可以是水墨晕染与宣纸纹理、治愈手绘纸感、城市水墨卡、留白海报的极简图形或写实摄影质感，并保持克制，让细密笔触、纸纤维、墨色层次或相应材质细节和明暗起伏形成沉浸式背景，视觉重心落在主视觉场的中部偏稳位置；主题名称或核心符号以干净字体居中压在纹理之上，字形可圆润现代或略带笔意，笔画清晰、间距舒展，像被纸张托住而不是浮在表面。中段设置一块大面积纯净结构色块，与上方影像形成利落硬切，色块承担秩序、品牌识别和信息承载功能，内部只放少量标题、色彩说明或核心参数，左侧主信息大而疏朗，右侧辅助信息小而轻，整体保持低密度、高呼吸感与大面积的留白。底部留出安静浅色空间，用浅灰细字写简短说明，行距宽松，形成从感性主视觉到理性信息再到解释性文字的阅读路径。色彩从主题与对应风格色板中提取，并保持克制：底色按所选风格决定（水墨用宣纸米白，治愈用同色系浅底，写实用胶片自然底色，概念海报可用深底），一个结构主色，信息字和说明字，全图不超过四色，明暗层次清晰，冷暖由主题决定，整体清透新鲜或沉静温润均可，但必须洁净、边界利落，避免污浊、陈旧、灰黄或过度装饰。画面中除主题名称与信息文字外不出现任何其他文字、水印、日期或签名。整体质感像高端品牌视觉规范页与所选材质质感的结合，信息少而准确，视觉记忆点来自流动纹理、结构色块与安静居中文字秩序之间的对比。

用户输入内容：主题：[请在此填写]
```

**建议比例**：竖版 3:4 或 2:3（系列卡/品牌页）；横版品牌页可改 16:9，并同步改写「上中下三段」为「左主视觉 / 右结构信息」。
**量化**：信息密度低；结构色块内信息 ≤3 项；色角色 = 风格底色 + 结构主色 + 信息字 + 说明字（≤4 角色）；留白/呼吸感明显；禁污浊灰黄、过度装饰、商业贴纸感。
**槽位**：主题 = 唯一必填变量。主视觉材质、结构主色、中段信息条目、底部说明均由主题与所选踏雪家族推演。

## 四、系列色相纪律（多图矩阵）

当用户要求「N 城 / N 图 / 色相不雷同」时，强制执行（模型无关，任何足够强的生图模型都适用）：

1. **先锁骨架，再锁色相**：骨架 = 上主视觉场 + 中结构色块 + 下浅色说明，全部图共用。
2. **色相覆盖彩虹**：按红、橙、黄、黄绿、绿、青、蓝、靛、紫、品红轮转；N=10 时每图占一个主色相，禁止相邻图主色相夹角过近；单张内仍保持踏雪受限色板（纸底 + 主色 + 点缀 ≤4 角色），不要用高饱和彩虹堆满。
3. **同图内角色关系不变**：纸底/浅底 + 克制的结构主色 + 信息字 + 浅灰说明字；只换结构主色与材质染色，不换版式。
4. **交付时附色相表**：每图一行「城市 | 主色相 | 结构主色名 | 材质关键词」，防止事后色相撞车。
5. **禁止**：全系列同色换城、只改文字不改材质、结构色块变成照片贴图、信息区堆满、为凑色相破坏纸感与克制。
