# F13 纸本档案

**家族量化规格**：主媒介 = 档案装帧或即时成像物证；主题必须落到一件可见物证；不硬编码节气物件；色彩由物证推演，≤4 种。

**风格卡片**：核心调性 = 刚结束的时刻、物证还在；视觉特征 = 底纸 / 卡片 / 窗口 / 越界，或拍立得时间切片；经典结构 = 一件物证跨过一层边界；禁忌 = 固定荷叶嫩芽、假日期、卡片内装饰圆点、口号文案。

**与子技能分工**：完整节气推演、解释矩阵、开放模式全书走 `taxue-solar-polaroid`。本家族是踏雪化压缩卡，给「要一张档案图 / 一张物证快照」时用，不替代子技能。

**变体索引**：

| 变体 | 名称 | 状态 |
|------|------|------|
| F13-AR | 物证档案卡 | 默认 |
| F13-PL | 即时成像物证 | 默认 |

## F13-AR — 物证档案卡

**Best for**：节气、天气过境、散场、余温、短句记忆。用户要整套节气组图时改走子技能。

```
一张纸本档案编辑视觉。外层是有触感的哑光底纸，颜色从[主题物证]推出来，不是固定节气色卡。底纸上压一张暖白档案卡，卡上有一个图像窗口。窗口里只放[物证]的可见状态，窗口内不写可读中文。有一件与物证同源的实物越过卡片或窗口的一条边。文字很少：标题写主题短句，副标题只描述看见的状态，不写诗，不写典故。未提供地点和日期时，不虚构日期。卡片内角落不放红点、方块、印章或装饰几何。全画面不超过四种颜色。禁止把节气画成符号吉祥物，禁止五张同构图换色。

用户输入内容：主题：[请在此填写]
```

**量化**：比例默认 3:4；阅读层级 = 底纸→卡→窗→越界物证；物证 1 件；色 ≤4；窗内无字；无虚构日期；禁装饰圆点。

**槽位**：主题（必填）；物证（由主题推演可见状态，如处暑→已硬的蜡油，回南天→墙根潮界，禁止套固定叶子）；标题短句（默认即主题，可覆盖）。

## F13-PL — 即时成像物证

**Best for**：人物、街拍、居家余温、旅途过站。要文人器物静物走 F7-QW；要 CCD 怀旧人像走 F7-U。

```
一张即时成像照片。画面是一个被钉住的时间切片：[主体]正在[动作]，现场只留下[物证]。闪光或窗光是现场光，不是影棚。拍立得边框可以有，也可以是照片本身带一点相纸色素。色彩低饱和，偏该时刻的色温，全画面不超过四种。不要摆拍笑容模板，不要无关花体字，不要把照片排成档案卡片。若有手写，只在相纸白边上写一句看见的状态，不超过十字。画面中除该手写外不出现任何其他文字与标点，无水印、日期（除非用户给了日期）、签名。

用户输入内容：主题：[请在此填写]
```

**量化**：比例默认 3:4 或 1:1；主体 1；物证 1；色 ≤4；现场光；禁影棚、禁档案卡结构、禁模板合照。

**槽位**：主体（谁或什么在场）；动作（正在发生的一件事）；物证（与动作同源的残留）。三者由主题推演，主题是人物/街拍时才用本变体。
