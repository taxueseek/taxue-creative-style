# 任务类型 × 不可变约束

**第一性原理**：任务类型决定「哪些必须锁死、哪些可以动」。同一视觉意图，不同任务类型的「锁定清单」不同。把「新图自由度」误用到「参考图改造」正是多数一致性崩坏的根因。本文件在任何模式（一/二/三）确定最终 prompt 前使用，做一次 MECE 的任务类型判定 + 锁定清单提炼。

#### 单行纪律（吸收冗余，浓缩为一句）

质量关卡、反模式、专名准入已由 optimize-pipeline 步骤 1.5 矛盾扫描 + prompt-craft 负向纪律覆盖；本文件独有职责 = **任务类型判定、不可变约束清单、多参考图角色分配、产品/电商场景补全**。反模式只收敛为一条：抽象可迁移结构、不复制独特措辞、不并列冲突风格、不把安全限制伪装成模型保证。

## 一、任务类型表（MECE，先判类型再动笔）

| 任务类型 | 输入 | 锁定不动 | 可动 | 主要文件 |
|---|---|---|---|---|
| 新图生成 | 主题/描述 | 家族模板原文、色彩纪律、比例 | 主体、场景、构图 | create-pipeline |
| 参考图改造 | 参考图 + 文字要求 | 参考图身份特征、产品几何、Logo | 背景、光线、语气、局部 | 本文件 §四 |
| 局部编辑 | 原图 + 编辑区域 | 未指区域全部保持 | 指定区域内内容 | imagegen-routing / prompt-craft 自检 |
| 系列扩展 | 已定主视觉 + 系列要求 | 角色身份、服装、色板、光线、镜头、颗粒度 | 每张只改场景/动作/道具一项 | brand-manual-visual / scenario-pack |
| 版式/海报设计 | 标题/副标/标签 + 主题 | 信息层级、短文本 | 视觉表达、风格 | cover-constraints |
| 人物/产品一致性 | 身份特征 + 上下文 | 脸部/产品特征、发型、服装轮廓 | 姿态、场景、表情 | 家族模板 + 本文件 §三 |

## 二、提炼不可变约束（锁定清单）

每次交付前，在内部先建「锁定清单」，逐项确认：**主体数量、主体身份、关键服装/产品特征、动作、空间关系、画幅比例、必须出现的文字、不能出现的内容**。系列图额外锁定：脸部、发型、服装、色板、材质、镜头语言。跨模型时把锁定项整体上移为「母版」的不可变项（model-dialect.md §一），方言层不得改动。

## 三、多参考图角色分配

参考图 = **视觉事实来源**；文字要求 = **修改指令**。禁止无依据重写参考图的关键身份特征。

- 参考图 A 负责主体，参考图 B 负责服装/材质，参考图 C 负责场景/构图
- 明确优先级：某平台不支持同数量/类型素材时，保留优先级最高者并明确告知取舍
- 最终画面必须指出「不出现多余主体」
- 跨模型时以 `@AssetName`（如 `@Image1`/`@Video1`/`@Audio1`）在 prompt 中引用素材名并写明其职责

## 四、场景补充（去重后真正新增）

现有场景包（scenario-pack）与封面约束（cover-constraints）已覆盖封面、海报、品牌、器物、城市、系列。本文件的独有补充：

### 人像（与 F1/F5/F7 模板配合）

明确年龄段而非「美女」；说明表情、姿态、视线、服装、镜头高度、焦点位置、皮肤/织物真实质感。涉及敏感或可能未成年的人物时，改为安全、成年且非色情的时尚或肖像表达。

### 产品与电商（taxue 缺口，新增）

明确产品数量、朝向、材质、无变形要求、背景留白、阴影方向、反射控制、品牌文字。产品图**优先控制几何结构与可读性，而非追求复杂氛围**。文字过长主动建议后期叠加或拆分。

### 海报与版式

先规定信息层级，再规定画面。明确标题、副标题、按钮/标签的原文、位置、字重、对齐、留白。文字过长时按 cover-constraints 三硬规则走后期叠加；文字为书法变体时保留模型直接生成的可能（prompt-craft §一）。

### 系列约束

输出「系列母版约束」：角色身份、服装、色板、光线、镜头、画面颗粒度；每张只改场景/动作/道具中的一项，维持连续性。批量系列色相纪律见 brand-manual-visual.md。

## 五、「保留—修改」句式（参考图/编辑任务）

推荐句式：「保留参考图中的主体身份、脸部特征、发型、服装轮廓和整体姿态；仅修改……」。局部编辑：指定编辑区域、不可改变区域、边缘融合方式、光影匹配方式；**不要要求整张图「重新生成得更好」，而要描述局部可验证变化**。

合成多张参考图时，按 §三 分配角色，并行写明「最终画面不能出现多余主体」，再走 prompt-craft 出图封装与自检。
