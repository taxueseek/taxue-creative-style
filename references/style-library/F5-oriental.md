## L — 上美影东方仕女

**Best for**：优雅东方女性、超现实美感、高艺术价值。

```
超现实东方美学，上美影水墨意境融合3D体积光，极深墨绿背景，抽象变形的青衣仕女半身像，衣袂如泼墨流动，侧脸窥视姿态，丹凤眼尾上挑，唇角似笑非笑。C4D渲染，Octane体积雾，面部微距特写，衣纹发丝超精细。色彩叙事：石青、钛白、墨黑。动态模糊，镜头张力，8K。

整体追求上美影经典动画的神韵与现代3D体积光的结合，东方韵味浓郁，不西化。
```

**量化**：色板 石青/钛白/墨黑；背景 = 深墨绿；渲染 = C4D + 体积雾。版本注：原型色板为石青/钛白/胭脂红，两版皆可用。

**槽位**：主体默认「抽象变形的青衣仕女半身像」，可替换为其他东方女性/古典神话人物（填「谁 + 姿态 + 服饰」）；其余质感与色板锁定句不动。

## M3 — 奢侈品影棚剪纸

**Best for**：剪纸的珠宝级质感。

```
以奢侈品高级珠宝广告的影棚灯光逻辑，拍摄一只小巧的剪纸[主体]。背景为深灰至纯黑的平滑渐变。单侧高对比硬光从侧后方勾勒镂空边缘，红色纸质轮廓呈现锐利高光线条。主体置于高反射黑色台面形成镜面反射，构图极度简洁，让剪纸成为价值连城的珠宝艺术品。
```

**量化**：背景 深灰→纯黑；光源 = 单侧硬光；主体 =1 只。

**定制示例（正红镂空剪纸马，珠宝影棚完整参数版，可直接用）**——源自早期多平台迭代最终形态：

```
正红镂空剪纸马，侧面昂首姿态，马身镂空饰以卷草云纹，多层叠纸可见微妙厚度与切口边缘，居中置于香槟金镜面台面，倒影完整清晰，带微暖金色调。背景上浅粉渐至下深粉，垂直渐变，无纹理。侧后 45° 硬光勾勒轮廓边缘，镂空处透光形成明暗穿透对比，正前方设大面积柔光反射板，补出正红纸面色彩与叠层细节。珠宝广告影棚逻辑，微距镜头，f/11 深景深，主体占画面约三分之一高度，极简竖幅构图，无装饰，无字留白。
```

**量化（增强版）**：光 = 侧后 45° 硬光勾勒 + 正前柔光反射板补色；镜头 = 微距 f/11 深景深；主体占画面 1/3；背景 = 上下粉渐变无纹理；镜面倒影完整。

## AD — 日式复古时尚插画

**Best for**：1980-90 日式杂志编辑风插画、复古时尚、品牌视觉。

**说明**：与 N（写实摄影风）同属「日式复古时尚」主题，但 AD 是插画风——平涂色块 + 笔触纹理边缘，视觉语言不同，独立变体。

```
日式复古时尚插画，1980-90 年代杂志编辑风格。优雅东亚女性模特半身像，高级时装姿态，肩颈微侧、眼神疏离从容，仿佛旧杂志内页的时装大片。大胆平涂色块搭配笔触纹理边缘——色块饱满利落，边缘保留手绘笔触的参差与质感，不追求矢量平整。复古杂志封面美学，强排版感。简约中文文案点缀。精致配色，锁定四色以内：一个主色、一个次色、一个点缀色、一个底色，随模特的服装与气质推演（如酒红+米白+墨黑+金）。插画师风格，纸面印刷质感，保留轻微纸张颗粒与印刷噪点。避免廉价矢量扁平、避免过度精致、避免塑料质感、避免写实照片感、避免杂乱元素堆砌。
```

**量化**：比例 3:4（复古杂志封面经典竖幅；全身姿态可改 2:3）；半身像 + 疏离眼神；平涂色块 + 笔触纹理边缘；色 ≤4 种（主/次/点缀/底）；纸面印刷颗粒；文案 ≤6 字（若模型写不对字，按封面约束档文字后期叠加）。

**槽位**：模特姿态、服装与色板（主/次/点缀/底四色，示例「酒红+米白+墨黑+金」只用于引导，不进入正文）、中文文案内容（≤6 字）。

**状态**：用户提供原创提示词优化，待出图验证。
