# 视觉欺骗技法包（破框 / 拼脸 / 缝合 / 图底）

参考模板（同 embroidery-illustration / geometric-monument：不占变体号，不改变体计数；模式二/三点名「错视 / 破框 / 拼脸 / 空间缝合 / 图底」时引用）。感知机制不是制作媒介，四卡互斥，一次只用一张。

**第一性原理**：视觉欺骗成立，当且仅当画面里有一条可指出的结构在骗大脑的自动换算。写机制，不写「optical illusion / 视觉错视 / mind-bending」。与 F2-OP 分工：欧普管「线密度成像」，本包管另外四条机制。

**状态**：V1 待出图。点名才用，禁止未指定时的默认路由。

## 恒变量分层

| 层 | 固定（语法） | 随主题推演（变量） |
|---|---|---|
| 机制 | 四卡各锁一条，禁止混写进同一张 prompt | — |
| 媒介 | 每卡一个媒介锚点（墙面油画 / 静物油画 / 写实绘画 / 二维平面） | — |
| 构图 | 比例、主体位置、交界或轮廓纪律 | 探出物件、物类、上下两景、对生的两个形象 |

| 文字 | 画面无字，无水印日期签名 | — |

## 一、破框错视

**Best for**：物件越界、封面主视觉、展览感概念图。主题被翻译成「一件东西从画里走到墙上」。

**机制**：画框与墙皮共享同一套透视灭点和接触阴影。物件一部分仍在框内的二维世界，一部分越过画框边缘，压在真实墙皮上。

```
一张 3:4 竖版的墙面油画。主题决定从画框里探出的那件东西，也决定墙皮的颜色和光线的时刻。画面是一面真实墙皮，正中钉着一副画框，画框四边完整可见。框内是同一主题的平面绘画。主题的核心物件从框内探出，一部分仍在框里的二维世界，一部分已经越过画框边缘，压在墙皮上，接触阴影贴着墙皮，和画框自己的影子共用同一盏斜上方硬光。画框、墙皮裂纹、钉子和物件边缘对齐在同一套透视灭点上，像一只手从相框里按住了真实的墙皮。墙皮约占一半画面，画框居中略偏下，四周露出真实墙面。色彩由主题推演，全图不超过四种，墙皮用主题浅色，物件用主题核心色，画框用同色系深色。画面中不出现任何文字与标点，无水印、日期、签名。画框四边保持完整，接触阴影贴在墙皮上，物件压着墙，不悬空。

用户输入内容：主题：[请在此填写]
```

**量化**：3:4 竖版；画框居中略偏下；墙皮约占一半；色 ≤4；画框四边完整；接触阴影贴墙。
**锁定句**：画框四边完整可见，物件的接触阴影贴在墙皮上。
**出图前确认**：画框还在；物件压着墙不漂；墙皮与框内是两个空间层。

### 槽位填法（示例不进正文）

| 主题 | 探出物件 | 墙皮 / 光 | 色板角色 |
|------|----------|-----------|----------|
| 时间 | 生锈座钟，钟摆越过下沿 | 石灰墙，午后斜硬光 | 墙浅灰、钟锈褐、框深褐、一丝铜金 |
| 童年 | 木马前蹄跨出画框 | 暖白墙，窗边侧光 | 墙米白、木马朱红、框松木色 |
| 财富自由 | 金钥匙从框缝顶开，齿压在油漆上 | 冷灰墙，顶侧硬光 | 墙冷灰、钥匙金、框墨黑 |

### 替换规则

- **一字不动**：墙面油画、画框四边完整、接触阴影贴墙、同一盏斜上方硬光、同一套灭点、无字、≤4 色
- **联动推演**：探出物件、墙皮色、画框色、光线时刻
- **覆盖口**：用户可写死探出物件，不填则由主题推演
- **比例**：正文锁 3:4。横向墙面长卷把首句「3:4 竖版」换成「16:9 横幅」，画框改到画面左侧三分之一，其余不动

## 二、物件拼脸

**Best for**：人物或身份的概念肖像、节气头像、品牌拟人。主题被翻译成「一类物堆成一张脸」。

**机制**：五官与发丝不单独绘制，全部由同一类可识别物件替换。物件外轮廓拼合成头骨与五官轮廓。近看能数出单件，远看是一张完整的脸。

```
一张 3:4 竖版近景头像，静物油画质感。主题决定这张脸是谁，也决定组成这张脸的物类。五官与发丝不单独绘制，全部由同一类可识别物件替换，物件的外轮廓拼合成头骨与五官的轮廓，近看能数出单件，远看是一张完整的脸。物类从主题最贴身的器物里推演，全脸只用这一类，物件之间有轻微叠压和缝隙。头像取三分之二侧面，居中占画面大约六成，背景是由主题推演的极浅纯色，干净无杂物。一盏斜上方的光只用来分开物件的体积。色彩由物类固有色推演，全图不超过四种色相。画面中不出现任何文字与标点，无水印、日期、签名。近看必须能数出单件，全脸只有一类物。

用户输入内容：主题：[请在此填写]
```

**量化**：3:4 竖版；头像居中约 60%；三分之二侧面；物类 = 1；色相 ≤4；背景极浅纯色。
**锁定句**：近看能数出单件，全脸只有一类物。
**出图前确认**：不是纹理贴在一张普通脸上；五官由物件缺口与叠压形成；物类唯一。

### 槽位填法（示例不进正文）

| 主题 | 身份 | 物类 | 色板角色 |
|------|------|------|----------|
| 书生 | 清瘦青年侧脸 | 线装书页、折角、书签 | 宣纸米、墨褐、一丝朱红签 |
| 秋分 | 女子侧脸 | 稻穗、柿子、枯叶 | 稻金、柿橙、叶褐、浅米底 |
| 程序员 | 半侧脸 | 排线、键帽、散热鳍片 | 键灰、线彩限一色、金属银、浅底 |

### 替换规则

- **一字不动**：静物油画、五官不另画、一类物、能数出单件、三分之二侧面、光只分体积、无字
- **联动推演**：身份、物类、物类固有色、浅底色
- **覆盖口**：用户可写死身份或物类，不填则由主题推演。二者都写时仍须一类物
- **比例**：头像特写可把首句「3:4 竖版」换成「1:1 方图」，主体改为约占七成，其余不动

## 三、空间缝合

**Best for**：人生隐喻、两个世界的概念海报、城市与故乡、昼夜交界。主题被翻译成「一条结构线同时属于两个世界」。

**机制**：上景与下景在画面中线附近相接。交界是同一条物理边，在上半是上景的结构，在下半是下景的结构，接点处线条一一对齐。

```
一张 3:4 竖版写实绘画。主题决定上下两层各是什么世界，也决定把它们缝在一起的那条线。画面上半是主题的一个世界，下半是主题的另一个世界，两层在画面中线附近相接。交界处是同一条物理边，这条边在上半是上景的结构，在下半是下景的结构，两边的线条在接点处一一对齐，像屋脊同时是山脊。每个区域只属于一个世界，只在那一条线上同时属于两个世界。光源只有一盏，从上景贯穿到下景，交界处的明暗连续。色彩由主题的画面反差推演，上景与下景共用一套不超过四种的色，靠明度差区分两个世界。主体位于中轴，交界线横贯画面。画面中不出现任何文字与标点，无水印、日期、签名。交界保持一条清晰的结构线，两边的边在接点处对齐。

用户输入内容：主题：[请在此填写]
```

**量化**：3:4 竖版；交界在中线附近；一盏光源；色 ≤4；中轴构图。
**锁定句**：交界是一条结构线，两边的边在接点处对齐。
**出图前确认**：交界可指出是哪条边；不是渐变溶解；不是两张图叠在一起。

### 槽位填法（示例不进正文）

| 主题 | 上景 | 下景 | 缝合边 |
|------|------|------|--------|
| 归处 | 城市阳台栏杆 | 故乡田埂 | 栏杆横杆接到垄线 |
| 杠杆 | 天平横梁 | 石桥桥面 | 横梁接到桥面 |
| 白夜 | 雪原地平 | 台灯下的书桌 | 地平接到桌沿 |

### 替换规则

- **一字不动**：写实绘画、一条物理边、一盏贯穿光、明暗连续、无溶解、无字、≤4 色
- **联动推演**：上景、下景、缝合边、反差色板
- **覆盖口**：用户可写死上景与下景，不填则由主题的画面反差推演
- **比例**：正文锁 3:4。左右缝合把「上半 / 下半 / 中线」换成「左侧 / 右侧 / 竖中线」，首句比例改为 4:3 横幅，其余不动

## 四、图底互生

**Best for**：对峙、阴阳、供需、符号双关。主题被翻译成「一条轮廓同时是两个形象的外缘」。

**机制**：全图只有一条闭合轮廓。填深色看见甲，填浅色看见乙，对调后两个主体互换。两个主体不各画一套边。

```
一张 1:1 方形的二维平面构成。主题决定互相生成的两个形象。画面只有一条闭合轮廓线，这条线同时是主体甲的外缘和主体乙的外缘，填上深色时看见甲，填上浅色时看见乙，对调深浅后两个主体互换。两个形象都从主题的对立体里推演，轮廓简洁，一眼可辨。背景与图形只用主题推演的一对高对比色，可加一枚极小的同色系点缀，全图不超过三种。纯正面平视，无体积光，无渐变，无阴影。图形居中，四周留出呼吸。画面中不出现任何文字与标点，无水印、日期、签名。全图只有一条闭合轮廓，两个主体共用这一条边。

用户输入内容：主题：[请在此填写]
```

**量化**：1:1 方图；轮廓 = 1 条；色 ≤3；平视；光影 N/A。
**锁定句**：全图只有一条闭合轮廓，两个主体共用这一条边。
**出图前确认**：能指出那一条共用边；对调深浅后另一主体仍可读；没有第二套轮廓。

### 槽位填法（示例不进正文）

| 主题 | 甲（深色时） | 乙（浅色时） | 色板 |
|------|--------------|--------------|------|
| 对峙 | 两只对视的狼头 | 中间负形是一棵松 | 墨黑 / 纸白，可一丝赭石点缀 |
| 供需 | 一只伸来的手 | 一只碗 | 靛蓝 / 米白 |
| 阴阳 | 一尾鱼 | 一只鸟，共用脊柱线 | 墨 / 暖白 |

### 替换规则

- **一字不动**：二维平面、一条闭合轮廓、对调深浅互换、无体积光无渐变无阴影、无字、≤3 色
- **联动推演**：甲、乙、高对比色对
- **覆盖口**：用户可写死两个形象，不填则由主题的对立体推演
- **比例**：正文锁 1:1。竖幅符号海报把首句「1:1 方形」换成「3:4 竖版」，图形仍居中，其余不动

## 四卡互斥与家族分工

| 需求 | 走哪张 | 不走 |
|------|--------|------|
| 东西从画里出来 | 破框 | 缝合（缝合没有画框层） |
| 脸由物构成 | 拼脸 | 图底（图底没有体积物件） |
| 两个世界共用一条边 | 缝合 | 破框（破框是画/墙两层，不是两套风景） |
| 正负形互换 | 图底 | 拼脸、F2-OP |
| 线密度成像 | F2-OP | 本包 |
| 不可能楼梯 / 彭罗斯 | 本包不收（B 档，模型会修正矛盾） | — |

禁止：四卡机制写进同一张 prompt；画师名（埃舍尔 / 阿钦博尔多等）进正文；效果词「视觉错视 / 光学幻觉」进正文。

## 交付纪律

1. 不占变体号。计数以 verification-ledger 为准，本包不进 77 变体。
2. 主题唯一必填。其余由主题推演，可选覆盖，不填则推演。禁用「缺省」。
3. 出图前把推演结果的 HEX 写实（墙皮 / 物类固有色 / 画面反差 / 高对比色对），禁止套水墨五色当全包色板。
4. 一次出图。仅 blocker（机制没了 / 主体错 / 禁忌）允许一次定向修；主观分不够不重生。同一 blocker 修一次仍失败即停（prompt-craft.md）。
5. 与 F2 海报「禁写实」互斥：破框、缝合、拼脸是写实或静物油画语法，点名本包时不要套 F2 负向。
