# Taxue Creative Style 踏雪创意风格

踏雪影像风格引擎。把「踏雪风格」变成模型可精确执行的视觉指令。

## 快速安装

```bash
npx skills add taxueseek/taxue-creative-style
```

安装后直接说：

- 「用踏雪风格画一张深夜书房」→ 风格出图
- 「优化这段提示词」→ 七维诊断 + 修复 + 注入踏雪 DNA
- 「写个提示词：有夏天感觉的图」→ 从零构建元提示词
- 「以后都用水墨 3:4」→ 记住偏好，下次优先匹配

## 四种能力

| 模式 | 干什么 |
|------|--------|
| 风格出图 | 7 家族 32 变体：文人水墨、留白海报、城市卡、治愈插画、上美影、剪纸、纸雕、日式杂志、写实胶片、CCD、影棚人像等 |
| 提示词优化 | 七维诊断打分 → 修复规则补缺 → 注入踏雪 DNA → 逐条变更说明 |
| 元提示词创作 | 任意一句话需求，重定义为可执行的视觉指令，带槽位可复用 |
| 学习记忆 | 记录使用历史与反馈，下次路由优先匹配偏好 |

## 核心方法论

- **留白第一**：大面积空白是构图主体，不是空缺
- **克制**：少即是多，宁意犹未尽不一览无余
- **文字即设计**：中文字是视觉元素，非附属说明
- **纸感优先**：宣纸肌理、印刷颗粒优于数字光泽
- **概念深度**：捕捉本质而非图解表面
- **色彩纪律**：受限色板，单一强调色常已足够

## 学习机制说明

本 skill 带学习记忆：每次出图后自动记录变体、比例与反馈，下次路由优先匹配你的偏好。**个性化学习内容只存在你本机**：

- `memory/user-preferences.md` 由 skill 自动维护，只记偏好不记出图内容，不提交、不入库
- `references/prompt-archive.md` 是本地版本归档，每次交付自动追加，不参与仓库更新
- 仓库已配置 `.gitignore` 排除 `memory/` 与测试文件，即使误操作也不会把学习记录推上来
