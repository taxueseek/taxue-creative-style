# 封面约束档（不是第五种模式）

只吸收与踏雪兼容的安全原则和负空间技巧。金色元宝类不过闸。封面 = 已选家族模板 + 下列约束，文字槽一律留空。

## 触发与流程

触发：封面、头图、banner、公众号封面、文章配图。
流程：内容主题 → 类型诊断 → 家族映射 → 家族模板（文字槽留空）+ 安全原则 → 出图封装 → 出图 → 自检。

**已验证基础公式**（源自个人实操方法论，多次出图验证）：
`做个公众号封面，[风格]，[构图]，[主题内容]，[留白/氛围]`

**已验证风格模块（可组合）**：现代设计中式审美简约；扁平插画 + Q 版人物 + 几何块面；立体笔触微景观 + 极简俯视图 + 大面积留白；中式剪纸 + 圆润憨态；工笔重彩 + 超写实融合。

## 类型 → 家族映射

| cover 类型 | 踏雪映射 | 说明 |
|-----------|---------|------|
| 微景观治愈 | F4-G / F4-J | 直接对应 |
| 电影叙事 | F6-D 或 F7-S/T | 孤独戏剧感 |
| 信息图表 | F2-I 隐喻物件 | 数字概念化，文字后期叠加 |
| 极简对比 | F2-B 或 F2-I | 直接对应 |

| Mondo 丝网 | F2 家族 + 负空间技巧 | 风格不照搬，技巧吸收 |

| 超现实隐喻 | F2-I 或 F1-W | 直接对应 |

## 封面安全原则（三铁律）

1. **文字一律后期叠加**（Figma/PS），提示词只生成纯图，画面中禁止任何文字
2. **安全边距**：主体避开上方 1/4 与下方 1/5 区域，留给标题叠加
3. **明度差**：背景明显浅于或深于主体，叠字后仍可读。不写百分比。

## 负空间三技巧（与踏雪留白 DNA 同构）

1. **图底反转**：主体剪影内部露出隐藏元素，剪影的缺口讲故事
2. **尺度对比**：微小主体 + 巨大客体，主体只占底部 20%，上方大留白
3. **单一形状叙事**：全画面只有一个符号，靠负空间讲完整个故事

## 失败模式与修复表

| 失败现象 | 原因 | 修复 |
|---------|------|------|
| 画面元素过多拥挤 | 提示词罗列 >3 主体 | 删至 1 个核心隐喻 |
| 背景空白无层次 | 未指定背景 | 加前景虚化/远景剪影 |
| 画风偏卡通幼态 | 缺质感词 | 加 film grain / paper texture |
| 色彩灰蒙蒙 | 未指定光源 | 明确光源方向与光质（见 prompt-craft.md 词库） |
| 主体居中死板 | 未打破对称 | 三分法/偏离中心 |
| 文字乱码 | 模型不擅长中文 | 纯图生成，文字后期 |
| 墨色发灰无层次 | 未约束浓淡 | 加「墨色浓淡自然分层」 |
| 留白消失 | 元素堆砌 | 量化留白 ≥50% |
| 几何化变矢量平涂 | 缺手绘约束 | 加「保留毛边与干湿变化，不追求边缘整齐」 |
| 飞白变描边 | 缺枯润约束 | 加「枯润相间，如毛笔自然拖出」 |

## 版画隐喻封面（维多利亚版画 × Gustave Doré）

来自个人原创工作流：先设计隐喻，再输出提示词。
1. 分析内容：核心主题（1 个名词）、核心观点（1 句话）、情绪基调（inspirational / mysterious / protective / breakthrough / contemplative / rebellious 六选一）、关键视觉锚点
2. 设计隐喻：前景主体物（与主题强关联）+ 超现实转化机制 + 2-3 个象征性辅助细节
3. 输出英文提示词，骨架：16:9 horizontal banner, [主体] rendered in detailed cross-hatching, [隐喻元素] in lighter stippling, [光源] against pure black void, [装饰细节] in negative space, [文字区域] pure black for text overlay, Victorian illustration / Gustave Doré style
4. 负向约束（全保留）：彩色/渐变/灰度照片/扁平/3D/卡通/水彩/油画；阴影渐变/模糊/光晕/滤镜/平涂黑色；非 16:9/对称居中/无文字预留区；字面翻译/无关装饰/超过 3 个元素/过度抽象；可爱/卡通/恐怖/血腥/广告感；添加文字/照片拼贴/低分辨率
5. 隐喻解释：1-2 句说明画面如何视觉化文章观点
