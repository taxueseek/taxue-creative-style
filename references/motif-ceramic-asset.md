# 中式纹样陶瓷素材卡（C4D 矢量风格 · 主题通用）

参考模板（同 beast-myth / character-lock-sheet：不占变体号，不改变体计数；模式二/三可按需引用）。服务「C4D 陶瓷质感素材图」一类任务：一件母题、一张竖版素材，语法固定、主题万变。

**第一性原理**：素材图的语法分两层——**工艺语法固定**（C4D 矢量风、陶瓷、描边、光、留白），**题材层全部随主题推演**（母题形态、主体本色、描边色、背景色）。描边色按主题走，系列内保持统一；母题的「神韵」不在拟人，在**笔意**——每种纹样有自己的写法。

## 一、恒变量分层

| 层 | 固定（语法） | 随主题推演（变量） |
|---|---|---|
| 介质 | C4D 渲染、矢量风格、哑光陶瓷 | — |
| 构图 | 居中单体约占一半、四周大留白 | 母题的朝向与动势 |
| 描边 | 均匀不断线、厚度适中、只在同色系深浅间渐变 | 描边色系（暖金 / 青银 / 赤陶 / 素瓷单色） |
| 色彩 | 低饱和、不过饱和发土、与背景拉开明度 | 主体本色、背景浅色 HEX |
| 光影 | 顶部漫射光、底部一片极淡柔和投影 | — |
| 神韵 | 有生命→神情传神；纹样器物→笔意传神，不拟人 | 母题笔意（见词表） |

## 二、元提示词（主题唯一必填）

```
一张 9:16 竖版的 C4D 渲染矢量风格素材图，商业素材级干净。主体是居中的一件[主题]，约占画面高度一半：形态与纹样语法由主题推演，守住母题的笔意——回卷的要卷得圆，层叠的要叠得匀，回环的要首尾闭合，缠绕的要见生长方向，走势有起有收，像一笔写成；主体由它最具辨识度的两三个视觉符号构成，饱满圆润、边缘流畅，可适度简化，一眼可辨。若主题有生命或以人物、瑞兽为原型，神情按它的气质推演，一眼传神；若是纹样、器物主题，不拟人，神韵全在形态动势里。通体哑光陶瓷质感，主色按主题本色推演，低饱和、不发土；轮廓带均匀不断线的渐变描边，描边色随主题气质推演，只在同一色系的深浅之间渐变，厚度适中。背景是由主题气质推演的极浅纯色，与描边拉开明度，干净无杂物。柔和顶部漫射光，体积圆润饱满，主体底部只留一片极淡的柔和投影。四周大面积留白，细节集中在主体的纹样转折与描边层次上，背景零细节。大师级质感。避免写实照片感，主色与描边都不过饱和发土。

用户输入内容：主题：[请在此填写]
```

词表未收录的主题按同一条推演法走：抓母题笔意 → 按气质定描边色系 → 配极浅底色（明度与描边拉开）。

**描边配色三向**（渐变只在同色系深浅之间，禁止跨色相渐变防脏）：暖系金（华贵、喜庆）、冷系青银（清雅、文人）、古朴赤陶（器物、高古）；极简素器可用单色瓷白描边（无渐变）。系列内描边色统一——系列识别从「金描边」上移为「描边语法 + 系列色」。

## 五、替换规则与降级

- **一字不动**：C4D 矢量风、居中半幅、哑光陶瓷、描边三律（不断线 / 厚度适中 / 同色系渐变）、顶部柔光、单片投影、留白纪律、负向收口
- **联动推演**：母题笔意、主体本色、描边色系、背景 HEX
- **覆盖口**：磨砂 / 半透明果冻质感；描边换银、玫瑰金——同系列内不换
- **比例**：9:16 固化于正文；通用设计素材把「9:16 竖版」替换为「1:1 方图」，其余一字不动
- **成套**：同主题系列 = 每张只换背景色相（极浅色系轮转），母题、描边色系、光全部不动；批量色相纪律见 brand-manual-visual.md

## 六、自检清单

- [ ] 母题一眼可辨，笔意成立（该卷的卷圆、该闭环的闭合）
- [ ] 描边均匀不断线、厚度适中、同色系渐变
- [ ] 陶瓷质感成立，主色低饱和不发土
- [ ] 背景纯净零细节，只有一片极淡投影
- [ ] 有生命主题神情传神；纹样主题未强行拟人

失败只修一项；同一项连续 2 次失败即停（prompt-craft.md 自检纪律）。

## 七、与构图词表对接的中式转译（西式构图参数 × 笔意母题）

构图词表（重复节奏、大字主导、网格阵列等）默认以几何单元为对象；遇到笔意母题时，参数必须先过一层转译再进提示词——失败教训：祥云 4×4 阵列写「严格一致」，十六朵云全部失去灵性，文字用几何无衬线也没有神韵。

| 西式构图参数 | 中式转译 |
|---|---|
| 重复 N 次、形态严格一致 | **同字异形**：重复的是笔意，姿态各异——朝向、卷数、疏密有别（兰亭「之」字、百福图传统） |
| 网格对齐、间距均匀 | **行气贯通**：间距大体均匀，留布白气口，整体有风向 |
| 大字主导、几何无衬线 | **字随母题笔意**：碑刻楷意 / 瓦当文 / 阳刻陶瓷浮雕，与母题同一笔势 |
| 破格焦点 | 破例仍唯一，破例方式随材质（满金、越界、变釉） |

转译后再进矛盾扫描与出图自检；笔意母题的「一致性」永远指笔意一致，不是形态一致。
