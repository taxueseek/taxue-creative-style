## S — 纪实人像

**Best for**：未修饰的真实情绪、后台、生活现场。

```
[主体：如后台休息的京剧刀马旦侧脸特写，卸妆前的真实状态]额头渗出细密的汗珠，混合着厚重的油彩。几缕湿润的发丝粘在脸颊上。聚焦眼神中的疲惫与坚韧，真实皮肤纹理，卡粉与毛孔细节清晰可见。后台昏暗的杂乱灯光，形成自然的散景。超写实，新闻纪实摄影风格，情绪饱满。

负向：磨皮、美颜、舞台定妆照、过度修饰、眼神空洞、塑料皮肤、影楼风、插画、平面化。
```

**说明**：主体槽位填「谁 + 什么状态下的特写」，示例（京剧刀马旦）是已发布版本，可替换为任何职业/人物。负向行必须保留。

**量化**：特写构图；皮肤纹理必须可见；负向 9 项全保留。

## T — 胶片抓拍（Kodak Portra）

**Best for**：亲密瞬间、九十年代私人照片感。

```
手持相机拍摄，稍微偏离中心的近景构图，[主体描述]。使用增感冲洗的柯达Portra 400胶片拍摄，配50mm f/1.4老镜头全开光圈——明显的胶片颗粒感，焦点柔和地落在眼睛上，鼻子和边缘位置稍微失焦，自然的动态模糊，边缘有轻微色差。城市夜晚混合光源，脸部稍微过曝，颧骨处有明显的高光溢出，阴影部分欠曝发黑，背景过曝形成光晕。画面带有轻微暗角，镜头灰尘轻微雾化，1-3度自然倾斜。九十年代私人约会照片的美学风格，不完美但亲密的瞬间，绝非影棚质量，自发的抓拍感觉。

负向：影棚布光、完美对焦、磨皮、商业精修、摆拍感。
```

**量化**：倾斜 1-3°；焦点 = 眼睛；必须有过曝高光 + 欠曝暗部；负向 5 项。

**槽位**：主体描述（填「谁 + 什么状态」，如「街角抽烟的老人」）。

## F7-QW — 器物禅意（文人器物静物）

**Best for**：器物品牌视觉、茶文化/香道主题、极简壁纸。把茶壶、香炉、花瓶从「水墨场景里的配角」提升为「绝对主角」——不是静物写生，是器物的肖像。

**与 F7-AE（非遗器物微距）分工**：AE 是藏品的微距记录（镜头语言主导）；QW 是器物的光影肖像（光影叙事主导，单件/组合/暗调三模式）。

**来源**：签名风格库 S8 吸纳（豆包出图验证 2026-08-16，样图 gallery/f7-qw-scholar-objects.jpg）。

**模式**：QW-1 单器静物（默认）/ QW-2 四艺组合（茶花香书）/ QW-3 光影器物（暗调戏剧版）。

**QW-1 单器静物（默认）**：

```
一幅东方极简器物肖像。[背景色：米白 #F5F0E8]底。画面[位置：中下偏左]一件[器物]，不超过画面四分之一，有[痕迹]，不是新品。[光源方向：左上 45° 侧光]，器物表面明暗清楚，[台面：旧木桌]上极淡投影。台面只露一小条，上方大留白。全画面器物本色、台面色、底色。禁止复杂背景、商品棚拍平光、多件拥挤、文字。
```

**QW-2 四艺组合（茶花香书）**：

```
一幅文人四艺主题的极简静物组合。
【器物组合】
画面中放置 2-3 件文人器物，形成疏密有致的组合——[组合：如一壶一杯（茶）/一炉一瓶（香花）/一砚一卷（书）/一壶一炉一卷（茶香书）]。器物之间有呼吸的间距，不拥挤、不堆砌，如文人案头的自然摆放。每件器物都有使用痕迹和时间感。
【主次关系】
器物组合中有明确的主次——主器物稍大、稍靠前、受光更充分；次器物稍小、稍靠后、处于半影中。主次关系通过大小、前后、光影三层信号传达。
【光影】
[光源方向]的侧光，在器物之间形成微妙的光影互动——主器物的投影可能轻轻触及次器物的边缘，如对话。器物在台面上投下柔和的投影。
【留白】
画面至少 50% 为留白，器物组合集中在画面下部或一侧，上方和另一侧是大片空白。
【色彩】
全画面色彩不超过四种，器物的自然色（陶土/青铜/青瓷/木色）与背景色构成和谐的低饱和色系。
【气质】
几件器物，一段留白，一个文人的精神世界。茶是清醒，香是沉静，花是生机，书是传承——四艺不是技能，是生活的方式。器物组合在一起，如几个老朋友的静默对坐。
【禁止】
超过 3 件器物、器物拥挤、复杂背景、装饰堆砌、多彩、卡通化、文字标语。
```

**QW-3 光影器物（暗调戏剧版）**：

```
一幅暗调戏剧光影的东方器物静物。
【黑暗中的器物】
画面为[背景色：深墨黑/深蓝黑/深褐]深色背景，一件[器物]从黑暗中浮现，只有受光面被[光源：如一束侧光/一缕烛光/一线天光]照亮，大部分器物沉入阴影中。观者只能看到器物的一部分轮廓和高光，其余靠想象补全。
【光影戏剧】
光源打来，在器物表面形成强烈的明暗对比——受光面有温暖的高光，背光面融入黑暗。器物的关键部位（如茶壶的壶嘴/香炉的香烟/花瓶的瓶口）在光线下格外清晰，成为视觉焦点。若为香炉，可有一缕极淡的香烟在光束中若隐若现。
【投影】
器物在台面上投下深邃的投影，投影边缘与黑暗融为一体，如器物向黑暗的延伸。
【留白（暗留白）】
画面至少 60% 为深色背景的「暗留白」——黑暗中的空白比明亮的空白更有张力，它是未知、是沉默、是器物的孤独。
【色彩】
全画面色彩不超过三种：器物受光面的暖色调、背景的深色调、光的微妙色偏（如烛光的暖橙/天光的冷蓝）。整体低明度，如伦勃朗的静物画，但更东方、更克制。
【气质】
黑暗中，一件器物被一束光照亮。它存在了多久？它见证了什么？光只照亮了它的一部分，正如我们只能理解事物的一部分。神秘、安静、有宗教般的肃穆感。
【禁止】
明亮背景、多件器物、复杂装饰、多彩、高饱和、卡通化、文字标语。
```

**量化**：器物 1 件 ≤25%（组合 2-3 件）；投影 1 处；留白 ≥55%（组合 ≥50%，暗调暗留白 ≥60%）；色彩 ≤4 种（暗调 ≤3）；默认 3:4 竖幅（组合可 4:3 横幅，暗调可 2:3 立轴感）。

**槽位**：器物（必填：紫砂壶/铜香炉/青瓷花瓶/旧木砚台/竹编茶则/锡制茶叶罐/玉璧/镇纸/笔架/线香炉）；器物位置（默认中下偏左）；光源方向（默认左上方 45° 侧光，可右侧逆光/顶部柔光/烛光/一线天光）；台面材质（默认旧木桌，可宣纸/石面/亚麻布）；背景色（默认米白 #F5F0E8，暗调用深墨黑 #1A1A1A）；使用痕迹（按器物推演：茶壶→茶渍、香炉→香灰、花瓶→开片）。

**出图锁定句**：只有一件[具体器物]，占比很小；[具体方向]侧光，有明暗和投影，不是平光；是旧物，有[具体痕迹]；至少一半是空白。
