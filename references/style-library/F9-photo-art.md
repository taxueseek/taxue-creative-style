# F9 照片转艺术

**家族量化规格**：保留原照片主体与氛围 ≥70%（不是重绘/滤镜/风格迁移）；留白 ≥40%；元素 ≤4 件；色 ≤4 种；踏雪 DNA（纸感、克制、诗意）。

**风格卡片**：核心调性 = 旧照片的情绪与记忆的艺术化；视觉特征 = 纸感手绘、抽象记忆面板、涂鸦叙事；经典结构 = 保留主体 + 踏雪留白 + 诗意短句/标题；禁忌 = 滤镜感、重绘失真、元素堆砌。

**Best for**：把用户已有的照片（日常废片、旅行碎片、宠物、人像）转成有踏雪审美的艺术作品。

**技法核心**：从照片中**提取关系**（色彩、情绪、结构）而非做风格迁移——保留主体，升华氛围。

**变体索引**：

| 变体 | 名称 | 状态 |

| R1 | 照片复活 | 默认 |
| R2 | 抽象记忆编辑 | 默认 |

## R1 — 照片复活

**Best for**：日常照片/废片 → 大留白纸面诗意手绘插画。

```
把用户上传的照片重绘成一幅大留白纸面上的诗意手绘插画。保留照片原有的主体、姿态与氛围，不做简单滤镜或完全重绘——主体轮廓清晰可辨，像被温柔地重新描画过。纸面为米白宣纸质感，带轻微颗粒与纤维肌理。大面积留白，主体只占画面一角或一小片，周围是空寂的素纸。画面一角以极简手写体写下一行短诗或短句，与画面情绪呼应。色彩克制，纸白为主，墨色勾勒，至多一处淡彩点染。整体安静、克制、有诗意，像一张被时间温柔对待过的旧照片重新活过来。画面中除那行短诗外不出现任何其他文字、水印、日期或签名。

用户输入内容：照片：[请在此上传/描述]
```

**量化**：保留主体 ≥70%；留白 ≥50%；纸白 + 墨色 + 淡彩 ≤1 处；短诗 1 行 ≤15 字。

**槽位**：照片 = 唯一必填变量（上传照片或描述）；主体、氛围、短诗、淡彩色由照片内容推演。

**状态**：待出图验证。

## R2 — 抽象记忆编辑

**Best for**：把照片转成「摄影 + 抽象记忆面板 + 诗意标题」的竖版编辑作品。

```
把用户上传的照片转成一幅竖版编辑作品：上方保留原始摄影区域（原照片的主体与光线，不重绘、不滤镜），下方是与之呼应的抽象记忆面板——从照片中提取的色彩、情绪与关系，化为极简的色块、线条与负空间，像照片在记忆里沉淀后的样子。画面边缘或面板一角放一行极简诗意标题，与照片情绪呼应。整幅作品克制、高级、有展览感，像一张被精心编辑过的艺术杂志跨页。画面中除那行诗意标题外不出现任何其他文字、水印、日期或签名。

用户输入内容：照片：[请在此上传/描述]
```

**量化**：摄影区 + 抽象面板双区；提取关系非风格迁移；留白 ≥30%；色 ≤4 种；标题 ≤8 字。

**槽位**：照片 = 唯一必填变量；摄影区保留比例、面板色彩、标题由照片内容推演。

**状态**：待出图验证。

## R3 — 照片涂鸦海报

**Best for**：日常照片 → 涂鸦风格海报，纯叙事不靠文字。

```
把用户上传的照片转成一幅涂鸦风格的竖版海报。保留照片中一个真实物件或主体作为锚点（如一杯咖啡、一只猫、一个人），周围以轻松手绘的涂鸦线条、色块与碎片化的日常场景填充，像儿童涂鸦的纯真与设计的克制结合。画面以涂鸦叙事代替文字——不添加任何文字，只通过涂鸦元素讲述照片里的故事与情绪。纸面质感，色彩明快但克制在四种以内，大量留白让涂鸦有呼吸感。整体活泼、有手作温度、有故事感，但不失设计秩序。画面中不出现任何文字、水印、日期或签名。

用户输入内容：照片：[请在此上传/描述]
```

**量化**：真实锚点 =1 个；涂鸦叙事不靠文字；留白 ≥40%；色 ≤4 种；禁文字。

**槽位**：照片 = 唯一必填变量；锚点物件、涂鸦元素、配色由照片内容推演。

**状态**：待出图验证。

**Best for**：照片 → 上美影水墨动画风的赛璐璐手绘。

```
把用户上传的照片转成一幅赛璐璐手绘动画感的竖版作品。保留照片的主体、姿态与氛围，以国产经典水墨动画的赛璐璐质感重新演绎——背景以淡墨晕染、宣纸肌理呈现，主体以柔和的墨线勾勒，色彩为传统水墨色板（石青、黛青、淡赭、钛白），平涂与晕染结合，边缘保留手绘的毛边与干湿变化，不追求机械整齐。主体形象清晰可辨，像从老动画里走出来的角色。画面留白含蓄，情绪安静、有东方诗意。色彩克制，墨色为主，至多一处淡彩点睛。画面中不出现任何文字、水印、日期或签名。

用户输入内容：照片：[请在此上传/描述]
```

**量化**：保留主体 ≥70%；赛璐璐手绘质感；水墨色板 ≤4 色；淡墨晕染背景；禁机械整齐边缘。

**槽位**：照片 = 唯一必填变量；主体、姿态、淡彩点睛色由照片内容推演。

## R5 — 皮影涂鸦（照片转皮影戏）

**Best for**：照片 → 皮影戏风格涂鸦，关节式可动感 + 拉毛纹理。

```
把用户上传的照片转成一幅皮影戏风格的竖版作品。保留照片中一个主体的轮廓与姿态，以皮影戏的造型重新演绎——主体为关节式可动的剪影结构，边缘带拉毛纹理与柔性纸张质感，像皮影戏里的角色。背景为传统皮影戏的暖色光晕（米黄、橙红），主体以墨黑或深棕剪影呈现，关节处有轻微的透光与投影，形成皮影戏的层次感。画面点缀少量传统纹样（祥云、缠枝）但克制。整体有民族美学的韵味与手工艺术质感，像一盏灯前的皮影戏定格。色彩克制在四色以内（暖光底 + 剪影深色 + 至多两处传统点缀色）。画面中不出现任何文字、水印、日期或签名。

用户输入内容：照片：[请在此上传/描述]
```

**量化**：保留主体轮廓 ≥70%；关节式可动剪影；拉毛纹理；暖光底 + 深剪影 + 点缀 ≤2 色；传统纹样 ≤2 处。

**槽位**：照片 = 唯一必填变量；主体姿态、点缀纹样、光晕色由照片内容推演。

**状态**：待出图验证。
