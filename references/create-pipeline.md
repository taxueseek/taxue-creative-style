# 模式三：元提示词创作管线

用户给任意需求（一句话到一段话），从零构建精确提示词。**核心：重新定义问题，不是直接翻译需求。**

**元提示词的正确形态（参数化，非固化）**：
- 元提示词 = 可复用模板：风格骨架固定一次，主题、主体意象、题字等为槽位，换主题只换槽位内容，风格段落一字不动。
- 输出必须含三件套：①带槽位的模板正文（保持自然语言）②槽位填法示例（≥3 个主题对照，说明主题→意象→题字如何联动）③替换规则（哪些段落一字不动、哪些联动更换、色彩等约束如何按主题微调）。
- 常见错误：把「当前主题的填充结果」当元提示词交付。用户说「这个我只要输一次即可」「以后换主题复用」= 要模板，只给固化主题版即不合格。
- 微调必须给理由：色彩等「建议锁定」的约束按主题调整时，说明微调原因，并提示保留原色板的替代选项。
- **变量最小化原则**：必填变量越少越好，主题作为唯一必填项是最高形态，主标题、副标题、主题色等由模型从主题自动推演，可留可选覆盖口，但默认不给用户填表负担。
- **用户输入区样式约定**：元提示词结尾保留「以下内容作为变量，每次可替换：」+ 变量列表（用户偏好样式），或更简的「主题：{主题}」单行 + 「用户输入内容：主题：[请在此填写]」；删掉用户的输入区会让模板失去入口感。

## 步骤 1：重定义需求（第一性原理）

用户说「画一张有夏天感觉的图」→ 不可直接出图。先把感受翻译成可执行要素：夏天感觉 = 什么场景（午后窗边）+ 什么光（斜射硬光）+ 什么色（低饱和暖黄绿）+ 什么质感（胶片颗粒）+ 什么情绪（慵懒）。

重定义追问清单（缺哪项问哪项，一次一个问题，优先从上下文推断，能推断就不问）：
1. 主体是什么？谁、在哪里、什么状态？
2. 情绪基调：静/动、暖/冷、庄/谐？
3. 媒介质感：水墨、纸、胶片、CG？
4. 观众感受：看完这张图希望对方感到什么？

## 步骤 1.5：创作推演卡（抽象命题先推演，再进七维）

当主题是抽象概念、情绪、记忆、节气或一句短句（「夏」「白夜」「离别」这类不是具体物件）时，步骤 1 只到要素还不够，还得回答「这个主题到底在发生什么变化、怎么把它画成可执行的形态」。本卡吸收 solar-polaroid 的动态创作路由，用本库语言重写。（具体物件主题如「一只猫在窗台」可跳过本卡，直接七维填充。）

推演卡七项（内部自检，不整段写进 prompt 正文，遵守「枚举不进正文」）：

| 推演项 | 回答什么 | 例子（主题=夏） |
|---|---|---|
| 主题核 | 一句可取舍的命题，写成「什么正在以何种方式改变」 | 浓夏正在把光熬成蜜色，人被逼向阴影 |
| 事实证据 | 选用户事实、可触材料或可见动作之一；无事实时标「创作解释」 | 创作解释：午后窗帘的影子斜在桌上 |
| 张力对 | 一组与主题相关的对照，可决定颜色与密度 | 明/暗、燥/静 |
| 核心形态 | 从方向、过程、连接、动作、断裂、累积中选一个可识别形态 | 光影的斜切与堆积 |
| 空间规则 | 让网格、留白、层叠、连续、剪影之一服务核心形态，不默认居中 | 大面积留白，主体偏一角 |
| 媒介材质 | 选与主题匹配的真实媒介，不用泛黄/颗粒冒充质感 | 水彩纸、夏日曝光过的胶片 |
| 文案语气 | 观察、记录、私语、索引或无文字之一，每句回到事实证据 | 短句如「影子已经斜到墙根」 |

**推演纪律**：
1. 事实证据必须标明来源，分「用户事实 / 创作解释」；未给地点时间时写「创作解释」，禁止伪造真实物候。
2. 张力对不强制二元色场，只取与主题相关的对照；色彩由张力对推导，不套固定色卡。
3. 核心形态从主题的变化里提取，不是装饰；空间规则服务于形态，不默认居中卡片。
4. 一组图至少改「主题角度 / 事实证据 / 核心形态 / 空间规则 / 媒介 / 文案语气」中的两项，禁止只换色或镜像。
5. 主题核写不出来就用一句推演指令进正文（如「核心形态与空间方向由主题推演」），禁止把七项枚举塞进 prompt。

## 步骤 2：七维填充（MECE 拆解）

任何影像 = 主体 × 构图 × 光影 × 色彩 × 质感 × 情绪 × 约束。逐维填实，每维至少一个可执行描述，不写抽象词（「高级感」不算描述）。（注：这是创作七维；与模式二诊断七维的「风格锚点/负向」不同，两套清单用途不同，勿混用。）

## 步骤 3：风格 DNA 决策

- 用户未指定风格 → 读 theme-router.md 按九类主题选主风格，再打开对应家族文件的一个变体段；禁止整库通读，禁止把剪纸与皮影写进同一张 prompt；**主题为「字/词/词组/短句的视觉化」或「高级概念海报」时，优先路由 F8-V8**（已验证模板）；**主题为「用户已有照片的艺术化」时，优先路由 F9-R1~R5**；**主题为「运动/速度感」时，优先路由 F7-H**；**主题为「抽象概念的诗意可视化 / 儿童绘本手账风」时，优先路由 F4-K**；**主题为人物/雅士/仕女/背影/时装形象时，先读 character-scene.md 定场面，再套对应默认变体，禁止把两个场面写进同一张 prompt**
- 用户指定了非本库风格 → 走 optimize-pipeline.md 对待（先诊断用户的风格描述再组合）
- 用户要求创新/混搭 → **混搭卡片机制**：明确「哪张家族卡片做内核（调性/概念深度）、哪张做外壳（视觉语言）、各自占比」，不得模糊混搭。范式：`内核 = 卡片的调性 + 外壳 = 卡片的视觉特征`。示例：F1 水墨调性（孤寂哲思）+ F2 海报外壳（极简几何+留白）= 水墨概念海报；F6 氛围调性（神秘电影感）+ F7 摄影外壳（胶片颗粒）= 电影感概念摄影
- **风格四层职责（混搭时的归属裁决，防风格吞并）**：任何成图的风格系统分四层，混搭/优化时逐层写明归属，禁止一层吞并另一层——
  ①主风格：管全局造型、线条、基础上色、空间语言（决定「这是一张什么图」）
  ②辅助风格：可为零；只承担局部职责（如仅管背景/仅管配色），禁止升格成全局主风格
  ③表面层：管颗粒、纸感、色偏、印刷感、扫描感等成像介质；归主风格的载体管，不随辅助风格变
  ④载体层：管最终呈现媒介（宣纸/胶片/印刷品/屏幕）
  混搭裁决示例：F1 调性 + F7 外壳时，表面层的颗粒属于 F7 载体（胶片颗粒），不得因内核是 F1 就改写为宣纸纤维——四层各自锁定，换任何一层不得连带动其他层
- **关系提取优先**：元提示词先定义「主题 → 核心关系」的转译，再画关系，不预写意象。踏雪寻仙的核心关系 = 寻→远方→不可及；鲸落 = 沉没→深海→归于寂静；白夜 = 永恒→循环→昼夜交界。关系决定叙事轴（视觉方向随主题情感推演），意象从关系派生，不从主题名硬编
- **概念海报双技法**：①字形级隐喻（笔画替换/字形同构/局部解构/正负形，词义做进字形）；②关系级叙事（字与图的空间关系承载词义）。两技法可单用可叠加，默认叠加
- **个人视觉系统定位**：本 skill 不是单风格生成器，是系统化视觉资产——家族卡片 + 修复块 + 色板 + 归档共同构成可复用的视觉系统，交付时提示词与成图一体（polished prompt + 图），不只是文本
- **枚举不进正文（MECE 枚举是自检逻辑，不是 prompt 内容）**：推演用的枚举清单（如五种空间叙事轴、六种情绪倾向）用于自检与设计侧推演，**禁止整段写进正文**。正文只留一句推演指令（如「核心关系与空间叙事方向由词义推演」），模型自会推演；枚举+括号塞进正文只会稀释注意力、制造噪音、导致崩坏。

## 步骤 4：量化锁定

出图前锁定：比例（prompt-craft.md 尺寸表）、色板（明确色名+角色+占比）、留白预算（若有）、元素数量上限、负向清单（精准克制，见下）。凡画面含指定文字，正文以自然语言写明文字纯净句（主 SKILL.md DNA 第 7 条）。色板用 HEX 色值锁定消除歧义（prompt-craft.md 参考色板）。六词检查口诀：风格、主体、动作、环境、构图、参数，六维说清再出图。人物主题额外锁三项（细则见 character-scene.md 技巧层）：①媒介先行（第一句锁定制作语言）；②尺度锚点（人物占画面百分比写死）；③光只做一件事（塑形 / 透光 / 环境时刻，三选一）。动作用未完成态。情绪只从姿态、视线、道具推。

**色板三件套（色名 + 角色 + 占比）**：≤4 色时写明每色的角色与占比（如「墨黑 #2C2C2C 主色约六成 / 宣纸白 #F5F0E8 底色约三成 / 朱砂红 #C3272B 点缀色不足一成」）。「单一强调色常已足够」是 2-3 色方案的简写形态，不是另一套标准；中高饱和需柔化处理，两个约束不冲突。

**负向克制原则（与 optimize-pipeline 负向维同一口径）**：只列该风格最可能真实跑偏的 2-5 个风险点，正向描述优先（「背景保持素净」优于「不要复杂背景」）；正文已声明的特征不得列入负向；无真实风险时写明无额外约束，禁止照抄通用否定词表。原图/原文已有的特征（如胶片颗粒、纸感）列入负向属自相矛盾。

**变体幅度（用户要「改一版/微调一版/换个姿势」时）**：锁风格四层职责（主风格/辅助/表面/载体一字不动），只改 2-4 个内容维度（主体内容/动作姿态/视线表情/服装道具/背景），小步幅度；变体交付必须附「哪些锁了、哪些变了」两行清单，禁止全盘重写。

**比例唯一性**：同一 prompt 正文只允许出现一个画幅比例；构图段与建议比例必须一致。宿主不支持目标比例需降级时（如 5:2 → 20:9），构图段同步改写（保留横向叙事与两侧渐隐描述），禁止只改比例数字不动构图段。

用户点名胶印 / 专色 / Riso / 单色或双色印刷封面时，不在本管线填印版配方，改走 `taxue-poster-studio` 印刷模式。F2 / F8 / F13 模板原文不因此改写。

**矛盾扫描关卡（交付前强制，与模式二同一道关卡）**：执行 optimize-pipeline.md 步骤 1.5 的十二类矛盾扫描。创作时从多个风格来源拼贴意象，媒介互斥（水墨×丙烯）、专名堆砌（≥2 画师名并列）与景别互斥是最高发类型；填入的意象必须与主题名词逐词对照（马×角）。输出格式同模式二：矛盾扫描结果（严重修复/轻微保留/通过）。

## 步骤 5：出图（imagegen-routing.md）→ 自检（prompt-craft.md）→ 记录（memory-protocol.md）。

**保持独到影像风格的三道闸**：
1. 拒绝直译：符号性需求（画龙舟、画月饼）必须转译为情感本质（F2-B 的「主题的东西不直接画」逻辑）
2. 留白强制：浅底/纸底家族（F1/F2/F4/F5 浅底变体/F8/F9/F10/F12/F13-AR）按各自家族规格的留白下限写进提示词；无留白规格的深底或满构图变体（F3-O、F5-L、F5-M3、F6-D、F11 灯屏、F14-YZ 年画满幅）改写为等价的负空间与呼吸感描述，禁止向这类模板注入留白百分比
3. 色彩预算：任何图 ≤4 色，写明确色名不写「多彩」「丰富」；唯一例外 = geometric-monument-poster.md 定稿模板（基座同色系层级需 ≤5 色），其余一律 ≤4
