## A — 文人水墨漫画（最鲜明主风格）

**Best for**：孤寂人物、安静日常、哲思或幽默的独处瞬间。

```
你是一位中国现代文人水墨漫画的创作者。用极简的笔墨，描绘一个疏简、孤寂而略带幽默的瞬间。

【基底】
陈年宣纸的米黄色肌理，带有细微纤维质感和自然老化痕迹。无任何背景纹样、图案或装饰。

【笔墨】
以毛笔写意，线条必须有粗细顿挫和枯润变化，生拙而有骨感。绝对禁止使用均匀的钢笔式描边或矢量线条。墨色为主，浓淡自然分层。

【人物】
人物仅以墨线勾勒轮廓，不作立体渲染。五官极度简化——眼睛至多为豆点大小，嘴巴至多为一短线或完全省略。情绪完全通过弯腰、低头、侧身、抬手等身体姿态传达，而非面部表情。

【场景与器物】
场景置于画面的唯一角落，不居中。器物最多不超过三件，如茶壶、孤灯、木凳、卷轴、杯盏、枯枝、烛台、书本等。器物同样以生拙墨线勾勒，不求工整。

【留白】
画面至少一半面积为素纸留白。留白不是空缺，是构图的主体部分。宁可空寂，不可拥挤。

【色彩】
墨色为绝对主导，占画面95%以上。仅允许一件小物施以淡赭或砖红薄薄点染，成为画面唯一的暖色。不使用其他任何颜色。

【题字】
留白处以竖排方式题写三两列毛笔行楷，字形略显笨拙，不求流美。内容为诗意而含哲思的短句，与画面形成互文。题字位置偏侧或偏下，不抢占主视觉。题字原样呈现不加标点，画面中除题字外不出现任何其他文字与标点，无任何水印、日期或签名。

【气质】
整体气息清淡、克制。幽默藏在孤寂里，诗意藏在笨拙里。宁可意犹未尽，不可一览无余。

【禁止】
印章、均匀线条、完整五官、复杂场景、多种颜色、对称构图、填满画面的倾向、华丽装饰、卡通化表达。

用户主题：[在此填入用户请求]
```

**量化**：墨 95% + 单暖色 5%；留白 ≥50%；器物 ≤3 件；题字 2-3 列竖排。

## Q2 — 水墨猫（动态速写）

**Best for**：猫的运动感、残影效果。

```
随机毛色猫咪自然随机姿态的极简水墨速写。用3-5条粗犷流畅的平行墨色线条叠加，捕捉猫身体的运动轨迹和残影效果。线条随猫的身体曲线自然延展，笔触浓淡参差，边缘自然晕染形成动态模糊感。尾巴如飘带般随势流动。大面积留白，粗糙宣纸上的干笔皴擦质感。
```

**量化**：墨线 3-5 条；留白 ≥60%；禁五官细节。

## Y — 宋代极简山水（现代极简 × 宋画意境）✅ 已验证

**Best for**：竖幅壁纸、现代艺术海报、禅意空间、文化概念画面。

```
一幅融合宋代山水画意境与极简主义构成的现代艺术作品。画面以天青色为主调，占据60%面积，宣纸米白为底色，墨色浓淡为骨架，天青之外至多一处淡赭作极小点缀（如孤舟或人物衣点）。采用S型构图，远山以几何化的三角形层叠呈现，层叠三四重，山形保留手绘的毛边与墨色干湿变化，不追求边缘整齐；中景留一处极小的孤舟或行人点景，仅米粒大小，作为尺度参照。近景留白处仅以几笔飞白书法线条暗示水波，飞白枯润相间，如毛笔自然拖出，不似矢量描画。宣纸纹理细腻，天青以矿物颜料薄罩而成，留有纸面颗粒与边缘自然晕染。光线柔和如晨雾：漫射光，无投影，明暗过渡如墨色晕染般缓慢。整体宁静禅意。禁止：均匀矢量平涂、光滑渐变、3D渲染体积感、完美对称、过度规整的几何切割、额外文字、水印、日期、签名。
```

**量化**：天青 60% + 米白底 + 墨骨架 + 点缀 ≤1 色；山形层叠 3-4 重；点景 ≤1 处且米粒大小；S 型构图；默认 9:16 竖幅。
**槽位**：点缀色与点景内容（孤舟/行人）可替换；比例可按用途换 3:4 或横幅。
**状态**：已出图通过（2026-08-13，Grok Imagine，9:16），可进默认路由。

## AF — 墨迹微缩世界（书法墨迹 × 3D 微缩 × 场景名文字轮廓）

**Best for**：城市名 / 神话场景 / 游戏世界观的「文字轮廓视觉化」，把任何场景名变成一幅从墨迹里生长出来的微缩世界。

**来源**：早期实践会话固化（2026-02，两轮对话 8 次迭代：融合版 → 单变量版 → 三层架构版 → 自然语言版 → 指代词单输入版）。核心方法论：场景名唯一变量，全文用「这个场景」指代词代指；三层架构 = 结构约束层（不可变）+ 内容授权层（模型自主提取符号）+ 渲染参数层。

**场景版模板（通用，覆盖城市/中西神话/游戏世界观，唯一变量 = 场景名）**：

```
场景：{场景名}

首先，提取「{场景名}」最具辨识度的 3~5 个视觉符号，以这些符号为核心作画。

一只手从画面右侧伸入，握着一支蘸满浓墨的毛笔，正在一张这个场景的图录上书写——笔锋从右下角向左上角划过，留下一道饱满的书法墨迹，边缘自然晕开。

墨迹里长出了这个场景的微缩世界——只放最能让人一眼认出它的东西，它们密集堆叠，恰好拼成这个场景名字的文字轮廓，像从墨水里生长出来的立体模型，场景本身的材质与光感，和黑墨形成强烈对比。

笔尖停在左上角，墨迹之外纯白。右下角起笔处，工笔题写这个场景的名称与别称，下方跟着原文名称与注音，顺笔迹方向斜排，细小清晰。

图录铺在做旧的古卷或图板上，符文与地域轮廓若隐若现。纯白背景，电影感打光，景深，8K，超写实，商业插画，画幅 2:3。
```

**城市版变体（场景名换成城市名时替换四组词）**：街头地图 + 做旧亚麻纸（换「图录/古卷」）；山、水、老街、古建、高楼、园林（换「符号清单」）；玻璃和金属质感（换「场景本身的材质」）；瘦金体 + 拼音（换「工笔题字 + 注音」）。

**量化**：三层空间叙事 = 图录层 → 墨迹层 → 微缩世界层；留白 ≥50%（笔迹外纯白，无边框无阴影）；元素 = 场景专属符号 3-5 个密集堆叠；题字 ≤2 处且极小；比例默认 2:3。

**槽位**：场景名 = 唯一必填变量；符号清单、质感对比、载体（图录/地图/卷轴/图板）由场景类型推演，不写死。

**状态**：早期实践已验证迭代逻辑，本体系待出图验证（城市版/神话版各一张）。

## AG — 线舞水墨猫（早期实践固化）

**Best for**：猫的线条之美，纯线条构成的水墨猫，禅意与笔势。

**来源**：早期实践标题固化（2026-02）。与 Q1（写意猫）的区别：Q1 有墨块晕染与留白构图，本变体**不见块面、唯有线的舞蹈**，纯线条造型。

```
当代水墨作品，画面中央一只猫完全由飞白与游丝般的焦墨线条写成，不见块面，唯有线的舞蹈。猫身呈 S 形，脊背的弧线以一笔枯笔飞白拖出，毛发的蓬松用游丝般的细线层层叠加，尾巴卷成一圈，线势回旋。线条有枯润浓淡变化，焦墨处如铁线，飞白处如云烟。大面积留白，纯素纸底。题字竖排一角，与线条的节奏呼应。墨色为绝对主导，至多一处淡赭点染。整体空灵、禅意、有笔势的韵律，像一笔写成的猫。
```

**量化**：线条 = 飞白 + 游丝两类笔法；无块面（禁晕染团块）；猫身 S 形构图；留白 ≥60%；墨色 95% + 淡彩 ≤1；题字 ≤1 列。

**槽位**：猫的姿态（S 形/回望/伸懒腰）可换。

**状态**：原始提示词为早期实践标题截断版，正文为本体系按标题笔法补全，待出图验证。
